# Task Plan for Manim Math Animations

## Project Overview
Process prompts.md files one by one to create math animations using Manim, verify the implementations, and generate final MP4 files.

## Phases
1. Discovery: Find all prompts.md files that don't have corresponding MP4 files
2. Processing: For each prompt, use the manim-math skill to create animations
3. Creation: Generate/update storyboard.md and Python code files
4. Verification: Run verification scripts on generated code
5. Animation: Execute Manim code to generate MP4 files

- [ ] Update storyboards and Python files for each
