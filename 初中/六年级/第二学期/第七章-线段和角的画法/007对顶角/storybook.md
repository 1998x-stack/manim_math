# 对顶角教学动画 - 分镜脚本

## 元信息
- **目标时长**: 60-75 秒
- **场景数量**: 7 个
- **难度等级**: 六年级（初级几何）
- **核心概念**: 对顶角的定义和性质（对顶角相等）

## 几何预计算清单

### 核心元素
| 元素 | 计算公式 | 存储变量 | 说明 |
|------|---------|---------|------|
| 交点O | 直线交点 | self.O | 两条直线的交点，画面中心 |
| 直线1端点 | O ± direction1 * length | self.A1, self.A2 | 第一条直线（蓝色） |
| 直线2端点 | O ± direction2 * length | self.B1, self.B2 | 第二条直线（红色） |
| 角1顶点方向 | A1-O, B1-O | - | ∠1的两条边 |
| 角2顶点方向 | B1-O, A2-O | - | ∠2的两条边（邻补角） |
| 角3顶点方向 | A2-O, B2-O | - | ∠3的两条边（与∠1对顶） |
| 角4顶点方向 | B2-O, A1-O | - | ∠4的两条边（与∠2对顶） |

### 几何验证
- ∠1 + ∠2 = 180° (邻补角)
- ∠1 = ∠3 (对顶角相等)
- ∠2 = ∠4 (对顶角相等)

## 技术要点提醒

### 1. 角度圆弧绘制
- 使用 `Angle` 类或 `Arc` 类
- 精确计算起始角度和终止角度
- 半径建议: 0.4-0.6（适合竖屏显示）

### 2. 度数标注
- 使用 `MathTex` 显示角度符号
- 度数符号: `r"60^\circ"`（不要用 `°`）

### 3. 邻补角关系
- 验证: angle1 + angle2 = π (180°)
- 对顶角: angle1 = angle3, angle2 = angle4

### 4. 相交线角度
- 建议使用45°或60°的交叉角（不要90°，避免特殊情况）
- 方向向量示例:
  - line1: 从(-3, 0, 0)到(3, 0, 0) 旋转30°
  - line2: 从(-3, 0, 0)到(3, 0, 0) 旋转-30°

### 5. 文字处理
- 所有中文用 `Text(font="Noto Sans CJK SC")`
- 数学公式用 `MathTex`
- 避免在 `MathTex` 中放中文
