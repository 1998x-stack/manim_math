## Scene 1: 开场钩子 (4秒)
**目的**: 生活情境引入，抓住注意力

### 元素
1. 作者信息 (y=7.3)
2. 钩子文字: "你能找出这个神秘数字吗？"
3. 问题: "某数加上 5 等于 12，某数是？"
4. 悬念停顿

---

## Scene 2: 建立方程概念 (8秒)
**目的**: 从文字问题过渡到方程

### 动画序列
1. "某数" → 用 x 表示 (Transform)
2. 文字方程 → 符号方程 x + 5 = 12
3. 强调结构: 左边 / 等号 / 右边

---

## Scene 3: 定义 — 什么是一元一次方程 (10秒)
**目的**: 拆解定义三要素

要素拆解（逐条亮起）:
1. "一元" → 只含**一个**未知数
2. "一次" → 未知数的次数是 **1**（指数=1）
3. "方程" → 含有未知数的**等式**

### 元素布局
- 标题: "一元一次方程" (y=6.0)
- 定义框（三行逐条出现）
- 公式: ax + b = 0 (a ≠ 0)

---

## Scene 4: 反例辨析 (8秒)
**目的**: 通过反例加深理解

展示4个式子，逐一判断:
1. x + 5 = 12      ✓ 是
2. x² + 1 = 0      ✗ 不是（二次）
3. x + y = 3       ✗ 不是（两个未知数）
4. 3x - 6 = 0      ✓ 是

---

## Scene 5: 标准形式 ax+b=0 (6秒)
**目的**: 展示标准形式，标注各部分

### 元素
- 大公式: ax + b = 0
- 标注箭头: a→系数, x→未知数, b→常数项
- 强调 a ≠ 0

---

## Scene 6: 方程的解 (8秒)
**目的**: 什么是方程的解

### 动画
1. x + 5 = 12
2. 尝试 x = 7: 7 + 5 = 12 ✓ → 是解
3. 尝试 x = 3: 3 + 5 = 8 ≠ 12 ✗ → 不是解
4. 结论: 使左右两边相等的值 = 方程的解

---

## Scene 7: 解方程预告 (4秒)
**目的**: 承上启下，预告解法

- "如何求解？→ 用等式的性质"
- Transform: x+5=12 → x=7

---

## Scene 8: 总结 + 片尾 (6秒)
**目的**: 知识点归纳 + 关注引导
