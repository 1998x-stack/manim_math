## Scene 1: 开场钩子 (3秒)
- 文字: "不等式里藏着一个大秘密..."
- 例子: "已知 x > 3，两边 ×(-1) 会发生什么？"
- 悬念停顿

## Scene 2: 概念引入 — 不等式 vs 等式 (6秒)
- 等式: a = b（天平平衡）
- 不等式: a > b（天平倾斜）
- 不等号种类: > < ≥ ≤

## Scene 3: 一元一次不等式定义 (7秒)
- 定义三要素（类比方程）:
  - 一元: 只含一个未知数
  - 一次: 次数为 1
  - 不等式: 含不等号
- 标准形式: ax + b > 0 (a≠0)
- 例子: 2x - 3 > 0, x + 1 < 5

## Scene 4: 性质一 — 加减法（不等号不变）(8秒)
- 初始: a > b
- 同加 c: a+c > b+c ✓ 不等号不变
- 同减 c: a-c > b-c ✓ 不等号不变
- 视觉：倾斜天平两边各加砝码，仍倾斜（同向）

## Scene 5: 性质二 — 乘除正数（不等号不变）(7秒)
- 初始: a > b
- 同乘 c (c>0): ac > bc ✓
- 视觉：箭头方向不变，绿色 ✓

## Scene 6: 性质三 — 乘除负数（不等号翻转！）(10秒)
⭐ 核心难点
- 初始: a > b
- 同乘 c (c<0): ac < bc ⚠️ 翻转！
- 具体数字演示: 3 > 2, ×(-1) → -3 < -2
- 动画：不等号旋转翻转（Transform）
- 强调警告框

## Scene 7: 解不等式示例 (10秒)
- 解: 2x - 6 > 0
  - Step1: 两边 +6 → 2x > 6
  - Step2: 两边 ÷2（正数，不变）→ x > 3
- 数轴表示：x > 3，开区间，向右箭头

## Scene 8: 数轴表示解集 (5秒)
- NumberLine 动画
- x > 3: 空心点 + 右箭头
- x ≤ 2: 实心点 + 左箭头
- 对比说明
