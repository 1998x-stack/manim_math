## Scene 1: 开场钩子 (3秒)
**目的**: 吸引注意力，提出问题

### 元素
1. 作者信息 (y=7, 灰色小字)
2. 大问号 + 钩子问题
3. 等式示例

### 动画序列
| 时间 | 动作 | 代码 |
|------|------|------|
| 0.0s | 作者信息淡入 | FadeIn(author) |
| 0.3s | 钩子文字: "等号两边能随意操作吗？" | Write(hook) |
| 1.3s | 等式 x+3=7 出现 | FadeIn(eq) |
| 2.0s | 等待 | wait(1.0) |

### 清理
- FadeOut: hook, eq

## Scene 2: 等式定义回顾 (4秒)
**目的**: 建立直觉——等号 = 天平平衡

### 元素
1. 标题: "等式的性质"
2. 天平图形（水平，平衡状态）
3. 左盘: a, 右盘: b

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 标题淡入 |
| 0.5s | 天平从中心生长 |

| 2.5s | 等号 "a = b" 出现在天平下方 |
| 3.0s | 等待 + 说明文字: "天平平衡 = 等式成立" |

## Scene 3: 性质一 - 加法 (9秒)
**目的**: 直观展示等式两边同加一个数仍相等

### 元素
1. 天平（平衡: a=b）
2. 向两边各加 "+c"
3. 天平仍平衡
4. 公式: a+c = b+c

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 性质一标题: "性质一（加法）" |
| 0.5s | 天平出现，左a右b，平衡 |
| 1.5s | 箭头指向左盘，"+c" 出现（橙色） |
| 2.0s | 同步在右盘也出现 "+c" |
| 2.8s | 天平保持水平（不倾斜） |
| 3.5s | 公式显示: 若a=b, 则a+c=b+c |
| 5.0s | 高亮闪烁 "仍然成立" |
| 6.5s | 等待理解 |

## Scene 7: 实例应用 (10秒)
**目的**: 用性质解方程

### 实例1: x + 3 = 7
1. 显示方程
2. "两边减3" 
3. x + 3 - 3 = 7 - 3
4. x = 4 ✓

### 实例2: 2x = 6
1. 显示方程
2. "两边除以2"
3. 2x/2 = 6/2
4. x = 3 ✓

```
性质一：a=b → a±c = b±c

```
