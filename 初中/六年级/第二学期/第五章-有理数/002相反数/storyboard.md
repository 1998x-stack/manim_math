# 002 相反数｜可核验分镜

入口：`opposite_numbers.py` → `OppositeNumbers`。9×16 逻辑竖屏，1080×1920。所有数轴点均调用同一 `NumberLine.n2p(value)`，不得由图像位置反猜数值。

| 镜头 | learning_fact / 输入条件 | 实际屏上状态 | 数学与对象检查 |
| --- | --- | --- | --- |
| 1 开场 | 3 与 -3 | 显示数对并引出互为相反数 | 二者和为 0；提示不能暗示 0 没有相反数 |
| 2 数轴 | 原点、±3 | 标准 `NumberLine([-5,5,1])`，由 `n2p(-3)`、`n2p(0)`、`n2p(3)` 标点 | 对称于原点，两侧各距离 3；数轴独立持有 `self.axis` 引用，后续镜头复用 |
| 3 定义 | 任意有理数 a，opposite(a)=-a | ±3 的左右距离箭头相同；公式 `a+(-a)=0` | 距离箭头置于刻度上方，必须检验 `a=0` 及 `a<0`；不使用“必须符号不同”排除 0 |
| 4 举例 | ±4、±1.5 | 数据列表驱动每个数轴点和对应显示数字；公式 `-(-a)=a` | 对任意展示例子，有 `a+(-a)=0`；标签取实际 `value` |
| 5 特例 | a=0 | 原点高亮、`-(0)=0`、`0+0=0` | 0 既不正也不负，0 的相反数仍为 0 |
| 6 总结 | 任意有理数 a | 一页展示数轴对称、求相反数、二重取反与零 | 实际 Scene 标题与品牌复用原有对象；明确未渲染前无法宣称安全区/字形通过 |
