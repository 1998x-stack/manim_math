# 005 有理数大小比较｜逐例分镜与数学规格

源文件：`005_有理数的大小比较.py`；保持入口 `有理数的大小比较Animation`。画幅：1080×1920，逻辑 9×16。教学内容：负数小于零，正数大于零；正数之间绝对值大的更大；负数之间绝对值大的反而更小；右边的数大于左边的数。

| 镜头 | learning_fact 与给定数据 | 可见状态 | 生命周期与 check |
|---|---|---|---|
| 1 数轴引入 | 原点 0、正方向及固定单位长度 | `NumberLine([-4,4], length=7)`，作者/标题位于竖屏顶部 | 保留数轴至最后；刻度和 dot 都使用轴的 `n2p(value)` |
| 2 原三数比较 | `values=(-2,0,1)`，`-2 < 0 < 1` | 保留原有 `MathTex(r"-2 < 0 < 1")` 和说明“数轴上右边的数大于左边的数”，三点位于 -2、0、1 | 兼容现有 `tools/tests/test_grade6_gotchas_contract.py`；结束清理三点与原公式 |
| 3 两正数 | 1 < 3；|1| < |3| | 点、箭头、标签与 `1<3` 来自同一条数据记录 | 两点位置严格递增；临时对象在镜头结束时清理 |
| 4 两负数 | -3 < -1；|-3| > |-1| | -3 点在 -1 点左边，中文说明“两个负数：绝对值大的数反而更小” | 不能把绝对值比较方向和数值比较方向混淆 |
| 5 分数 | 1/2 < 3/2 | 点在数轴 0.5、1.5 位置；可见分数标签与数值同源 | MathTex 只包含合法纯数学字符串；检查分数标签与点位置对应 |
| 6 总结 | -3 < -1 < 0 < 1 < 3 | 数轴、右大左小规则和不等式同时出现 | 结束清除临时数据、数轴、标题与作者信息 |
