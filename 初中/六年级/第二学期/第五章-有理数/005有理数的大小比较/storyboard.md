# 005 有理数大小比较｜逐例分镜与数学规格

源文件：`005_有理数的大小比较.py`；入口保持 `有理数的大小比较Animation`（合法 Python Unicode 类名）。1080×1920，逻辑 9×16。课堂内容必须覆盖：正数大于 0、负数小于 0；同为正数绝对值大的更大；同为负数绝对值大的反而更小；数轴上右边的数大于左边的数。

| 镜头 | 给定数据、learning_fact | 可见状态 | check 与对象生命周期 |
|---|---|---|---|
| 1 引入 | 一条数轴的原点、正方向、固定单位长度 | `NumberLine([-4,4], length=7)`；标题/作者在竖屏顶部 | 数轴 0 位置由 `axis.n2p(0)` 决定；数轴和作者至片尾保持 |
| 2 负数与零 | -2 < 0 | `Dot(axis.n2p(-2))` 在 `Dot(axis.n2p(0))` 左边；箭头左到右，屏幕公式 `-2<0` | 每组点、箭头、数字标签、结论同组显示后清理 |
| 3 零与正数 | 0 < 1 | 同一轴位置 0、1 与公式保持一致 | 不混用相反数标签 |
| 4 正数之间 | 1 < 3，|1| < |3| | 1 的点在 3 左边，文字指出“两个正数：绝对值大的数更大” | 数据与文字共同由同一比较行驱动 |
| 5 负数之间 | -3 < -1，但 |-3| > |-1| | -3 的点在 -1 左边，强调“两个负数：绝对值大的数反而更小” | 避免把负数的绝对值比较方向误写为数值比较方向 |
| 6 分数之间 | 1/2 < 3/2 | 0.5 与 1.5 的点通过 `axis.n2p(value)` 定位；可见标签使用真实分数 | 分数 MathTex 与浮点坐标来自同一数据行，不出现标签错位 |
| 7 总结 | -3 < -1 < 0 < 1 < 3 | 保留数轴并显示右大左小规则 | 清理所有临时示例、数轴、作者；不存在其它画面残影 |
