## 几何预计算清单

### 长方体参数
| 参数 | 值 | 说明 |
|------|---|------|
| 长 (length) | 3.0 | x方向 |
| 宽 (width) | 2.0 | y方向 |
| 高 (height) | 2.5 | z方向 |
| 缩放 (SCALE) | 0.7 | 适配竖屏 |
| 偏移 (OFFSET) | UP * 1.5 | 整体位置 |

### 8个顶点坐标（逆时针，前面优先）
使用 Prism 类会自动生成，但我们需要手动标记：

**前面4个顶点**（z = height/2）:
- V0: 左下前 `[-length/2, -width/2, height/2]`
- V1: 右下前 `[length/2, -width/2, height/2]`
- V2: 右上前 `[length/2, width/2, height/2]`
- V3: 左上前 `[-length/2, width/2, height/2]`

**后面4个顶点**（z = -height/2）:
- V4: 左下后 `[-length/2, -width/2, -height/2]`
- V5: 右下后 `[length/2, -width/2, -height/2]`
- V6: 右上后 `[length/2, width/2, -height/2]`
- V7: 左上后 `[-length/2, width/2, -height/2]`

### 12条棱分组
**长度方向（4条，平行于x轴）**:
- 前下: V0-V1
- 前上: V3-V2
- 后下: V4-V5
- 后上: V7-V6

**宽度方向（4条，平行于y轴）**:
- 左前: V0-V3
- 右前: V1-V2
- 左后: V4-V7
- 右后: V5-V6

**高度方向（4条，平行于z轴）**:
- 左下: V0-V4
- 右下: V1-V5
- 右上: V2-V6
- 左上: V3-V7

### 6个面
1. **前面**: V0-V1-V2-V3
2. **后面**: V4-V5-V6-V7
3. **左面**: V0-V3-V7-V4
4. **右面**: V1-V2-V6-V5
5. **上面**: V3-V2-V6-V7
6. **下面**: V0-V1-V5-V4

## 技术难点与解决方案

### 难点1: 3D顶点标签位置
**问题**: 3D场景中，顶点标签可能被遮挡或位置不准

**解决方案**:
```python
# 使用 always_redraw + 3D投影
label = always_redraw(
    lambda: Text("V0").move_to(
        vertex_position + OUT * 0.3  # 略微向外偏移
    ).scale(0.8)
)
```

### 难点2: 棱的分组高亮
