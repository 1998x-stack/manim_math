## Scene 3: 相交关系 (16-28秒)
**目的**: 展示两平面相交 α ∩ β = l

### 3D几何（核心计算）
- α: z=0 水平矩形 [-2.5,-1.5,0] ~ [2.5,1.5,0]
- β: α绕x轴旋转60°得到
  - β_corners = rotate_x(α_corners, 60°)
  - 二面角 = 60°（非直角）
- 交线 l: x轴，y=0, z=0

### 旋转验证
rotate_x(P, θ) = [Px, Py·cos(θ), Py·sin(θ)]
β法向量 = (0, sin(60°), -cos(60°)) = (0, √3/2, -0.5)
α法向量 = (0, 0, 1)
夹角 = arccos(|n_α · n_β|) = arccos(0.5) = 60° ✓

### 动画序列

| 16.5 | α 水平平面创建 |
| 17.5 | β 倾斜平面从铰链线展开 |
| 18.5 | 交线 l (黄色Line3D) 高亮 |
| 19.0 | 公式 α ∩ β = l |
| 19.5 | 镜头旋转 2.5秒 |
| 22.0 | 清场 |
