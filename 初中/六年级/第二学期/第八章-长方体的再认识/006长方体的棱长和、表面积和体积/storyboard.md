# 长方体的棱长和、表面积和体积 - 动画分镜脚本

## 元信息
- 年级: 六年级第二学期
- 目标时长: ~60 秒
- 场景数量: 7 个
- 背景色: #1a1a2e

## 颜色配置
```python
BG        = "#1a1a2e"
C_BOX     = "#4a90d9"   # 长方体蓝
C_EDGE    = "#f1c40f"   # 棱 黄
C_FACE_A  = "#e74c3c"   # ab面 红
C_FACE_B  = "#2ecc71"   # bc面 绿

```

## 几何参数
```
a = 2.0  # 长 (x方向)
b = 1.4  # 宽 (z方向)  
c = 1.0  # 高 (y方向)
Prism(dimensions=[a, c, b]) → Manim中 dimensions=[length, height, depth]
摄像机: phi=65°, theta=-45°
```

## 坐标系约定
- Manim Prism: dimensions=[x, y, z]
- 摄像机视角下: x=长方向, y=高方向, z=深度方向
- 中心在 ORIGIN
