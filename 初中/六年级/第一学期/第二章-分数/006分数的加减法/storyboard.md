## Scene 2: 同分母加法 - 直观演示 (5-18秒)
**目的**: 用圆饼图直观展示 1/4 + 1/4 = 2/4 = 1/2

### 核心概念
同分母分数相加：**分母不变，分子相加**

### 视觉元素
1. 两个圆形（圆饼）
2. 第一个圆：1/4 涂色（90度扇形）
3. 第二个圆：1/4 涂色（90度扇形）
4. 数学公式：`1/4 + 1/4`
5. 结果圆：2/4 涂色（180度扇形）
6. 化简步骤：`2/4 = 1/2`

### 几何计算
```python
# 圆心位置
self.circle_left_pos = np.array([-2.5, 2, 0])
self.circle_right_pos = np.array([2.5, 2, 0])
self.circle_result_pos = np.array([0, -1, 0])

# 圆半径
self.circle_radius = 1.2

# 扇形角度
self.angle_quarter = PI / 2  # 1/4 = 90度

```

## Scene 5: 通分过程 (35-48秒)

2. **分数等价变换**:
   - `1/2 = 3/6`
   - `1/3 = 2/6`
3. **同分母相加**: `3/6 + 2/6 = 5/6`

### 视觉元素
1. 通分示意图（圆饼重新分割）
2. 变换箭头
3. 分步公式

# 圆饼6等分扇形

## 关键技术点

### 1. 扇形绘制
```python
# 1/4 扇形 (90度)
sector = Sector(
    outer_radius=radius,
    angle=PI/2,
    start_angle=0,
    color=COLOR_PRIMARY,
    fill_opacity=0.7
)
```

### 2. 圆饼分割动画
```python
# 2等分 → 6等分
old_divisions = [Line(...) for _ in range(2)]
new_divisions = [Line(...) for _ in range(6)]
self.play(Transform(old_divisions, new_divisions))
```

### 3. 分数显示
```python
# 避免中文在MathTex中
numerator = MathTex("3")
line = Line(...)
denominator = MathTex("6")
fraction = VGroup(numerator, line, denominator).arrange(DOWN)
```

### 4. 矩形块填充
```python
# 创建矩形网格
blocks = VGroup(*[
    Rectangle(width=w, height=h).shift(...)
    for i in range(5)
])
# 填充前3个
filled = blocks[:3].copy().set_fill(COLOR_PRIMARY, opacity=0.8)
```
