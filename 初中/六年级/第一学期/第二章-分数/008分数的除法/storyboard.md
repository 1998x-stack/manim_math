## 关键技术点

### 1. 分数显示函数
```python
def create_fraction_display(numerator, denominator, color=WHITE, font_size=36):
    num = MathTex(str(numerator), font_size=font_size, color=color)
    line = Line(LEFT*0.3, RIGHT*0.3, color=color)
    den = MathTex(str(denominator), font_size=font_size, color=color)
    return VGroup(num, line, den).arrange(DOWN, buff=0.15)
```

### 2. 翻转动画（倒数）
```python
# 方法1: Transform
fraction_original = create_fraction_display(3, 4)
fraction_flipped = create_fraction_display(4, 3)
self.play(Transform(fraction_original, fraction_flipped))

# 方法2: Rotate with swap
self.play(
    Rotate(fraction, angle=PI),
    # 同时交换分子分母位置
)
```

### 3. 符号变换动画
```python
# ÷ 变成 ×
division_sign = MathTex(r"\div", font_size=40)
times_sign = MathTex(r"\times", font_size=40)
self.play(Transform(division_sign, times_sign))
```

### 4. 强调框/圆圈
```python
# 框住元素
box = SurroundingRectangle(element, color=YELLOW, buff=0.1)
self.play(Create(box))

# 圆圈
circle = Circle(radius=0.5, color=YELLOW).move_to(element)
self.play(Create(circle))
```
