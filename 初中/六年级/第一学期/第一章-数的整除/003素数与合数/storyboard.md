# 素数与合数 - 动画分镜脚本

## 元信息
- **目标时长**: 75-85秒
- **场景数量**: 8个
- **难度等级**: 基础
- **年级**: 六年级
- **知识点**: 素数与合数的定义和识别

## 颜色配置
```python
COLOR_PRIMARY = "#3498db"        # 蓝色 - 主要概念
COLOR_PRIME = "#2ecc71"          # 绿色 - 素数
COLOR_COMPOSITE = "#e74c3c"      # 红色 - 合数
COLOR_SPECIAL = "#f39c12"        # 橙色 - 特殊情况（1）
```

## 核心教学流程
1. **开场钩子** - 数字分组问题
2. **因数回顾** - 快速复习因数
3. **素数定义** - 只有2个因数
4. **素数示例** - 2,3,5,7的可视化
5. **合数定义** - 多于2个因数
6. **合数示例** - 4,6,8,9的可视化
7. **特殊情况** - 1的特殊性，2的特殊性
8. **总结回顾** - 关键要点+关注

## 视觉元素设计
- 用数字卡片展示
- 用方块阵列展示因数分解
- 用颜色区分素数/合数
- 用✓和✗标记
- 用表格汇总

## 关键注意事项

### 1. 视觉化要求
- 数字卡片要大而清晰
- 因数用小字列出
- 方块阵列展示分解
- 颜色对比强烈（绿/红/橙）

### 2. 教学重点
- 素数vs合数的核心区别：因数个数
- 1的特殊性必须强调
- 2的两个特殊性都要讲
- 用视觉帮助理解，不要只用文字

### 3. LaTeX与中文分离
- 数字、公式：MathTex
- 说明文字：Text with "Noto Sans CJK SC"
- 不要混用

### 4. 动画节奏
- 数字卡片出现：0.5秒
- 因数展示：0.5秒每个
- 关键概念停留：1.5-2.0秒
- 例子展示：每个1.0秒

### 5. 互动性
- 最后给出练习题：判断11, 12, 13
- 鼓励学生自己尝试
