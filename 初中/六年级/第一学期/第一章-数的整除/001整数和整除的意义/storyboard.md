### 视觉设计
- 方块: 0.3×0.3 的正方形
- 初始: 4行3列排列
- 分组: 3个组，每组4个，用颜色区分
- 颜色: 
  - 组1: #9b59b6 (紫色)
  - 组2: #f39c12 (橙色)
  - 组3: #3498db (蓝色)

### 坐标计算
```python
# 12个方块的初始位置
squares_positions = []
for i in range(3):  # 3列
    for j in range(4):  # 4行
        x = (i - 1) * 0.5  # 列间距0.5
        y = 3 + (1.5 - j) * 0.5  # 行间距0.5，从y=3开始
        squares_positions.append([x, y, 0])

# 分组后位置
group_positions = [
    LEFT * 2,   # 第1组中心
    ORIGIN,     # 第2组中心
    RIGHT * 2   # 第3组中心
]
```

## 关键注意事项

### 1. 视觉化要求
- 方块阵列必须清晰可见
- 分组动画要流畅
- 颜色对比度要高
- 文字大小适合6年级

### 2. LaTeX与中文分离
- 数学符号: `MathTex`
- 说明文字: `Text` with "Noto Sans CJK SC"
- 不要混用

### 3. 动画节奏
- 分组动画: 1.5-2.0秒
- 方块出现: 每个0.15秒
- 关键概念停留: 2.0秒

- y: [-7, 7]
- 方块不要太小（至少0.25×0.25）

### 5. 教学重点
- 余数为0是关键

- 符号记法要清楚
- 对比能否整除
