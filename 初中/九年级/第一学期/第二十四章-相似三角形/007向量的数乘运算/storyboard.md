# 向量数乘运算 - 动画分镜脚本

## 元信息
- 目标时长: ~75 秒
- 场景数量: 8 个
- 难度等级: 中等（九年级）
- 格式: TikTok 竖屏 1080×1920

## 颜色配置
```
COLOR_BG        = "#1a1a2e"      # 深蓝背景
COLOR_PRIMARY   = "#e94560"      # 红色 - 主向量 a
COLOR_SCALED    = "#00d4ff"      # 青蓝 - λa
COLOR_HIGHLIGHT = "#f5c518"      # 金色 - 高亮/标题
COLOR_AUXILIARY = "#a8a8b3"      # 灰色 - 辅助线/标注
COLOR_TEXT      = "#ffffff"      # 白色正文
COLOR_POS       = "#2ecc71"      # 绿色 - λ>0 标记
COLOR_NEG       = "#e74c3c"      # 红色 - λ<0 标记
COLOR_ZERO      = "#95a5a6"      # 灰蓝 - λ=0 标记
```

## 几何预计算清单
| 元素 | 计算公式 | 存储变量 |
|------|---------|---------|
| 向量a起点 | 原点偏移 | self.O (origin) |
| 向量a终点 | O + a方向 | self.A_end |
| λ=2时终点 | O + 2*a | self.A2_end |
| λ=0.5时终点 | O + 0.5*a | self.Ahalf_end |
| λ=-1时终点 | O + (-1)*a | self.Aneg_end |
| λ=-2时终点 | O + (-2)*a | self.Aneg2_end |

### 核心内容

## Scene 3: λ>0 同向演示 (12s)
**目的**: 动态演示 λ=0.5, 1, 2 时向量同向伸缩

### 核心内容
- 基本向量 a (λ=1)
- λ=2 时：同向，长度2倍
- λ=0.5 时：同向，长度半倍
- ValueTracker 动态演示

### 核心内容
- λ=-1 时：反向，等长
- λ=-2 时：反向，长度2倍
- 关键结论突出
