# 《比例线段》教学分镜与验收记录

源文件：`proportional_segments.py`；Scene：`ProportionalSegments`。适用九年级上学期第二十四章。目标视频为 9:16、1080×1920，逻辑画面宽 9、高 16。本表描述**当前修复分支的代码**，不是旧 MP4 的实际镜头记录。原作者标识保留在片头与片尾；六个教学环节的顺序不变。

## 数学规格与数据源

- 所有线段长度均为有限正数，比例 `a/b=c/d` 的分母不为 0；本课使用 `(a,b,c,d)=(2,3,4,6)`，因此 `2/3=4/6` 且 `ad=bc=12`。
- 比例中项使用 `(a,b,c)=(2,4,8)`，由 `b=√(ac)>0` 算得 `b=4`、`b²=ac=16`，不得只由 `b²=ac` 忽略线段长度的正值条件。
- 合比公式 `(a+b)/b=(c+d)/d` 和等比公式 `(a+c)/(b+d)=a/b=c/d` 均以本课四条正长度为前提；由 `b,d>0` 推出 `b+d>0`，不存在零分母。
- `valid_proportion` 与 `proportional_mean` 是不依赖 Manim 的数学函数。`tools/tests/test_grade9_proportions.py` 验证正常例、反例、零分母、负长度与非有限输入。
