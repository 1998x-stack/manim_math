### 场景3: 测量建筑物高度
建筑物底部B在地面，顶部T在B正上方。
人站在地面点P处，人头顶E在P正上方。
日影：建筑物影子端点S，人影端点S'。
太阳光线平行 → ∠BTS = ∠PES (同位角相等) → △BTS ∽ △PES (AA相似)

坐标设计 (以地面为x轴):
- B = (-2, -2, 0)  建筑物底部
- T = (-2, 3, 0)   建筑物顶部  (高度5)
- S = (1, -2, 0)   建筑物影子端点 (影长3)
- P = (0.5, -2, 0) 人的位置
- E = (0.5, -1, 0) 人的头顶  (人高1)
- S'= (1, -2, 0)   人影端点 (与建筑影子端点重合 - 同一太阳角度)

验证: 太阳角度 = arctan(5/3) for building, 人影长 = 1 * 3/5 = 0.6
所以 S' = (0.5 + 0.6, -2, 0) = (1.1, -2, 0)
不对，需要统一太阳角度。

重新设计:
太阳角度 θ (与地面的夹角): tan(θ) = 高度/影长
建筑物高 h = 5, 影长 L = 3, tan(θ) = 5/3
人高 h' = 1, 人影长 L' = h'/tan(θ) = 1 * 3/5 = 0.6

统一设计:
- B = (-1.5, -2, 0)  建筑物底部
- T = (-1.5, 3, 0)   建筑物顶部 (高5)
- S = (1.5, -2, 0)   建筑物影子端点 (影长3)
- P = (0.7, -2, 0)   人的位置
- E = (0.7, -1, 0)   人的头顶 (人高1)  
- S' = (1.3, -2, 0)  人影端点 (影长0.6)

大三角形: T-B-S (顶点T, 直角B, 影端S)
小三角形: E-P-S' (顶点E, 直角P, 影端S')

### 场景5: 测量河流宽度
河流宽度无法直接测量。在河岸一侧构造相似三角形。

A点在河对岸，B点在本岸河边正对A。
在本岸选点C，使BC⊥AB。
再选D在BC延长线上，使BD = 2*BC (或某比例)。
过D作DE∥AB，在DE上找E使得C、A、E三点共线。
则 △ABC ∽ △DEC → AB/DE = BC/DC

坐标设计:
- A = (-1, 2.5, 0)   对岸点 (河对岸)
- B = (-1, -0.5, 0)  本岸河边 (AB为河宽, AB⊥地面方向)
- 河宽 AB = 3
- C = (1.5, -0.5, 0) BC⊥AB, BC = 2.5
- D = (4, -0.5, 0)   BD上的点, DC = BC = 2.5, BD = 5

验证: △ABC ∽ △DEC (AA)
- ∠ABC = ∠EDC = 90° (BC⊥AB, DC⊥DE)
- ∠ACB = ∠ECD (对顶角)
所以 AB/DE = BC/DC = 2.5/2.5 = 1 → DE = AB = 3

E点: 过D作DE∥AB, DE = 3
D = (4, -0.5, 0), DE方向与AB平行 (AB是竖直的)
E = (4, 2.5, 0)

验证C-A-E共线:
C = (1.5, -0.5), A = (-1, 2.5), E = (4, 2.5)
CA方向: (-2.5, 3)
CE方向: (2.5, 3)  
不共线！需要修改。

重新设计: 用更标准的方法
让 BC = 2, DC = 2 (即C是BD中点)
则 AB/DE = BC/DC = 1, DE = AB

或者用比例 BC:DC = 1:1 太简单。让用 BC = 2, DC = 4
则 AB/DE = BC/DC = 2/4 = 1/2, DE = 2*AB

好，换一种经典构造:
- A在对岸
- B在本岸对A
- 从B沿河岸走到C
- 在C处，找D使得 BC = CD (C是BD中点)  
- 连接AD，延长交BC延长线的垂线于E
- 则 △ABC ∽ △EDC

实际用更简单的标准方法:
A对岸, B本岸对岸, C在本岸使BC已知
在C处测量∠BCA，在D处测量∠BDA
用正弦定理求AB

太复杂了，回到经典构造:

方法: 在河岸同侧
- B在河边, A在对岸
- 沿河岸走到C (BC可测)  
- 在C处转向远离河的方向到D (CD⊥BC, CD可测)
- 连DA, 在DA上找点E使得CE⊥DA
- ...

最简经典法:
A对岸点, B本岸对A点
沿岸从B走到C (BC = a, 已测)
过C画CD⊥BC, CD = b (已测)  
连AD
过B画BE∥CD交AD于E
则 △BEA ∽ △DCA (AA相似: ∠BAE=∠DAC公共角, ∠BEA=∠DCA=90°)
→ AB/AC = BE/DC = BA/DA ... 

让我用最直接清晰的经典方法:

**对岸测距经典法（三角形相似）**:
1. 对岸树木A, 本岸河边B, 沿河岸到C使BC⊥河岸(即BC⊥AB)
2. 在BC延长线上取D, 使C为BD中点 (BC = CD)  
3. 过D作DE⊥BD交CA延长线于E
4. 则 △BCA ∽ △DCE (∠BCA = ∠DCE对顶角, ∠ABC = ∠CDE = 90°)
5. BC = CD → AB = DE, 只需测DE即可得AB

坐标:
- B = (0, 1, 0) 本岸河边
- A = (0, 4, 0) 对岸 (河宽AB = 3, 竖直方向)
- C = (2, 1, 0) BC⊥AB (水平), BC = 2
- D = (4, 1, 0) CD = BC = 2, C为BD中点
- DE⊥BD (竖直向下), DE = AB = 3
- E = (4, -2, 0)

验证三点共线 C-A-E:
C = (2,1), A = (0,4), E = (4,-2)
CA方向: (-2, 3)
CE方向: (2, -3) = -1 * (-2, 3) ✓ 共线！
