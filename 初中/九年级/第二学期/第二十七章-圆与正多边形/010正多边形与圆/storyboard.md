# 正多边形与圆 - 动画分镜脚本

## 元信息
- 目标时长: 70-80 秒
- 场景数量: 6 个
- 难度等级: 九年级中等
- 核心公式: 中心角 = 360°/n, S = (1/2)×n×a×r

## 颜色配置
```python
BACKGROUND = "#1a1a2e"
COLOR_POLYGON = "#4fc3f7"      # 浅蓝色 - 正多边形
COLOR_CIRCLE = "#ffb300"       # 金黄色 - 外接圆
COLOR_CENTER = "#ff4757"       # 红色 - 中心点O
COLOR_RADIUS = "#2ed573"       # 绿色 - 外接圆半径R
COLOR_APOTHEM = "#ff6b81"      # 玫红色 - 边心距r
COLOR_ANGLE = "#a29bfe"        # 紫色 - 中心角
COLOR_SIDE = "#ffeaa7"         # 淡黄 - 边长a
COLOR_FORMULA = WHITE
COLOR_TITLE = GOLD
COLOR_TEXT = GRAY_A
AUTHOR_COLOR = GRAY_B
```

## 几何预计算清单

| 元素 | 计算公式 | 存储变量 |
|------|---------|---------|
| 正六边形顶点 | R*(cos(k*60°), sin(k*60°)) | self.hex_vertices |
| 正六边形中心 | (0, 0) | self.center |
| 正六边形边心距 | R * cos(π/n) = R * cos(30°) = R*√3/2 | self.apothem |
| 中心角 | 360°/6 = 60° | self.central_angle |
| 正四边形（演示）| n=4, 中心角=90° | self.square_vertices |
| 正三角形（演示）| n=3, 中心角=120° | self.tri_vertices |

## Scene 2: 认识核心元素 (10-12秒)

2. 中心点O (Dot)
3. 外接圆半径 R (DashedLine)
4. 边心距 r (DashedLine 到边中点)
5. 中心角弧线 (Angle)
6. 各元素标签

### 动画序列
| 时间 | 动作 |
|------|------|

| 2.5s | 边心距虚线 + "边心距 r" |
| 3.5s | 中心角弧 + "中心角" |

### 清理
- FadeOut: 标题，部分标签

## Scene 5: 面积公式推导 (15-18秒)
**目的**: 推导 S = (1/2) × n × a × r

### 元素
1. 正六边形分割为6个等腰三角形
2. 一个三角形高亮 + 标注底边a、高r
3. 面积公式逐步展示

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 标题 "正多边形面积公式" |
| 0.6s | 从中心向每个顶点连线（分割图形）|
| 1.8s | 高亮一个三角形 |
| 2.5s | 标注: 底 = a (边长), 高 = r (边心距) |
| 3.5s | 单个三角形面积 = (1/2) × a × r |
| 5.0s | 共n个三角形 |
| 6.0s | S = n × (1/2) × a × r |
| 7.5s | = (1/2) × na × r = (1/2) × 周长 × r |
| 9.0s | 框选最终公式 |
| 10.0s | 停顿理解 |
