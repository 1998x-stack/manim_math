## 元信息
- 目标时长: 60-75 秒
- 场景数量: 6 个
- 难度等级: 初中入门
- 年级: 七年级第一学期

## 颜色配置
```python
COLOR_PRIMARY = "#3498db"      # 蓝色 - 主要项
COLOR_SECONDARY = "#e74c3c"    # 红色 - 次要项
COLOR_HIGHLIGHT = YELLOW       # 黄色 - 高亮
```

## 核心概念结构
本动画无需几何计算，主要使用代数式的视觉化表示：
- 使用 MathTex 展示代数式
- 使用 SurroundingRectangle 标识同类项
- 使用 Transform 展示合并过程
- 使用颜色编码区分不同部分（系数 vs 字母）

## 颜色使用策略
- **系数**: 绿色框/高亮 - 强调"数字相加"
- **字母和指数**: 紫色框 - 强调"保持不变"
- **同类项组**: 不同颜色的边框 (蓝/红/橙等)
- **正确答案**: 金色/绿色边框
- **错误示例**: 红色叉号

## 动画节奏控制
- 定义讲解: 稍慢 (1.0-1.5s per step)
- 判断示例: 中速 (0.6-0.8s per example)
- 合并演示: 慢速 (1.2-1.8s per step) - 关键步骤
- 总结: 快速 (0.6-0.8s per point)

## 特殊效果
1. **Flash**: 用于正确答案的✓和错误的✗
2. **Transform**: 用于代数式的合并动画
3. **SurroundingRectangle**: 用于框选同类项
4. **Arrow**: 用于指示变换方向
5. **Brace**: 用于标注系数部分

## 教学重点
1. **定义清晰**: "字母相同" + "指数相同"
2. **常数项特殊性**: 所有常数都是同类项
3. **合并法则**: 系数相加，字母不变
4. **视觉强化**: 用颜色区分系数和字母部分
