## 元信息
- 目标时长: 60-75秒
- 场景数量: 7个
- 难度等级: 初级（七年级）
- 目标受众: 初中一年级学生

## 颜色配置
```python
COLOR_ALGEBRAIC = "#3498db"      # 蓝色 - 代数式
COLOR_MONOMIAL = "#e74c3c"       # 红色 - 单项式
COLOR_POLYNOMIAL = "#2ecc71"     # 绿色 - 多项式

```

## 几何预计算清单
本动画主要使用文本和公式，不涉及复杂几何计算。
主要元素位置规划：
- 标题区域: y ∈ [5.5, 7]
- 主内容区: y ∈ [-3, 5]
- 解释文字区: y ∈ [-5, -3]

## Scene 1: 开场钩子 (5秒)
**目的**: 吸引注意力，引出主题

### 元素
1. 作者标识 (顶部)
2. 钩子问题（大字）
3. 悬念式的代数式示例

### 动画序列
| 时间 | 动作 | 代码参考 |
|------|------|---------|
| 0.0s | 作者信息淡入 | `FadeIn(author_info, shift=DOWN*0.2)` |
| 0.3s | 钩子文字快速书写 | `Write(hook_text, run_time=0.6)` |
| 1.0s | 神秘代数式闪现 | `FadeIn(mysterious_expr, scale=1.2)` |
| 2.0s | 代数式旋转变化 | `Rotate` + `Transform` |
| 3.5s | 提问文字 | `Write(question)` |
| 4.5s | 等待 | `Wait(0.5)` |

### 清理
- FadeOut: hook_text, mysterious_expr, question
- 保留: author_info

## 关键动画技巧
1. **文字书写**: 使用 `Write()` 配合适当 run_time
2. **公式变换**: 使用 `TransformMatchingTex()` 实现平滑过渡
3. **高亮强调**: 使用 `Indicate()`, `Flash()`, `SurroundingRectangle()`
4. **分步展示**: 控制 run_time 和 Wait 时间，让学生有思考时间
5. **颜色编码**: 一致使用颜色区分概念（系数-橙色，次数-紫色）

---

## 节奏控制
- 开场要快速抓住注意力（5秒内）
- 定义部分要清晰缓慢（8-10秒每个概念）
- 示例要有足够停留时间（1.5-2秒）
- 总结要简洁有力（8-10秒）
- 总时长控制在60-75秒
