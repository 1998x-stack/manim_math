# 整式的乘法｜可核验分镜（七年级第一学期第九章 005）

Scene 入口：`polynomial_multiplication.py::PolynomialMultiplication`；竖屏 1080×1920，逻辑画幅 9×16。课程共七个镜头，原有 MP4 和讲解音轨不参与此次源码修复。

## 数学契约

| claim | assumptions / justification | edge case / unit test |
|---|---|---|
| `(2x)(3x²)=6x³` | 结合律、交换律和同底数幂指数相加，系数 2×3=6、指数 1+2=3 | x=0、x<0、x>0 逐值检验 |
| `a(b+c)=ab+ac` | 乘法分配律，每个加数都要乘到 | 常数为 0 或负数；`2x(3x+4)=6x²+8x` |
| `(a+b)(c+d)=ac+ad+bc+bd` | 两次分配律，每个行因子分别乘每个列因子 | 负号不能丢；纯 Python 升幂系数卷积含负系数测试 |
| `(x+2)(x+3)=x²+5x+6` | 四格分别为 x²、3x、2x、6；3x+2x=5x | 数值代入及 `[2,1]*[3,1]=[6,5,1]` 系数卷积 |

课内检查 `python verify_lesson.py` 不导入 Manim，能证实数学样例与源代码结构，不能代替实际图形/文字的渲染检查。

## 逐镜头追踪

| 镜头 | 教学目标与数学结论 | 屏上对象与生命周期 | 关键帧验收 |
|---|---|---|---|
| 1 开场 | 三种整式乘法 | `expressions` 三个式子依次显示，`clear_content()` 清理 | 三式可同时阅读，作者标签不遮挡标题 |
| 2 单×单 | `2×3=6`、`x¹x²=x³` | `problem`, `coefficient`, `powers`, `result`, `note` 依次显示 | 指数为 3，不是 2；公式居中 |
| 3 单×多 | `2x(3x+4)=6x²+8x` | 抽象公式、两个分配律分项、最终答案 | 3x 与 4 都被乘到，8x 没有漏掉 x |
| 4 多×多引入 | 两项乘两项共有四个乘积 | `(a+b)(c+d)` → 完整展开式及不漏项提示 | 四项符号正确 |
| 5 四格法 | `ac`, `ad`, `bc`, `bd` | `product_grid` 建两个行因子、两个列因子、四个有独立矩形与 MathTex 标签的 `cell`，按行依次显示 | 2×2 恰有四格，行/列乘积与格内字母一致 |
| 6 具体例题 | 四项相加后合并 `3x+2x` | 与镜头 5 共用网格构造逻辑，行 `x,2`，列 `x,3`，四格 `x²,3x,2x,6` | 四格与结果 `x²+5x+6` 对应一致 |
| 7 总结 | 三条规则及分配律 | 三张 `RoundedRectangle` 卡片，最后文字回顾；清理作者标签 | 卡片不重叠、中文始终正向、最终画面清屏 |

`clear_content()` 只淡出 `Scene.mobjects` 内实际显示的对象，作者标签使用同一引用留到最后一镜；不对未加入 Scene 的临时对象调用 `FadeOut`。可见网格和数学测试使用一致的四项次序：行 0 列 0、行 0 列 1、行 1 列 0、行 1 列 1。
