# 完全平方公式｜逐镜数学与画面契约（第九章 007）

入口：`perfect_square_formula.py::PerfectSquareFormula`；竖屏 1080×1920、逻辑画幅 9×16；保留既有视频，不把旧成片作为此次修复证据。

## 数学契约

| claim | 前提、证明及显示数据 | 边界与反例 |
|---|---|---|
| `(a+b)²=a²+2ab+b²` | 对任意实数成立；分配律得到 `a²+ab+ab+b²` | 仅写 `a²+b²` 在 ab≠0 时是错误的；对负数和零进行代入检验 |
| `(a−b)²=a²−2ab+b²` | 对任意实数成立；分配律得到 `a²−ab−ab+b²` | 两次相减的交叉项为负，但末项 `b²` 仍为正 |
| 正方形面积四分块 | 绘图专用 a>0、b>0：总边长 a+b；左上 a×a、右上 b×a、左下 a×b、右下 b×b | `square_regions(a,b)` 对零、负数、非有限值报错；四块总面积应等于 `(a+b)²` |
| `(x±3)²=x²±6x+9` | 直接代入两个代数恒等式，不依赖正边长几何图 | x=0、负数与正数均应成立 |

`verify_lesson.py` 独立抽取并执行 `square_regions` 模型，校验四块尺寸、同边相接、覆盖整块正方形、面积总和、非法参数及正负代数取值；静态测试不等于实际 Manim 画面验收。

## 七镜头与对象生命周期

| 镜头 | 数学结论 | actual scene object / 数据流 | 必检关键帧 |
|---|---|---|---|
| 1 提问 | 平方和不能漏交叉项 | `title`,`question`,`hint`；`clear_content()` 后只保留作者标记 | 标题和公式安全区 |
| 2 代数展开 | 正、负完全平方公式各自的两次交叉乘积 | 四条 MathTex 公式独立行显示、全屏清理 | 两条证明的中间项正负号与 b² 符号 |
| 3 正方形 | 边长 a+b；面积 `(a+b)²` | `big_square` 使用 `spec["side"]`，`big_side_label` 与大框保留到分割 | 边长标注位置、整体宽度 |
| 4 分割 | 垂直、水平分割点分别位于左端 a 与底端 b 处 | `vertical_split`,`horizontal_split` 使用 `spec["x_split"]`,`spec["y_split"]`，不手填派生点 | 两条分割线准确贯穿正方形，标签不遮挡 |
| 5 四区域 | a²、ab、ab、b² 恰好填满 | 遍历 `spec["cells"]` 各自创建 `Rectangle` 与 `MathTex`；位置由尺寸与左下角坐标计算 | 四块无重叠和缝隙，两个 ab 独立可见 |

| 7 练习及退场 | `(x+3)²` 与 `(x−3)²` | 两条例题与正边长几何图的适用范围说明，最后清屏 | 对所有实数 x 成立；无倒转中文字、残留对象 |
