## Scene 2: 性质1 - 同乘不为零的整式 (5-18s)
**目的**: 用动画演示 A/B = (A×C)/(B×C)

### 核心公式
```
  A         A × C
─────  =  ─────────   (C ≠ 0)
  B         B × C
```

### 动画序列
| 时间   | 动作                                                  |
|--------|-------------------------------------------------------|
| 5.0s   | 标题 "性质1：同乘不为零的整式"                       |
| 5.5s   | 显示 A/B（左侧）                                      |
| 6.2s   | 箭头 → 指向右侧                                       |
| 6.8s   | 显示 (A×C)/(B×C)（右侧）                             |
| 7.8s   | 分别用彩色框标注分子×C、分母×C                       |
| 9.0s   | 条件标注: C ≠ 0（红色高亮）                          |
| 10.0s  | 具体例子1: x/(x+1) → 2x / (2(x+1))（C=2）           |
| 12.0s  | 具体例子2: a/b → a(b+1) / (b(b+1))（C=b+1）         |
| 14.5s  | 等号验证✓ + 强调"分式的值不变"                       |
| 16.5s  | 等待                                                  |
