## Scene 4: 例题1（正常解）(18~34s)
**目的**: 完整演示三步解法，结果有效

### 题目
$$\frac{1}{x-1} = 2$$

### 步骤
1. **原式** → 最简公分母 = (x-1)
2. **去分母**：两边×(x-1) → 1 = 2(x-1)
3. **整理**：1 = 2x-2 → 2x = 3 → x = 3/2
4. **检验**：x=3/2 时，x-1 = 1/2 ≠ 0 ✅

---

## Scene 5: 例题2（增根陷阱！）(34~54s)
**目的**: 核心教学点——增根的发现与处理

### 题目
$$\frac{x}{x-1} = \frac{1}{x-1} + 2$$

### 步骤
1. **原式** → 最简公分母 = (x-1)
2. **去分母**：x = 1 + 2(x-1)
3. **整理**：x = 2x-1 → x = 1
4. **检验**：x=1 时，x-1 = **0** ❌ 分母为零！
5. **结论**：x=1 是增根，此方程**无解**

### 动画高潮：检验失败的戏剧性处理
- 红色 ✗ 大叉
- 分母变红 + 闪烁
- "增根！舍去！"文字震动入场
