## Scene 5: 异分母例题 (34~52s)
**目的**: 步步演示，含通分全过程

### 例题
$$\frac{1}{x} + \frac{2}{x+1}$$

### 步骤
1. 原式（两个分母不同）
2. 找LCD = x(x+1)
3. 化同分母：(x+1)/[x(x+1)] + 2x/[x(x+1)]
4. 分子相加：(x+1+2x) / [x(x+1)]
5. 合并同类项：(3x+1) / [x(x+1)]（最简结果）

## Scene 6: 括号陷阱 (52~62s)
**目的**: 重点警示！多项式分子减法必须加括号

### 例题（陷阱版 vs 正确版）
$$\frac{2}{a-1} - \frac{a-2}{a-1}$$

**❌ 错误**: 2/(a-1) - (a-2)/(a-1) = (2 - a - 2)/(a-1)
**✅ 正确**: = (2-(a-2))/(a-1) = (2-a+2)/(a-1) = (4-a)/(a-1)

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 警告标题（红色/橙色）⚠️ |
| 0.5s | 原式 Write |
| 1.5s | 错误做法（红叉）|
| 3.0s | 正确做法（绿勾+括号高亮） |
| 5.0s | "分子是多项式，减法要加括号！" |
| 6.0s | Wait 2.0s |
