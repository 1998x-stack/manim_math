## 核心教学逻辑
通分三步走：
  Step 1 → 因式分解各分母
  Step 2 → 找最简公分母 LCD（各因式最高次幂之积）
  Step 3 → 分子分母同乘补充因式 → 统一分母

## Scene 3: 核心例题一 1/x + 1/(x+1) (13-31s)
**目的**: 最简情形，分母已是最简，LCD = x(x+1)

### 动画序列
| 时间   | 动作                                                        |
|--------|-------------------------------------------------------------|
| 13.0s  | "② 例题：1/x + 1/(x+1)"                                  |

| 14.3s  | Step1: 分母已是最简，无需分解                               |
| 15.2s  | Step2: LCD 推导动画                                         |

|        | 1/x → 分子分母 ×(x+1) → (x+1)/x(x+1)                     |

## Scene 4: 进阶例题 1/(x²-1) + 1/(x+1) (31-46s)
