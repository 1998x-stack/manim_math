## 技术要点

### 角度弧线绘制
```python
# 使用 Angle 对象精确绘制角度弧线
angle_arc = Angle(line1, line2, radius=0.5, other_angle=False)
```

### 公共边标记
```python
# 邻补角的公共边高亮
common_edge = Line(O, point_on_line, stroke_width=6, color=COLOR_HIGHLIGHT)
```

### 平角动画
```python
# 展示两个邻补角合并成平角 (180°)
straight_angle = Arc(start_angle=0, angle=PI, radius=0.8)
```

### 数值标注定位
```python
# 角度数值标注在角平分线方向
bisector_direction = normalize(vec1 + vec2)
```
