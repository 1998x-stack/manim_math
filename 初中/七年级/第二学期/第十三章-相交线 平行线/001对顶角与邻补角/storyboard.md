# 对顶角与邻补角｜同源几何七镜分镜

Scene 入口：`vertical_and_adjacent_angles.py::VerticalAndAdjacentAngles`。画布：1080×1920、逻辑坐标 9×16；此文档对应该脚本现行七镜，不采用历史路径下旧 MP4 作为新脚本验证依据。

## 可检验的几何定义

交点 `O=(0,1.1)`。两条直线方向分别为 `30°` 和 `-40°`，其四条射线按顺时针顺序为 `30°、-40°、210°、140°`。第 i 个角的弧线起点是第 i 条射线，终点是下一条射线，有向弧度：`sweep = (end-start+π) % (2π) - π`。实际四个 sweep 依次为 `-70°、-110°、-70°、-110°`，绝对值即屏上的角度 `70°、110°、70°、110°`。每个标签放在 `start+sweep/2` 方向，并以交点为中心偏移，从而对应**同一短角**；不能在数值为 70° 的角处画出 290° 的优角。

对顶角：`∠1=∠3=70°`、`∠2=∠4=110°`；邻补角：`∠1+∠2=180°`，角的两条非公共边互为反向延长线。邻补角需共顶点、共边；只验证数值和为 180° 不足以证明它们是邻补角。
