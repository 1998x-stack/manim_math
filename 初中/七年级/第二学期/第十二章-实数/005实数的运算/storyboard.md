## 数学规格

实数加减满足常规运算律；根式先化简，再合并相同根式（例如 `√2+√8=3√2`）。实数范围内 `√a√b=√(ab)` 需要 `a≥0,b≥0`，`√a/√b=√(a/b)` 需要 `a≥0,b>0`。对任意实数 a、`b≥0`，正确的化简公式是 `√(a²b)=|a|√b`，不能未经 `a≥0` 条件就写成 `a√b`。负数因子提出根号时特别检查绝对值。比较 `√10` 与 3 可由 `10>9` 得出，有限小数只用作近似，不冒充证明。

## 分镜与关键检查

| 分镜 | 数学命题与画面 | 本课检查 |
| --- | --- | --- |
| opening | 边长 1 的正方形示意及对角线 `d=√2` | 正方形对角线由实际两角连接，边长和单位说明清楚 |
| add_sub | `√2+√8=√2+2√2=3√2`，`√2+√3` 不能合并 | 不再笼统声称根号内不同就无法合并 |
| mul_div | 乘法两个非负被开方数；除法分母被开方数严格为正 | 分母非零、实际数值和条件同屏 |
| simplify | `√8`、`√18` 及通用 `√(a²b)=|a|√b` | 检查 `a=-3,b=2`，提出根号的系数不能为 -3 |
| abs_value | `|√2-1|`、`|3-√10|`、`|-√5|` | 用非负性与平方比较确定括号内正负 |
| laws | 交换、结合、分配律 | 字母均为实数，含根式/分母时另验定义域 |
| combined | `(√3+√2)(√3-√2)=1` 与 `√2√8+√3√3=7` | 中间算式、结论与实际数值一致 |
| outro | 先化简、定义域、绝对值总结 | 重点提示 `|a|` 而不是无条件 a |
