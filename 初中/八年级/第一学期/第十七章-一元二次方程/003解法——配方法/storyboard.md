# 003 配方法｜八镜可核验分镜

- 源码 `completing_the_square.py`，实际 Scene `CompletingTheSquare`，原八个 show_* 方法名保留，目标竖屏 1080×1920、逻辑 9×16。源 `description.json` 是数学规格线索，屏上公式与现有源码、测试相互核对。
- 代数模型：`ax²+bx+c=0 (a≠0)`，两边除以 a 得 `x²+px+q=0`，其中 `p=b/a,q=c/a`；两边加 `(p/2)²` 得 `(x+p/2)²=(p/2)²-q`。右侧为正有两个互异实数根，为零一个互异实数根，为负无实数根。
- 几何图只对正长度 x、3 给出面积分块示意；恒等式 `(x+3)²=x²+6x+9` 对所有实数成立。取 x=2 时四块面积 4、6、6、9，总面积 25，正方形整体边长 5。原四块均为相同边长正方形的显示违背面积比例，必须由统一缩放的 x 与 3 决定实际宽高。

| 方法 / 镜头 | learning_fact 与屏幕状态 | check / 关键帧 |
|---|---|---|
| 1 `show_opening` | 从 `x²+6x+5=0` 移项为 `x²+6x=-5`，提出一次项系数一半为 3 | 不在不配方时对整个左式开平方，方程两边保持等价 |
| 2 `show_perfect_square_review` | `(a+b)²=a²+2ab+b²`，`(x+3)²=x²+6x+9` | 中间项是 2·x·3，补 9 而非 3 |
| 3 `show_geometry_visualization` | `x=2` 面积图的 x²、3x、3x、9 分别对应四块宽高为 x×x、3×x、x×3、3×3，组合为大正方形 | `area_tiles(2,3,.67)` 给出统一比例边长 1.34、2.01 及面积比 4:6:6:9；四块严格无缝拼合；字幕说明 x>0 的图例与对任意实数成立的代数式之区别 |
| 4 `show_method_steps` | 系数化 1、移项、两边加一次项系数一半的平方、检查平方右侧符号 | 不在未入场对象上直接 `.animate.shift`；四张独立步骤卡排布和清场准确 |
| 5 `show_example_1` | `x²+6x=-5` → `x²+6x+9=4` → `(x+3)²=4` → `x=-3±2=-5,-1` | 原方程两根代入为 0；`complete_parameters(1,6,5)==(3,4)` |
| 6 `show_example_2` | `2x²-8x+3=0` → `x²-4x=-3/2` → `(x-2)²=5/2` → `x=2±√(5/2)` | `complete_parameters(2,-8,3)==(-2,2.5)`；两根代入残差容差 1e-12 |
| 7 `show_applications` | `y=x²+6x+5=(x+3)²-4`，顶点 (-3,-4)，抛物线开口向上，最小值 -4 | 平移方向、顶点与公式一致，文字不遮挡卡片 |
| 8 `show_summary` | 总结配平方公式及正、零、负三种根数情况，最后独立移除作者水印 | MathTex 不放中文；一次 `_clear()` 只对当前顶层对象创建单次 FadeOut |

## 验收等级

- 数学：`python -m unittest test_completing_square_math.py -v` 覆盖代数系数、零/正/负右侧、两组实际根、正长度面积块的面积恒等式及相同比例；不把 x>0 的面积示意当作任意负 x 的几何证明。
- 静态：`python -m py_compile completing_the_square.py` 和 Skill `scripts/audit_scene.py`。先核对原真实 Scene 名，不使用不存在的通用几何测试。
- 媒体：需实际 Manim 预览检查四块位置/边界、公式字体、首尾帧、对象生命周期及 9×16 安全区；产片后 ffprobe 和音轨审查。未经实渲染不得覆盖原 MP4、prompt、音轨，静态 CI 不代表完成视频验收。
