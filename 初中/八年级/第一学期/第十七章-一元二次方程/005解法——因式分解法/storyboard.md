# 一元二次方程 - 因式分解法 | 动画分镜脚本

## 元信息
- **目标时长**: 60-75 秒
- **场景数量**: 7 个
- **难度等级**: 初中八年级
- **目标受众**: 初中生（需要简洁易懂的语言）

## 核心教学流程
1. 钩子问题 → 引起兴趣
2. 零因式定理 → 理论基础
3. 因式分解步骤 → 具体操作

5. 验证答案 → 巩固理解

7. 片尾关注 → 引导互动

## Scene 4: 应用零因式定理 (25-35秒)
**目的**: 从因式到解

### 元素
1. 因式分解后的方程

### 动画序列
| 时间 | 动作 | 代码参考 |

| 6.0s | 分支2 | x-3 = 0 单独显示右侧 |
| 7.0s | 求解2 | x = 3 (绿色) |
| 8.5s | 答案汇总 | 两个解合并 |
| 9.5s | 等待 | `Wait(0.5)` |

### LaTeX 公式
```python

```

### 清理

## 关键注意事项

### LaTeX 编译
- ✅ 使用原始字符串: `r"..."`
- ✅ 中文用 `Text()` 而非 `MathTex()`
- ✅ 乘号用 `\times` 不用 ×
- ✅ 度数用 `^\circ` 不用 °

### 边界安全
- 主内容区: y ∈ [-3, +5]
- 标题区: y ∈ [+5.5, +7]
- 说明区: y ∈ [-6, -3]
- 横向: x ∈ [-4, +4]

### 动画节奏
- 简单变换: 0.5-0.8s
- 复杂变换: 1.0-1.5s
- 理解停顿: 1.0-2.0s
- 关键步骤: 2.0-3.0s
