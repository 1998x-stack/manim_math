## 正方形坐标精确计算

### 三角形布局
- C (直角顶点): (-0.9, -1.5, 0)
- A (a边终点): (0.9, -1.5, 0)  → CA = 1.8 (横边=a)
- B (b边终点): (-0.9, 0.9, 0)  → CB = 2.4 (竖边=b)
- 验证: c = sqrt(1.8²+2.4²) = sqrt(3.24+5.76) = sqrt(9) = 3.0 ✓

### 在a边外侧构造正方形 (向下展开)
- C = (-0.9, -1.5, 0)
- A = (0.9, -1.5, 0)
- 向外方向: 从CA向下(y负方向) → (0, -1, 0)
- sq_a = [C, A, A+(0,-1.8,0), C+(0,-1.8,0)]
- sq_a = [(-0.9,-1.5,0), (0.9,-1.5,0), (0.9,-3.3,0), (-0.9,-3.3,0)]

### 在b边外侧构造正方形 (向左展开)
- C = (-0.9, -1.5, 0)
- B = (-0.9, 0.9, 0)
- 向外方向: 从CB向左(x负方向) → (-1, 0, 0)
- sq_b = [C, B, B+(-2.4,0,0), C+(-2.4,0,0)]
- sq_b = [(-0.9,-1.5,0), (-0.9,0.9,0), (-3.3,0.9,0), (-3.3,-1.5,0)]

### 在c边(斜边AB)外侧构造正方形
- A = (0.9, -1.5, 0)
- B = (-0.9, 0.9, 0)
- AB向量 = (-1.8, 2.4, 0), 长度 = 3.0
- 外法向量(向右上) = (2.4, 1.8, 0) / 3.0 = (0.8, 0.6, 0)
- A_ext = A + 3.0*(0.8,0.6,0) = (0.9+2.4, -1.5+1.8, 0) = (3.3, 0.3, 0)
- B_ext = B + 3.0*(0.8,0.6,0) = (-0.9+2.4, 0.9+1.8, 0) = (1.5, 2.7, 0)
- sq_c = [A, B, B_ext, A_ext]
