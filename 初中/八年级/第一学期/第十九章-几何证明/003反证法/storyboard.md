# 反证法 (Proof by Contradiction) - 动画分镜脚本

## 元信息
- 目标时长: 60-70 秒
- 场景数量: 6 个
- 难度等级: 中等（八年级）
- 格式: TikTok 竖屏 1080×1920

## 颜色配置
```python
BG_COLOR = "#1a1a2e"
```

## Scene 3: 三步骤图解 (15秒)
**目的**: 详细展示反证法的三个步骤，带流程图

### 布局
```
    [步骤1]
    假设结论不成立 (¬P)
         ↓
    [步骤2]  
    逻辑推理... → 矛盾！(×)
         ↓
    [步骤3]
    ∴ 原结论成立 (✓)
```

### 元素
1. 三个步骤框 (RoundedRectangle)
2. 连接箭头
3. 矛盾闪烁效果
4. 对勾/叉

### 动画序列
| 时间 | 动作 |
|------|------|
| 0-2s | 步骤1框动画出现 + 文字 |
| 2-3s | 箭头向下延伸 |
| 3-6s | 步骤2框 + 推导文字 + 闪烁矛盾 |
| 6-7s | 箭头向下 |
| 7-10s | 步骤3框 + 结论成立 + 对勾 |
| 10-15s | 整体高亮回顾 + 等待 |

---

## Scene 4: 例题演示 (25秒)
**目的**: 用具体例子展示反证法过程

### 例题选择
题目: 证明 "若 n² 是偶数，则 n 也是偶数"

### 步骤展示
1. 展示题目
2. Step1: 假设 n 是奇数
3. Step2: 设 n=2k+1, 则 n²=4k²+4k+1=2(2k²+2k)+1 → 奇数
   → 与"n²是偶数"矛盾！
4. Step3: ∴ n 必然是偶数 ✓

### 动画序列
| 时间 | 动作 |
|------|------|
| 0-2s | 题目出现 |
| 2-5s | 【Step1】假设 n 是奇数 (红色) |
| 5-12s | 【Step2】代入推导，公式动画，矛盾出现 |
| 12-16s | 矛盾闪烁×，强调 |
| 16-20s | 【Step3】结论成立 √ |
| 20-25s | 总结等待 |
