## Scene 4: 3-4-5 例题验证 (23–43s)
**目标**: 具体数字验证，让学生看懂

### 三角形顶点
- A = (-2.0, -2.0)  ← 直角顶点（待证明）
- B = ( 2.0, -2.0)  ← 底边端点
- C = (-2.0,  1.0)  ← 顶端

**精确计算**:
- AB = |2.0-(-2.0)| = 4.0  → 标注 b=4
- AC = |1.0-(-2.0)| = 3.0  → 标注 a=3
- BC = √(4²+3²) = √25 = 5.0 → 标注 c=5

**边界检查**:
- x: [-2.0, 2.0] ✓ 在 [-2.8,2.8] 内
- y: [-2.0, 1.0] ✓ 在 [-3.5,4.0] 内

**标注位置**:
- a=3：x=-2.5（AC左侧），y=-0.5（AC中点）
- b=4：y=-2.5（AB下方），x=0（AB中点）
- c=5：斜边中点偏右上 (0.3, -0.3) 偏移

### 计算步骤（下方逐行）
位置：y从-3.5开始，间距0.55
```
① a² + b² = 3² + 4² = 9 + 16 = 25
② c²       = 5²           = 25
③ ∴ a² + b² = c²  ✓
④ ∴ △ABC 是直角三角形！
```

### 直角标记方向验证
- RightAngle(B, A, C)
- 向量 A→B = (4, 0)，角度 = 0°
- 向量 A→C = (0, 3)，角度 = 90°
- 从 A→B 到 A→C 逆时针转 90° ✓
- **无需** other_angle=True

### 动画序列
1. 清场，出现题目「已知三角形三边为3、4、5」
2. DrawBorderThenFill 三角形（初始无直角标记，灰色）
3. 边长标注依次出现
4. 计算步骤逐行 Write（每行0.5s）
5. 等式成立时，三角形颜色从灰→绿（Indicate动画）
6. 直角标记 Create
7. 结论文字「直角三角形！」大字弹出
