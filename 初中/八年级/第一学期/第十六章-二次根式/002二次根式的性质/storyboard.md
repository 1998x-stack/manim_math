## 核心数学内容（精确）
- 性质1: (√a)² = a，定义域 a ≥ 0
  - 例：(√5)² = 5，(√3)² = 3
- 性质2: √(a²) = |a|，定义域全体实数
  - a = 3 → √(3²) = √9 = 3 = |3| ✓
  - a = -3 → √((-3)²) = √9 = 3 = |-3| = 3 ✓  (注意不是-3)
  - a = 0 → √(0²) = 0 ✓
