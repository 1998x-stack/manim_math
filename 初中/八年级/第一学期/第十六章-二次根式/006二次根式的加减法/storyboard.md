# 006 二次根式的加减法｜逐镜可验分镜

- 实际 Python 源码：`radical_add_sub.py`，Scene 类：`RadicalAddSub`，原十镜方法名不变，逻辑画幅 9×16。
- 先将每项化成最简二次根式，再按被开方数归并；负项须携带负系数，抵消为零的项应删除。纯数学模型 `normalized_term`、`add_subtract_radicals` 与可见结果相对应。
- 不同被开方数的最简二次根式不得套同类项加减法；例如 `√2+√3≠√5`，保留两项而非擅自将被开方数相加。

| 镜头 / 方法 | learning_fact → 可见数学状态 | check 与关键帧 |
|---|---|---|
| 1 `scene_opening` | `√8+√18≠√26`，两项先化简得 `5√2` | 初始和揭晓同一数值，公式及卡片不互相覆盖 |
| 2 `scene_three_steps` | `√8=2√2`、`√18=3√2` → 找同类 → `(2+3)√2=5√2` | 各步与后续例题使用同一数学事实 |
| 3 `scene_ex1_direct` | `2√3+3√3=5√3`，用 2 个青色 + 3 个绿色矩形展示五个相同的 √3 单元 | 数据断言 `{3:5}`，确认数块数量、字幕系数、最终结果一一对应 |
| 4 `scene_ex2_main` | `√8+√18=2√2+3√2=5√2` | 数学回归涵盖非最简转最简后分组 |
| 5 `scene_ex3_subtract` | `√12-√3=2√3-1√3=√3` | 明确单独根式系数 1，保留减号；断言 `{3:1}` |
| 6 `scene_ex4_mixed` | `√8+√18-√2=(2+3-1)√2=4√2` | 三项符号分别为 +、+、−，断言 `{2:4}` |
| 7 `scene_cannot_merge` | `√2+√3≠√5`，平方得到 `5+2√6>5` | 保留两项，不使用无条件的“根号内不同即不可能合并” |
| 8 `scene_quick_practice` | `3√5+2√5=5√5`、`√50-√8=3√2`、`√12+√27=5√3`、`√3+√5` 不同类 | 四项均以纯数学分组结果检查，原负项和非同类表达保持一致；四卡在安全区 |
| 9 `scene_summary` | 规则 `m√r±n√r=(m±n)√r` 只用于相同根式；重现三项混合例 | 记住先化最简与负系数，不虚构其他条件 |
| 10 `scene_outro` | 重现 `√8+√18=5√2`，并清理全场 | 当前屏上同一顶层对象只 FadeOut 一次，水印末尾单独移除 |
