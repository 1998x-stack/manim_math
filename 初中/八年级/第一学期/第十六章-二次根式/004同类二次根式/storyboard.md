# 004 同类二次根式｜逐镜可验分镜

- 真正 Scene：`like_radicals.py` → `LikeRadicals`；10 个分镜方法，9:16、逻辑 9×16。
- 数学定义：将两个二次根式**分别化成最简形式后**，其被开方数相同，才是同类二次根式。只看尚未化简的两个被开方数会误判 `√12` 与 `√3`。
- 课程整数示例的唯一规范化数据：`normalized_term(coefficient, radicand)`；合并分组：`collect_like_terms`。系数可负，零系数项清除；反例保留不同被开方数两项。

| 镜头 / 方法 | learning_fact 与屏上状态 | check / 验收帧 |
|---|---|---|
| 1 `scene_opening` | `2√3+5√3` 可按同类项合并；`√2+√3` 不可直接合并 | 问题与两张例题卡同框；标题没有覆盖卡片 |
| 2 `scene_definition` | 明确“**各自先化最简**，再比较被开方数”；示例 `√12=2√3` 与 `√3` | 不以 `a=b⇒√a=√b` 的普通等值命题替代同类根式定义 |
| 3 `scene_check_method` | `√12→2√3`、`√3→1√3`、`2√3+√3=3√3` | `collect_like_terms([(1,12),(1,3)]) == {3:3}`；关键变换屏上公式一致 |
| 4 `scene_merge_rule` | `m√r+n√r=(m+n)√r`，前提是根式部分相同 | 强调只合并系数，不加根号内的数；卡片宽度合规 |
| 5 `scene_example_basic` | `2√3+5√3=7√3`；画面增加 2+5 个同宽方块直观表示系数相加 | 7 个单元真实位于安全区；`{3:7}` 数学断言与公式一致 |
| 6 `scene_example_advanced` | `√12+√3=2√3+√3=3√3` | 先化简再合并，三张卡片的同一数值关系可逐步核对 |
| 7 `scene_counter_example` | `√2+√3≠√5`，由平方得 `5+2√6>5`；保留 `√2+√3` | 不把非同类误说成数值不能写成任何其他根式，只是不按同类项法则合并 |
| 8 `scene_quick_judge` | 四题分别给出 `5√5`、`3√2`、不可同类合并、`3√6` | 所有结果由数学测试覆盖，判断文字分离于 `MathTex`；四张卡片无重叠 |
| 9 `scene_summary` | 以文字准确定义同类，并并列直接合并、化简后合并的例子 | 不再出现原总结中以 `a=b⇒√a=√b` 充当定义的表述 |
| 10 `scene_outro` | 提示“先化简、再比较、才合并”，水印单独淡出 | 无重复 `FadeOut`、无遗留对象 |
