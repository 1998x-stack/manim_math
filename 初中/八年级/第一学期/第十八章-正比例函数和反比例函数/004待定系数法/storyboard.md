## Scene 2: 四步解题流程展示 (6–16s)
**目标**: 展示通用四步法

### 四步流程（纵向排列）
每步：左侧序号圆圈 + 右侧文字说明

| 步骤 | 序号颜色 | 内容 |
|------|---------|------|
| ① 设 | 蓝色 | 设 y = kx |
| ② 代 | 绿色 | 代入点 (2,6) → 6=2k |
| ③ 解 | 橙色 | 解得 k=3 |
| ④ 写 | 金色 | y=3x ✓ |

布局：
- 步骤1: y=2.2
- 步骤2: y=0.9
- 步骤3: y=-0.4
- 步骤4: y=-1.7

### 动画序列
每步骤依次 Write + 小延迟（0.4s间隔）

## Scene 3: 正比例函数完整过程（可视化） (16–32s)
**目标**: 一边演示计算，一边在坐标轴上画出结果

### 布局（左右分屏）
- 左侧计算区（x<0）: 步骤逐行
- 右侧图像区（x>0）: 坐标轴 + 直线

### 坐标轴（右侧小型）
- Axes: x_range=[-1, 4, 1], y_range=[-1, 8, 1]
- x_length=3.5, y_length=4.5
- 整体: move_to(RIGHT*2.0 + DOWN*0.5)
- 轴顶端: y 屏幕坐标 = -0.5 + 4.5/2 = 1.75 ✓

### 计算步骤（左侧）
x坐标: x_pos = -1.5
- "设 y = kx": y=2.5
- "代入(2,6): 6=2k": y=1.3
- "k = 3": y=0.1（高亮）
- "y = 3x": y=-1.1（结论，金色大字）

### 动态过程
1. 先画坐标轴
2. 标出点 (2,6)（红色大点）
3. 左侧计算逐步出现
4. 解出 k=3 后，直线 y=3x 从原点出发 Create
5. 验证：点在线上（高亮点和线的交叉）

## 几何计算验证

### Scene 3 坐标轴（正比例）
- Axes center: RIGHT*2.0 + DOWN*0.5 = (2.0, -0.5)
- x_length=3.5, x_range=[-1,4]（跨度5）→ x_scale=3.5/5=0.70
- y_length=4.5, y_range=[-1,8]（跨度9）→ y_scale=4.5/9=0.50
- 轴屏幕范围:
  - x: [2.0-1.75, 2.0+1.75] = [0.25, 3.75] ✓
  - y: [-0.5-2.25, -0.5+2.25] = [-2.75, 1.75] ✓
- 点(2,6) 屏幕坐标:
  - x: 2.0 + (2-(-1))*0.70 = 2.0+2.1=4.1... ⚠️ 超出右边界3.75
  - **需调整**: x_range改为[-1,5]，x_scale=3.5/6=0.583
  - 点(2,6): x屏 = 2.0+(2+1)*0.583=2.0+1.75=3.75 ✓（刚好边界）
  - y屏 = -0.5+(6+1)*0.5 = -0.5+3.5 = 3.0 ✓（在4.5以内）

  **修正参数**: x_range=[-1,5], x_length=3.5, y_range=[-1,8], y_length=4.5

### Scene 4 坐标轴（反比例）
- Axes center: RIGHT*2.0 + DOWN*0.8 = (2.0, -0.8)
- x_length=3.5, y_length=3.5, x_range=[-4,4], y_range=[-4,4]
- x_scale = 3.5/8 = 0.4375, y_scale = 3.5/8 = 0.4375
- 轴范围:
  - x: [2.0-1.75, 2.0+1.75] = [0.25, 3.75] ✓
  - y: [-0.8-1.75, -0.8+1.75] = [-2.55, 0.95] ✓（标题区以下）
- 点(2,-3) 屏幕:
  - x屏 = 2.0+2*0.4375 = 2.875 ✓
  - y屏 = -0.8+(-3)*0.4375 = -0.8-1.3125 = -2.1125 ✓
