## Scene 2: 函数定义式 (7–15s)
**目标**: 建立 y=k/x 标准形式

### 元素
- 核心公式大字: y = k/x
- 条件标注: k≠0，x≠0
- 当 k>0 时：一、三象限（绿色标注）
- 当 k<0 时：二、四象限（红色标注）

### 布局
- 公式: y=0（屏幕中央）, size=64
- 条件: 公式下方 y=-1.2
- 象限说明两列: y=-2.5 到 -3.5

## Scene 3: k>0 图像（双曲线一、三象限） (15–30s)
**目标**: 画出 y=2/x 的图像，理解分布

### 坐标轴参数
- Axes: x_range=[-4, 4, 1], y_range=[-4, 4, 1]
- x_length=6.0, y_length=6.0
- 整体: move_to(UP*0.0)（标题在4.5，axes顶端约3.0，安全）

### 坐标轴边界验证
- axes 屏幕宽: x∈[-3.0, 3.0]（x_length=6, ÷2=3.0）✓
- axes 屏幕高: y∈[-3.0, 3.0]（y_length=6, ÷2=3.0）✓

### k>0 曲线（y=2/x）
分两段绘制（避开 x=0 奇点）：
- 右支: x∈[0.3, 4.0]   → y∈[0.5, 6.7]，截断 y≤4
- 左支: x∈[-4.0, -0.3] → y∈[-6.7, -0.5]，截断 y≥-4

**关键点标注**（屏幕坐标需换算，axes x_scale=6/8=0.75）:
- (1,2): 屏幕 (0.75, 1.5)  ← 在轴内 ✓
- (2,1): 屏幕 (1.5, 0.75)  ✓
- (-1,-2): 屏幕 (-0.75, -1.5) ✓

### 渐近线
- x=0: 竖轴本身（虚线标注）
- y=0: 横轴本身（虚线标注）
- 渐近线文字: "x轴和y轴是渐近线"

### 动画序列
1. 清场，标题 "k>0：一、三象限" (绿色)
2. Create(axes)
3. 右支曲线 Create（从 x=4 向 x=0.3 描绘）
4. 左支曲线 Create
5. 关键点 FadeIn + 坐标标注
6. 渐近线虚线 + 说明文字
7. 每象限内增减性箭头（小箭头沿曲线方向）

## 几何计算验证

### Axes 坐标转换（x_range=[-4,4], x_length=6.0）
- x_scale = 6.0 / 8.0 = 0.75 屏幕单位/数学单位
- y_scale = 6.0 / 8.0 = 0.75
- 数学点 (1,2) → 屏幕 (0.75, 1.5) ✓
- axes 整体 move_to(UP*0.0)，不额外偏移

### 曲线截断验证（防止曲线飞出屏幕）
- x_min 截断: 0.4（不能太小，y值会过大）
- y=2/0.4 = 5.0（数学），× 0.75 = 3.75 屏幕 < 4.0 ✓
- x=0.3: y=2/0.3=6.7→屏幕5.0，超出但axes内部clip ✓

### MathTex 规则
- y = k/x → r"y = \dfrac{k}{x}" ✓
- k ≠ 0 → r"k \neq 0" ✓
- k > 0 → r"k > 0" ✓
- 所有中文用 Text()，不用 MathTex()

### 避免的 API
- ❌ GrowArrow → ✅ Create
- ❌ 中文在 MathTex → ✅ Text
- ❌ ° 字符 → ✅ ^\circ
