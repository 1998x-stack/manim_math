## 基础梯形坐标 (raw, SCALE=0.95, OFFSET=UP*0.3)
```
A(-1.0, 1.0) → actual (-0.95, 1.25)   左上
B( 1.0, 1.0) → actual ( 0.95, 1.25)   右上
C( 2.5,-1.2) → actual ( 2.375,-0.84)  右下
D(-2.5,-1.2) → actual (-2.375,-0.84)  左下
上底AB = 2.0, 下底DC = 5.0, 高h = 2.2
```

## 派生点预计算 (raw)
| 元素 | 公式 | raw坐标 | 用于 |
|------|------|---------|------|
| foot_A | A投影到DC线 | (-1.0, -1.2) | 方法1 |
| foot_B | B投影到DC线 | (1.0, -1.2) | 方法1 |
| E | B+(D-A) | (-0.5, -1.2) | 方法2 |
| P | 两腰延长交点 | (0, 2.467) | 方法3 |
| O | 对角线交点 | (0, 0.371) | 方法4 |
| M | AD中点 | (-1.75, -0.1) | 方法5 |
| N | BC中点 | (1.75, -0.1) | 方法5 |

## Scene 2: 方法①作高 (6-20s)
**目的**: 展示从顶点向下底作垂线，构造直角三角形/矩形

### 关键几何
- 从A作垂线到DC，垂足E₁(-1.0,-1.2)
- 从B作垂线到DC，垂足E₂(1.0,-1.2)
- 形成: 矩形ABE₂E₁ + △ADE₁ + △BCE₂

### 动画序列
| 时间 | 动作 |
|------|------|
| 0s | 方法标题卡片滑入 |
| 1s | 虚线高AE₁出现 + 直角标记 |
| 2s | 虚线高BE₂出现 + 直角标记 |
| 3s | 矩形区域高亮填充 |
| 5s | 两个直角三角形高亮 |
| 7s | 说明文字："化梯形为矩形+三角形" |
| 9s | wait 2s |
| 11s | FadeOut |

## Scene 3: 方法②平移一腰 (20-35s)
**目的**: 过顶点平移一条腰，构造平行四边形+三角形

### 关键几何
- 过B作BE∥AD，E在DC上: E(-0.5,-1.2)
- ABDE是平行四边形
- △BCE是三角形，EC = DC - AB = 3.0

### 动画序列
| 时间 | 动作 |
|------|------|
| 0s | 方法标题卡片 |
| 1s | 辅助线BE虚线出现，动画创建 |
| 2s | E点出现+标注 |
| 3s | 平行四边形ABDE填充高亮 |
| 4.5s | △BCE填充不同颜色 |
| 6s | 说明"BE∥AD, BE=AD" + 等号标记 |
| 8s | "化梯形为平行四边形+三角形" |
| 10s | wait 2s |
| 12s | FadeOut |

## Scene 6: 方法⑤作中位线 (60-74s)
**目的**: 连接两腰中点，展示中位线性质

### 关键几何
- M = AD中点 (-1.75,-0.1) raw

- MN = (AB+DC)/2 = 3.5
- MN ∥ AB ∥ DC
