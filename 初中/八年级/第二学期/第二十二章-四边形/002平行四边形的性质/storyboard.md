## 几何预计算清单

平行四边形 ABCD（非矩形，视觉上有倾斜感）：
- A = (-2.5, -1.2, 0)
- B = (1.5, -1.2, 0)
- C = (2.5, 1.2, 0)
- D = (-1.5, 1.2, 0)
  
注意：AB = CD = 4.0（横向边），AD = BC（斜边相等）
AB ∥ CD：两者 y 坐标差相同，方向向量 [4, 0]
AD ∥ BC：方向向量 [1, 2.4]（从 A 到 D，从 B 到 C 相同）

对角线交点 O（精确计算）：
- 对角线 AC 和 BD 的交点 = (self.A + self.C) / 2 = (0, 0, 0)
- OA = OC，OB = OD（精确成立）

| 元素 | 计算公式 | 存储变量 |
|------|---------|---------|
| 对角线交点O | (A+C)/2 = (B+D)/2 | self.O |
| AB中心标记位置 | (A+B)/2 + DOWN*0.3 | self.mid_AB |
| CD中心标记位置 | (C+D)/2 + UP*0.3 | self.mid_CD |
| AD中心标记位置 | (A+D)/2 + LEFT*0.3 | self.mid_AD |
| BC中心标记位置 | (B+C)/2 + RIGHT*0.3 | self.mid_BC |
| ∠A角度 | 计算A处夹角 | self.angle_A_val |
| ∠B角度 | 180 - ∠A | self.angle_B_val |
