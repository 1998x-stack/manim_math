# 梯形 - 动画分镜脚本

## 元信息
- 目标时长: ~75 秒
- 场景数量: 7 个
- 难度等级: 八年级第二学期
- 格式: TikTok 竖屏 1080×1920

## 颜色配置
```python
BG_COLOR = "#1a1a2e"
COLOR_TRAPEZOID = "#4FC3F7"     # 主梯形 - 浅蓝
COLOR_EQUAL = "#FFD700"         # 等腰梯形 - 金色
COLOR_RIGHT = "#69F0AE"         # 直角梯形 - 绿色
COLOR_LABEL = WHITE
COLOR_AUX = GRAY_B
COLOR_HIGHLIGHT = YELLOW
COLOR_FORMULA = "#FF7043"       # 公式颜色 - 橙红
COLOR_ANGLE = "#CE93D8"         # 角度 - 紫色
```

## 几何预计算清单
| 元素 | 计算公式 | 存储变量 |
|------|---------|---------|
| 普通梯形4顶点 | 直接定义 (上底短下底长) | self.T_A,B,C,D |
| 梯形高H | 垂足计算 | self.trap_height |
| 等腰梯形4顶点 | 对称计算 | self.I_A,B,C,D |
| 高的垂足 | perpendicular_foot | self.foot_left, self.foot_right |
| 对角线交点 | 无需计算，直接画线 | — |

## Scene 1: 开场钩子 (0-5s)
**目的**: 吸引注意力，引出主题

### 元素
1. 作者标识 (顶部)
2. 大字标题 "梯形" + 问句
3. 普通梯形淡入

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 作者信息淡入 |
| 0.3s | "你认识梯形吗？" 书写 |
| 1.5s | 梯形Create动画 |
| 2.5s | "只有一组对边平行的四边形" 文字出现 |
| 4.0s | Wait |

---

## Scene 2: 梯形定义 (5-15s)
**目的**: 展示梯形定义，标注上底/下底/腰

### 元素
1. 梯形 (保留)
2. 平行标记线
3. 各部分标注: 上底、下底、腰
4. 定义文字

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 高亮上底 (变色) |
| 0.5s | 高亮下底 (变色) |
| 1.0s | 平行符号出现 |
| 1.5s | "上底 a" 标签 |
| 2.0s | "下底 b" 标签 |
| 2.5s | 腰变色 + "腰" 标签 |
| 3.5s | 定义文字 |

---

## Scene 3: 梯形的高 (15-25s)
**目的**: 展示高的定义和面积公式

### 元素
1. 梯形 (保留)
2. 高线 (DashedLine从上底顶点垂直到下底)
3. 直角标记
4. Brace标注高 "h"
5. 面积公式 S = (a+b)h/2

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 高线从上底垂直画下 |
| 0.8s | 直角标记出现 |
| 1.2s | Brace出现, "h" |
| 2.0s | 公式 S = (a+b)×h÷2 |
| 3.5s | Wait |
