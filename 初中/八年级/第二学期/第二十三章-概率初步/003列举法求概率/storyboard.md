## 场景详细分镜

### Scene 3 — 列表法 (15s)
**题目**: 同时投两枚骰子（1/2/3），求点数之和=4的概率

**表格布局（3×3内容+行列标题=4×4）**:
```
       第2枚: 1    2    3
第1枚: 1  (1,1)(1,2)(1,3)
       2  (2,1)(2,2)(2,3)
       3  (3,1)(3,2)(3,3)
```

**坐标计算**:
- 表格中心: (0, +3.2)
- 单元格宽: 1.6，高: 0.85
- 行标题列: x = -2.8
- 列标题行: y = +4.5
- 内容格 (i,j): x = -1.2 + j*1.6, y = 3.6 - i*0.85，i,j∈0..2

**动画**: 逐行 `Write`，然后高亮和=4的格 (1,3),(2,2),(3,1)

---

### Scene 5 — 树状图 (12s)
**题目**: 投两枚硬币，P(至少一正)

**树结构**:
```
根节点 (0, +5.0)
├── 正H (-2.0, +3.5)  → 正H(-3.2,+2.0)  反T(-0.8,+2.0)
└── 反T (+2.0, +3.5)  → 正H(+0.8,+2.0)  反T(+3.2,+2.0)
叶节点标签: HH, HT, TH, TT  y=+0.8
```

**Arrow路径**:
- 根→左: start=(0,+5.0) end=(-2.0,+3.5), angle≈-135° (第三象限，abs=135°<180° ✓)
- 根→右: start=(0,+5.0) end=(+2.0,+3.5), angle≈-45° ✓

**颜色方案**:
- HH, HT, TH：绿色（至少一正）
- TT：红色（两反）

---

### Scene 6 — 树状图求解 (8s)
- 叶节点总数 n=4
- 高亮 HH, HT, TH，m=3
- P(至少一正) = 3/4

---

## 关键公式（全部 LaTeX 无中文）

```latex
P = \frac{m}{n}
P(\text{sum}=4) = \frac{3}{9} = \frac{1}{3}
P(\text{at least one H}) = \frac{3}{4}
```
