## Scene 3 — 折线图设计 (15s)

**坐标轴**:
- Axes 范围: x∈[0,100]（代表实验次数），y∈[0,1]（频率）
- 屏幕坐标: x_origin=(-3.5, -0.5)，宽7，高3.5
- x轴标签: "试验次数 n"
- y轴标签: "正面频率"
- 虚线: y=0.5（代表理论概率）

**数据点（预计算）**:
```python
import numpy as np
np.random.seed(42)
counts = np.arange(1, 101)
# 模拟累积频率
flips = np.random.randint(0, 2, 100)  # 0=反，1=正
freq = np.cumsum(flips) / counts
```
选取关键点: n=5,10,20,30,50,80,100

**动画顺序**:
1. Create Axes (0.5s)
2. Draw DashedLine at y=0.5 (0.4s)
3. 逐点 Dot + Line 连接，前20个点用 0.2s/点，后面加速
4. 强调末端频率≈0.5
