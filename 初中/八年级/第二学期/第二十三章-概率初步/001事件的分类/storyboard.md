# 事件的分类 - 概率初步动画分镜脚本

## 元信息
- 目标时长: 60-75 秒
- 场景数量: 8 个
- 难度等级: 入门
- 目标观众: 八年级学生

## 颜色配置
```python
COLOR_CERTAIN = "#2ecc71"        # 绿色 - 必然事件
COLOR_IMPOSSIBLE = "#e74c3c"     # 红色 - 不可能事件
COLOR_RANDOM = "#3498db"         # 蓝色 - 随机事件
COLOR_HIGHLIGHT = YELLOW         # 黄色 - 强调
COLOR_AUXILIARY = GRAY_B         # 灰色 - 辅助
BACKGROUND_COLOR = "#1a1a2e"     # 深蓝黑背景
```

## 核心概念
- **必然事件**: P = 1，一定会发生
- **不可能事件**: P = 0，一定不会发生
- **随机事件**: 0 < P < 1，可能发生也可能不发生

## 可视化策略
- 使用概率数轴（0到1）
- 用生活实例说明概念
- 颜色编码三类事件

## 边界安全检查

### 位置布局
- 标题区：y ∈ [5.5, 7]
- 主内容区：y ∈ [-2, 5]
- 底部说明：y ∈ [-5, -2]
- 横向安全：x ∈ [-4, 4]

### 字体大小
- 标题: 36-40
- 副标题: 28-32
- 正文: 22-26
- 数学公式: 28-36
- 说明: 20-24
