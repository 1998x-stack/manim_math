# 二元二次方程组 - 动画分镜脚本

## 元信息
- 目标时长: 60-75 秒
- 场景数量: 6 个
- 难度等级: 中等
- 目标观众: 八年级学生

## 颜色配置
```python
COLOR_PRIMARY = "#3498db"      # 蓝色 - 主方程
COLOR_SECONDARY = "#e74c3c"    # 红色 - 次方程
COLOR_HIGHLIGHT = YELLOW        # 黄色 - 关键步骤
COLOR_SOLUTION = "#2ecc71"      # 绿色 - 解
COLOR_AUXILIARY = GRAY_B        # 灰色 - 辅助说明
BACKGROUND_COLOR = "#1a1a2e"    # 深蓝黑背景
```

## 核心概念
- 二元二次方程组：至少有一个方程是二次的
- 消元法：代入消元、加减消元
- 降次思想：二次 → 一次

## 示例题目
使用经典例题：
```
{ x² + y² = 25
{ x + y = 7
```

## Scene 1: 开场钩子 (5秒)
**目的**: 抓住注意力，引出问题

### 元素
1. 作者标识 (顶部小字)
2. 钩子问题 (大字)
3. 方程组淡入

### 动画序列
| 时间 | 动作 | 代码参考 |
|------|------|---------|
| 0.0s | 作者信息淡入 | `FadeIn(author, shift=DOWN*0.2)` |
| 0.3s | 钩子文字闪现 | `Write(hook_text)` |
| 1.0s | 方程组写入 | `Write(equation_system)` |
| 2.5s | 高亮二次项 | `Indicate(quadratic_terms)` |
| 3.5s | 等待 | `Wait(1.0)` |

### 关键文案
- 钩子："两个未知数，两个方程，怎么解？"
- 副标题："二元二次方程组"

### 清理
- FadeOut: hook_text
- 保留: equation_system, author_info

## Scene 4: 代入消元法 - 代入并化简 (15秒)
**目的**: 将y的表达式代入第一个方程

### 元素
1. 第一个方程：x² + y² = 25
2. y = 7 - x（高亮）
3. 代入后的方程
4. 展开和化简步骤
5. 箭头连接

### 动画序列
| 时间 | 动作 | 备注 |
|------|------|------|
| 0.0s | 高亮第一个方程 | 准备代入 |
| 1.0s | y → (7-x) 闪烁 | 指示替换 |
| 2.0s | 代入动画 | `TransformMatchingTex` |
| 3.0s | 显示 x² + (7-x)² = 25 | |
| 4.0s | 展开 (7-x)² | 步骤动画 |
| 6.0s | x² + 49 - 14x + x² = 25 | |
| 7.0s | 合并同类项 | 颜色标注 |
| 9.0s | 2x² - 14x + 24 = 0 | |
| 10.0s | 化简: x² - 7x + 12 = 0 | 除以2 |
| 12.0s | 框住最终方程 | 强调 |

### 关键文案
- "Step 2: 代入第一个方程"
- "降次成功！一元二次方程"

### 清理
- 保留: x² - 7x + 12 = 0

| 2.0s | y₁ = 7 - 3 = 4 | 计算 |
| 3.5s | x₂ = 4 代入 | |
| 4.5s | y₂ = 7 - 4 = 3 | |
| 6.0s | 显示解集 | 大括号 |
| 7.0s | 解1: (3, 4) | 绿色框 |
| 7.5s | 解2: (4, 3) | 绿色框 |

## 技术要点

### 字体大小
- 标题: 36-40
- 方程: 28-32
- 说明文字: 22-24
- 作者信息: 20

### 动画时长
- 方程书写: 0.8-1.0s
- 变换动画: 1.0-1.5s
- 理解停顿: 1.5-2.5s
- 快速提示: 0.4-0.6s

### 位置布局
- 主方程区：y ∈ [0, 4]
- 步骤说明：y ∈ [-4, -2]
- 侧边记录：x ∈ [3, 4.5]

### 颜色使用
- 第一个方程（二次）：蓝色
- 第二个方程（一次）：红色
- 代入步骤：黄色高亮
- 最终解：绿色
