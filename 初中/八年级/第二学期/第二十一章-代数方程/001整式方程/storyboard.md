## 内容设计
- **主方程**: x³ - 4x = 0
- **核心步骤**:
  1. x(x² - 4) = 0  (提公因式)
  2. x(x+2)(x-2) = 0  (平方差公式)
  3. x=0 或 x+2=0 或 x-2=0
  4. 解: x=0, x=-2, x=2

## Scene 4: 例题解法 (18秒) [核心]
**目的**: 逐步展示 x³ - 4x = 0 的解法

### 步骤分解
1. 原式: x³ - 4x = 0
2. 提公因式: x(x² - 4) = 0
3. 平方差: x(x+2)(x-2) = 0
4. 零乘积: 得到三个方程
5. 解出: x = 0, -2, 2

| 时间 | 动作 |
|------|------|
| 0.0s | 例题标题 + 方程出现 |
| 1.5s | "第一步: 提公因式" 标注 |
| 3.0s | 变换到 x(x²-4)=0 |
| 5.0s | "第二步: 平方差公式" 标注 |
| 6.5s | 变换到 x(x+2)(x-2)=0 |
| 9.0s | "第三步: 零乘积定理" 标注 |
| 10.5s | 拆开三个因式 = 0 |
| 14.0s | 得出三个解 |
| 17.0s | 答案框出现 |
