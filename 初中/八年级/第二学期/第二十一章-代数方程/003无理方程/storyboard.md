## 例题设计（精心选择：含1个有效根 + 1个增根）
**主方程**: √(2x+1) = x - 1

**解题过程**:
1. 整理: 根号已在一边，√(2x+1) = x-1
2. 两边平方: 2x+1 = (x-1)² = x²-2x+1
3. 整理: x²-4x = 0  →  x(x-4) = 0
4. 两个解: x=0 或 x=4
5. 检验 x=0:
   - 左边: √(2×0+1) = √1 = 1
   - 右边: 0-1 = -1
   - 1 ≠ -1，且右边 = -1 < 0  →  ❌ 增根，舍去
6. 检验 x=4:
   - 左边: √(2×4+1) = √9 = 3
   - 右边: 4-1 = 3
   - 3 = 3  ✓  有效解

**最终答案**: x = 4
