## 示例题目
**某商店去年的销售额为100万元，今年的销售额为121万元。如果每年的增长率相同，求这个增长率。**

## 解题思路
1. 审题：理解"连续两年相同增长率"
2. 设未知数：设增长率为 x
3. 找等量关系：去年 × (1+x)² = 今年
4. 列方程：100(1+x)² = 121
5. 解方程：(1+x)² = 1.21 → 1+x = ±1.1 → x = 0.1 或 x = -2.1
6. 检验：x = 10% 合理，x = -210% 不合实际
