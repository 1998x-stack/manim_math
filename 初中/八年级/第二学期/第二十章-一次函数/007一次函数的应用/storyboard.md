# 一次函数的应用 - 动画分镜脚本

## 元信息
- 目标时长: ~70 秒
- 场景数量: 6 个
- 难度等级: 中等（八年级）
- 主题问题: 出租车计费问题

## 问题设定
某市出租车：起步价 3 元，之后每公里 2 元。
- 建模：y = 2x + 3 （x ≥ 0）
- 问题①：乘坐 5 公里花多少钱？→ y = 13 元
- 问题②：付 15 元最多坐几公里？→ x = 6 公里

## 颜色配置
```python
BG_COLOR        = "#1a1a2e"   # 深海蓝背景
COLOR_TITLE     = YELLOW      # 标题黄
COLOR_FORMULA   = "#00FF7F"   # 函数绿
COLOR_Q1        = ORANGE      # 问题1橙色
COLOR_Q2        = "#FF6B6B"   # 问题2红色
COLOR_STEP      = "#00CED1"   # 步骤青色
COLOR_AXIS      = WHITE       # 坐标轴白色
```

## 几何预计算清单
| 元素 | 数值 | 说明 |
|------|------|------|
| 函数 | y = 2x + 3 | 一次函数解析式 |
| Q1点 | (5, 13) | x=5时的交点 |
| Q2点 | (6, 15) | y=15时的交点 |
| 纵截距 | (0, 3) | 图像与y轴交点 |

## 坐标轴参数
- x_range: [0, 7, 1]，x_length = 5.5
- y_range: [0, 16, 2]，y_length = 5.5
- 坐标轴中心: DOWN * 1.0（在主内容区中下方）

## Scene 1: 开场 Hook（约8秒）
**目的**: 抓住注意力，引入打车费用问题

### 元素
1. 作者标识（顶部）
2. 钩子大字"打车要花多少钱？"
3. 简单出租车图形
4. 问号费用标注

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 作者信息淡入 |
| 0.3s | 钩子标题 Write |
| 1.1s | 出租车图形 FadeIn |
| 1.7s | 计价器文字 |
| 2.5s | 等待 |
| 3.0s | FadeOut 清场 |

## Scene 5: 解题（约20秒）
**目的**: 用图像求解两个问题

### 问题①（约10秒）
- 从x=5画垂线到函数图像
- 从交点画水平线到y轴
- 显示 y = 2×5+3 = 13
- 答: 13元

### 问题②（约10秒）
- 从y=15画水平线到函数图像
- 从交点画垂线到x轴
- 显示 15 = 2x+3, x=6
- 答: 6公里
