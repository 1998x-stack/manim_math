# 一次函数的性质 · 七镜可核验分镜

对应脚本 `linear_function_properties.py`，入口 `LinearFunctionProperties`，年级：初中八年级下册。

## 数学规格

- 函数 `y=kx+b` 中 `k≠0`，默认实数定义域。`x₂>x₁` 时，`f(x₂)-f(x₁)=k(x₂-x₁)`；当 `k>0` 严格递增、`k<0` 严格递减。
- 四种 `k`、`b` 非零符号组合：`(+,+)→一二三`，`(+,-)→一三四`，`(-,+)→一二四`，`(-,-)→二三四`。`b=0` 时正斜率经过一三、负斜率经过二四；`x=0` 或 `y=0` 的轴上点不属于任一象限。
- 用具体点帮助学生观察象限并由直线与坐标轴交点解释一般结论；有限样本点仅用于示意，不能把几枚圆点称为严格证明。所有线段在 `[-3,3]×[-3,3]` 坐标窗口内裁剪。

## 验收层级

本课使用 `python -m py_compile linear_function_properties.py verify_linear_function_properties.py`、`python verify_linear_function_properties.py` 和 Skill 的 `scripts/audit_scene.py`，独立测试需覆盖象限六种情况、全部绘图端点及非法输入。之后实际执行 `manim -ql linear_function_properties.py LinearFunctionProperties`，逐镜检查动态数值、方向箭头、象限点、文字排版及清场；最后真实检查 ffprobe 输出及原音轨。旧视频存在与静态检查通过均不等价于完成渲染验收。
