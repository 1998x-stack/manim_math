# 直线的方程

## 概述
直线方程的五种形式：①点斜式：y-y₀=k(x-x₀)（过点(x₀,y₀)，斜率为k）；②斜截式：y=kx+b（斜率k，y截距b）；③两点式：(y-y₁)/(y₂-y₁)=(x-x₁)/(x₂-x₁)（过两点）；④截距式：x/a+y/b=1（x截距a，y截距b，a,b≠0）；⑤一般式：Ax+By+C=0（A,B不同时为0）。不同形式适用于不同条件，灵活选用可简化计算。

## 数学公式
- 点斜式：y - y₀ = k(x - x₀)
- 斜截式：y = kx + b
- 两点式：(y-y₁)/(y₂-y₁) = (x-x₁)/(x₂-x₁)
- 截距式：x/a + y/b = 1
- 一般式：Ax + By + C = 0
