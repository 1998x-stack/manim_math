## 数学数据预算
- 直线 l: 3x + 4y - 12 = 0
  - 截距：(0,3), (4,0)
  - 法向量：(3, 4)，方向向量：(4, -3)
- 点 P: (1, 1)
- 垂足 Q: (8/5, 9/5) = (1.6, 1.8)
  - t = -(3×1 + 4×1 - 12)/(9+16) = 5/25 = 1/5
  - Q = (1 + 3/5, 1 + 4/5) = (1.6, 1.8)
- 距离 d = |3+4-12|/√25 = 5/5 = 1

- 平行线1: 3x+4y-12=0，平行线2: 3x+4y-2=0
  - 距离 = |(-12)-(-2)|/√25 = 10/5 = 2
