# 椭圆的定义与标准方程

## 概述
椭圆的定义：平面内到两定点F₁、F₂（焦点）的距离之和等于常数2a（2a>|F₁F₂|=2c）的点的轨迹。标准方程：焦点在x轴上x²/a²+y²/b²=1（a>b>0）；焦点在y轴上x²/b²+y²/a²=1（a>b>0）。关系：a²=b²+c²。椭圆的四个顶点：(±a,0)和(0,±b)。a是长半轴长，b是短半轴长，c是半焦距。

## 数学公式
- 定义：|PF₁| + |PF₂| = 2a
- 焦点在x轴：x²/a² + y²/b² = 1 (a > b > 0)
- 焦点在y轴：x²/b² + y²/a² = 1 (a > b > 0)
- a² = b² + c²
- 顶点：(±a, 0), (0, ±b)
- 焦点：(±c, 0) 或 (0, ±c)
