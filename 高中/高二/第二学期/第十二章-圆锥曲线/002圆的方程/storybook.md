# 圆的方程

## 概述
圆的定义：平面内到定点（圆心）距离等于定长（半径）的点的轨迹。标准方程：(x-a)²+(y-b)²=r²（圆心(a,b)，半径r）。一般方程：x²+y²+Dx+Ey+F=0，当D²+E²-4F>0时表示圆，圆心(-D/2,-E/2)，半径r=½√(D²+E²-4F)。直线与圆的位置关系（通过圆心到直线距离d与半径r比较）：d<r相交，d=r相切，d>r相离。

## 数学公式
- 标准方程：(x-a)² + (y-b)² = r²
- 一般方程：x² + y² + Dx + Ey + F = 0
- 圆心：(-D/2, -E/2)
- 半径：r = ½√(D² + E² - 4F)
- 相交：d < r, 相切：d = r, 相离：d > r
