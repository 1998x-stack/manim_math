# 双曲线的几何性质

## 概述
双曲线x²/a²-y²/b²=1的几何性质：①范围：|x|≥a，y∈R；②对称性：关于x轴、y轴、原点对称；③顶点：(±a,0)；④离心率e=c/a（e>1），e越大开口越大；⑤渐近线y=±(b/a)x（双曲线无限趋近但永不相交的直线）；⑥准线x=±a²/c。等轴双曲线a=b时，渐近线互相垂直，e=√2。

## 数学公式
- 离心率：e = c/a (e > 1)
- 渐近线：y = ±(b/a)x
- 准线：x = ±a²/c
- 通径：2b²/a
- 焦半径：|PF₁| = |ex₀ + a|, |PF₂| = |ex₀ - a|
- 等轴双曲线：a = b, e = √2
