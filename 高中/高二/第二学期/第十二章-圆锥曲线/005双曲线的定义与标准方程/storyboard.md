# 双曲线的定义与标准方程

## 概述
双曲线的定义：平面内到两定点F₁、F₂（焦点）的距离之差的绝对值等于常数2a（0<2a<|F₁F₂|=2c）的点的轨迹。标准方程：焦点在x轴上x²/a²-y²/b²=1；焦点在y轴上y²/a²-x²/b²=1。关系：c²=a²+b²。双曲线有两支，分别在焦点两侧。a是实半轴长，b是虚半轴长，c是半焦距。

## 数学公式
- 定义：||PF₁| - |PF₂|| = 2a
- 焦点在x轴：x²/a² - y²/b² = 1
- 焦点在y轴：y²/a² - x²/b² = 1
- c² = a² + b²
- 顶点：(±a, 0) 或 (0, ±a)
- 焦点：(±c, 0) 或 (0, ±c)
