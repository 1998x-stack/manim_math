# 抛物线的定义与标准方程

## 概述
抛物线的定义：平面内到定点F（焦点）和定直线l（准线，F不在l上）距离相等的点的轨迹。标准方程：①y²=2px（p>0）：焦点(p/2,0)，准线x=-p/2，开口向右；②y²=-2px：开口向左；③x²=2py：开口向上；④x²=-2py：开口向下。p是焦点到准线的距离（焦准距）。抛物线只有一个焦点和一条准线。

## 数学公式
- 定义：|PF| = 点到准线距离
- y² = 2px：焦点(p/2, 0)，准线x = -p/2
- y² = -2px：焦点(-p/2, 0)，准线x = p/2
- x² = 2py：焦点(0, p/2)，准线y = -p/2
- x² = -2py：焦点(0, -p/2)，准线y = p/2
