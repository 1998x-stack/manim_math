# 椭圆的几何性质

## 概述
椭圆x²/a²+y²/b²=1（a>b>0）的几何性质：①范围：-a≤x≤a，-b≤y≤b；②对称性：关于x轴、y轴、原点对称；③顶点：(±a,0)，(0,±b)；④离心率e=c/a（0<e<1），e越接近1越扁，越接近0越圆；⑤焦点到准线距离a²/c；⑥准线方程x=±a²/c（焦点在x轴）。通径（过焦点垂直于长轴的弦）长为2b²/a。

## 数学公式
- 离心率：e = c/a (0 < e < 1)
- 准线：x = ±a²/c (焦点在x轴)
- 通径：2b²/a
- 焦点到准线距离：a²/c - c = b²/c
- 焦半径：|PF₁| = a + ex₀, |PF₂| = a - ex₀
