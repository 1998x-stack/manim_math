## 核心几何计算（示例复数 z = 3 + 4i）
```
a = 3,  b = 4
|z| = √(3² + 4²) = √25 = 5
θ = arctan(4/3) ≈ 53.13°
三角形式: z = 5(cos53.13° + i·sin53.13°)
共轭: z̄ = 3 - 4i → 点 (3, -4)

Axes 设置:
  center: (0, 1.2)  [屏幕坐标]
  x_range: [-2, 6, 1],  x_length: 5.6
  y_range: [-5, 6, 1],  y_length: 5.6
  scale: 5.6 / 8 = 0.7 单位/格

屏幕坐标 c2p(a, b):
  z    = c2p(3,  4) = (3×0.7+0, 4×0.7+1.2) = (2.10,  4.00)  ✓
  z̄   = c2p(3, -4) = (2.10, -1.60)                           ✓
  foot = c2p(3,  0) = (2.10,  1.20)                           ✓
  O    = c2p(0,  0) = (0.00,  1.20)                           ✓
```

## 辐角方向验证
```
vertex = O = (0, 1.2)
p1 (实轴正方向) = c2p(1, 0) = (0.7, 1.2)
p2 (z方向) = c2p(3, 4) = (2.1, 4.0)

v1 = p1 - vertex = (0.7, 0)
v2 = p2 - vertex = (2.1, 2.8)
cross_z = 0.7×2.8 − 0×2.1 = 1.96 > 0
→ 逆时针 → other_angle=False ✓  角度 ≈ 53.13° < 90° ✓
```

## Scene 4: 模 |z| (8s)
**目的**: |z| = √(a²+b²) = 距离

## Scene 5: 辐角 θ (8s)
**目的**: 辐角 = OZ与实轴的夹角

## Scene 6: 三角形式 (8s)
**目的**: z = r(cosθ + i sinθ)
- r=|z|=5, θ=辐角
- 公式推导: a=rcosθ, b=rsinθ
- 完整三角形式
