# 实系数一元二次方程

## 概述
实系数一元二次方程ax²+bx+c=0（a≠0）的求根公式：x=(-b±√Δ)/(2a)，其中Δ=b²-4ac。当Δ>0时，有两个不相等的实根；当Δ=0时，有两个相等的实根；当Δ<0时，有两个共轭虚根x=(-b±i√|Δ|)/(2a)。韦达定理：x₁+x₂=-b/a，x₁·x₂=c/a，在复数范围内仍然成立。任何实系数多项式方程的虚根成共轭对出现。

## 数学公式
- x = (-b ± √Δ)/(2a)
- Δ = b² - 4ac
- Δ > 0：两不等实根
- Δ = 0：两相等实根
- Δ < 0：两共轭虚根
- 韦达定理：x₁ + x₂ = -b/a, x₁x₂ = c/a
