# 复数的四则运算

## 概述
设z₁=a+bi，z₂=c+di。加法：z₁+z₂=(a+c)+(b+d)i；减法：z₁-z₂=(a-c)+(b-d)i；乘法：z₁·z₂=(ac-bd)+(ad+bc)i（可用i²=-1展开）；除法：z₁/z₂=(z₁·z̄₂)/(z₂·z̄₂)=[(ac+bd)+(bc-ad)i]/(c²+d²)（分母实数化）。运算律：加法和乘法满足交换律、结合律，乘法对加法满足分配律。

## 数学公式
- 加法：(a+bi) + (c+di) = (a+c) + (b+d)i
- 减法：(a+bi) - (c+di) = (a-c) + (b-d)i
- 乘法：(a+bi)(c+di) = (ac-bd) + (ad+bc)i
- 除法：(a+bi)/(c+di) = [(ac+bd)+(bc-ad)i]/(c²+d²)
- i² = -1, i³ = -i, i⁴ = 1
