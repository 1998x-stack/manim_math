# 复数的概念

## 概述
复数是形如z=a+bi的数，其中a、b是实数，i是虚数单位，满足i²=-1。a称为实部（Re(z)=a），b称为虚部（Im(z)=b）。当b=0时，z是实数；当b≠0时，z是虚数；当a=0且b≠0时，z是纯虚数。两复数相等：a+bi=c+di⟺a=c且b=d。复数的引入使得任何一元二次方程都有根，完善了代数基本定理。

## 数学公式
- z = a + bi (a, b ∈ R, i² = -1)
- 实部：Re(z) = a
- 虚部：Im(z) = b
- 相等：a + bi = c + di ⟺ a = c 且 b = d
- 共轭复数：z̄ = a - bi
