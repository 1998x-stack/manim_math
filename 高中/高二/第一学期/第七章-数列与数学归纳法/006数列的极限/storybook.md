# 数列的极限

## 概述
数列{aₙ}的极限：若当n无限增大时，aₙ无限接近于常数A，则称A为数列{aₙ}的极限，记作lim(n→∞)aₙ=A或aₙ→A(n→∞)。极限存在的数列称为收敛数列，否则称为发散数列。极限运算法则：lim(aₙ±bₙ)=lim aₙ±lim bₙ，lim(aₙ·bₙ)=lim aₙ·lim bₙ。重要极限：lim(1/n)=0，lim(1+1/n)ⁿ=e≈2.718。

## 数学公式
- lim(n→∞) aₙ = A
- lim(aₙ ± bₙ) = lim aₙ ± lim bₙ
- lim(aₙ · bₙ) = lim aₙ · lim bₙ
- lim(aₙ / bₙ) = lim aₙ / lim bₙ (lim bₙ ≠ 0)
- lim(1/n) = 0
- lim(1 + 1/n)ⁿ = e ≈ 2.718
- lim qⁿ = 0 (|q| < 1)
