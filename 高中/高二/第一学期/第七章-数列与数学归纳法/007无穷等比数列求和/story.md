# 无穷等比数列求和

## 概述
对于无穷等比数列{aₙ}，当|q|<1时，Sₙ=a₁(1-qⁿ)/(1-q)当n→∞时，qⁿ→0，因此无穷等比数列的和S∞=a₁/(1-q)。这个公式在很多实际问题中有应用，如循环小数化分数、物理中的衰减问题等。当|q|≥1时，数列不收敛，无穷级数发散，不存在有限和。

## 数学公式
- |q| < 1: S_∞ = a₁/(1-q)
- |q| < 1: lim qⁿ = 0
- |q| ≥ 1: 级数发散
- 0.999... = 9/10 · 1/(1-1/10) = 1
- 循环小数 0.ȧ = a/9
