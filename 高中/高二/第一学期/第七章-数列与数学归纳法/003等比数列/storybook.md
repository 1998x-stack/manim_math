# 等比数列

## 概述
等比数列是指从第二项起，每一项与前一项的比都等于同一非零常数q的数列，q称为公比。通项公式：aₙ=a₁·q^(n-1)=aₘ·q^(n-m)。前n项和：当q=1时，Sₙ=na₁；当q≠1时，Sₙ=a₁(1-qⁿ)/(1-q)=(a₁-aₙq)/(1-q)。等比中项：若a,G,b成等比数列（同号），则G²=ab。性质：若m+n=p+q，则aₘ·aₙ=aₚ·aₓ。

## 数学公式
- aₙ₊₁ / aₙ = q (公比, q ≠ 0)
- aₙ = a₁ · q^(n-1)
- q ≠ 1: Sₙ = a₁(1 - qⁿ)/(1 - q)
- q = 1: Sₙ = na₁
- 等比中项：G² = ab
- m + n = p + q ⇒ aₘ · aₙ = aₚ · aₓ
- |q| < 1: S_∞ = a₁/(1-q)
