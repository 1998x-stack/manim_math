# 二阶行列式

## 概述
二阶行列式是由四个数排成的2×2数表按一定规则计算的一个数。|a b; c d|=ad-bc（对角线法则：主对角线乘积减副对角线乘积）。二阶行列式可用于：①解二元一次方程组（克拉默法则）；②判断两向量是否平行；③计算平行四边形面积。性质：行列式转置值不变；交换两行（列）变号；某行（列）乘k等于行列式乘k。

## 数学公式
- |a b; c d| = ad - bc
- 克拉默法则：x = D₁/D, y = D₂/D
- |ka kb; c d| = k|a b; c d|
- |a b; c d| = |a c; b d| (转置)
- 交换两行变号
