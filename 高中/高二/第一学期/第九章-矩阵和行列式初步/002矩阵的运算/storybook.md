# 矩阵的运算

## 概述
矩阵加法：同型矩阵对应元素相加，A+B=(aᵢⱼ+bᵢⱼ)。数乘：kA=(kaᵢⱼ)。矩阵乘法：设A是m×s矩阵，B是s×n矩阵，则AB是m×n矩阵，(AB)ᵢⱼ=∑aᵢₖbₖⱼ（第i行与第j列对应元素乘积之和）。注意：矩阵乘法不满足交换律（一般AB≠BA）。矩阵乘法满足结合律和分配律。EA=AE=A，A·O=O·A=O。

## 数学公式
- A + B = (aᵢⱼ + bᵢⱼ)
- kA = (kaᵢⱼ)
- (AB)ᵢⱼ = Σaᵢₖbₖⱼ
- AB ≠ BA (一般)
- (AB)C = A(BC)
- A(B + C) = AB + AC
- EA = AE = A
