# 矩阵的概念 - 动画分镜脚本

## 元信息
- 目标时长: 60-75 秒
- 场景数量: 8 个
- 难度等级: 基础
- 目标受众: 高二学生

## 颜色配置
```python
COLOR_PRIMARY = "#3498db"      # 蓝色 - 主要矩阵
COLOR_SECONDARY = "#e74c3c"    # 红色 - 强调元素
COLOR_HIGHLIGHT = YELLOW        # 黄色 - 高亮
COLOR_SPECIAL = "#2ecc71"       # 绿色 - 特殊矩阵
COLOR_AUXILIARY = GRAY_B        # 灰色 - 辅助线
COLOR_BACKGROUND = "#1a1a2e"    # 深蓝背景
```

## 几何预计算清单
| 元素 | 计算方式 | 存储变量 |
|------|---------|---------|
| 矩阵显示位置 | 居中偏上 | self.MATRIX_CENTER |
| 行列数标注位置 | 矩阵旁边 | 动态计算 |
| 括号缩放 | 根据矩阵大小 | 动态调整 |

## 关键约束
1. 所有矩阵元素必须对齐
2. 字体大小保持一致性
3. 矩阵括号必须完整包围元素
4. 标注不能遮挡主要内容
5. 元素在安全边界内 (x∈[-4,4], y∈[-7,7])
