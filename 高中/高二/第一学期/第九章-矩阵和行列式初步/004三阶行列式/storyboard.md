## 矩阵坐标系统

### 标准矩阵布局
```
元素索引: (row, col)
┌─────────────────┐
│ (0,0) (0,1) (0,2) │  a₁  b₁  c₁
│ (1,0) (1,1) (1,2) │  a₂  b₂  c₂
│ (2,0) (2,1) (2,2) │  a₃  b₃  c₃
└─────────────────┘
```

### 扩展矩阵布局（用于对角线法则）
```
┌─────────────────────────┐
│ (0,0) (0,1) (0,2) (0,3) (0,4) │  a₁  b₁  c₁  a₁  b₁
│ (1,0) (1,1) (1,2) (1,3) (1,4) │  a₂  b₂  c₂  a₂  b₂
│ (2,0) (2,1) (2,2) (2,3) (2,4) │  a₃  b₃  c₃  a₃  b₃
└─────────────────────────┘
```
