## Scene 4: 五要素详解 - 逐个展示
**总时长:** 20 秒（每个4秒）

```

      Step1 → Step2 → Step3 → ... → END
y=-3: "算法必须在有限步骤内结束"
```

### 4.5 输出 (Output)

### 通用动画模式
```python
def show_feature(self, number, name, diagram, explanation):
    # 标题
    title = Text(f"{number} {name}", ...).move_to(UP*6)
    self.play(Write(title), run_time=0.6)
    
    # 图示
    self.play(Create(diagram), run_time=1.2)
    
    # 说明
    explain = Text(explanation, ...).move_to(DOWN*3)
    self.play(FadeIn(explain), run_time=0.6)
    
    # 理解停顿
    self.wait(1.2)
    
    # 清理
    self.play(FadeOut(VGroup(title, diagram, explain)), run_time=0.4)
```

## 验证清单

### 实施前检查
- [x] 所有文字使用 Text() 而非 MathTex()（无复杂数学公式）
- [x] 场景时长合理（45-60秒范围内）
- [x] 元素布局在安全边界内（x∈[-4,4], y∈[-7,7]）
- [x] 颜色方案一致
- [x] 动画节奏：难点2-3秒停顿

### 技术约束
- [ ] 无几何计算需求（流程图布局为固定坐标）
- [ ] 所有中文使用 `Text(..., font="Noto Sans CJK SC")`
- [ ] 流程图元素使用 Manim 基本形状
- [ ] 箭头使用 Arrow() 不使用 scale_tips

### 特殊注意
- **流程图元素:** 
  - 开始/结束: Ellipse
  - 处理: Rectangle
  - 判断: Polygon (菱形)
  - 输入/输出: Polygon (平行四边形)
- **连接箭头:** 使用 Arrow(start, end, buff=0.2)
- **文字位置:** 确保不与形状重叠
- **颜色对比:** 深色背景 + 亮色元素
