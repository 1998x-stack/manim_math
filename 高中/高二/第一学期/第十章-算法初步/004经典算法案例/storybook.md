# 经典算法案例

## 概述
常见的经典算法案例：①辗转相除法（欧几里得算法）：求两个正整数的最大公约数；②秦九韶算法：计算多项式的值，将n次多项式改写为嵌套形式，减少乘法次数；③进制转换算法：十进制转k进制（除k取余法），k进制转十进制（按权展开求和）。这些算法体现了数学思想与计算机程序的结合。

## 数学公式
- 辗转相除法：gcd(a,b) = gcd(b, a mod b)
- 秦九韶算法：f(x) = (...((aₙx + aₙ₋₁)x + aₙ₋₂)x + ... + a₁)x + a₀
- 十进制转k进制：除k取余，逆序排列
- k进制转十进制：∑aᵢkⁱ
