# 向量的坐标表示

## 概述
在平面直角坐标系中，向量可以用有序数对（坐标）表示。设向量a⃗的起点在原点，终点为(x,y)，则a⃗=(x,y)，x、y分别称为a⃗在x轴、y轴上的分量。向量的坐标表示将几何问题代数化，使向量运算变得简便。基本单位向量i⃗=(1,0)，j⃗=(0,1)，任意向量a⃗=(x,y)=xi⃗+yj⃗。若向量起点为A(x₁,y₁)，终点为B(x₂,y₂)，则AB⃗=(x₂-x₁,y₂-y₁)。

## 数学公式
- a⃗ = (x, y) = xi⃗ + yj⃗
- i⃗ = (1, 0), j⃗ = (0, 1)
- AB⃗ = (x₂ - x₁, y₂ - y₁)
- |a⃗| = √(x² + y²)
- a⃗ = b⃗ ⟺ x₁ = x₂ 且 y₁ = y₂
