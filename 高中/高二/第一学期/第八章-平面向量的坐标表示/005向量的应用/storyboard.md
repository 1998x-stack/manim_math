# 向量的应用

## 概述
向量在几何中的应用：①证明平行：a⃗∥b⃗⟺a⃗=λb⃗⟺x₁y₂-x₂y₁=0；②证明垂直：a⃗⊥b⃗⟺a⃗·b⃗=0；③求夹角：cos θ=a⃗·b⃗/(|a⃗||b⃗|)；④求距离：|AB|=|AB⃗|；⑤判断共线：三点A、B、C共线⟺AB⃗=λAC⃗。向量还可以用于解决物理中的力的合成与分解、速度合成等问题。

## 数学公式
- 平行：a⃗ = λb⃗
- 垂直：a⃗ · b⃗ = 0
- 夹角：cos θ = (a⃗ · b⃗)/(|a⃗||b⃗|)
- 三点共线：AB⃗ = λAC⃗
- 向量法求面积：S = ½|x₁y₂ - x₂y₁|
