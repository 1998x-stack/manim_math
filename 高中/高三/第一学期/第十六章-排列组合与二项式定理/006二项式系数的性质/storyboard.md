## Scene 5: 奇偶和 + 最大系数 (40-57s)
**目标**: 代入 x=-1 得奇偶和；最大系数位置

### 推论1: 奇偶和
```
令 x=-1: 0 = C(n,0)-C(n,1)+...
→ 偶项和 = 奇项和 = 2^(n-1)
```

### 最大系数
- n 偶数: C(n, n/2) 最大（中间项）
- n 奇数: C(n, (n-1)/2) = C(n, (n+1)/2) 最大（中间两项）
- 可视化: n=6 的杨辉三角第6行（高亮中间项）

### 预计算: n=6
- 第6行: 1,6,15,20,15,6,1
- 最大项: C(6,3)=20
