# 二项式系数的性质

## 概述
二项式系数的性质：①对称性：C(n,k)=C(n,n-k)；②递推性：C(n,k)=C(n-1,k)+C(n-1,k-1)；③各系数和：令a=b=1，得∑C(n,k)=2ⁿ；④奇偶项系数和相等：令a=1,b=-1，得C(n,0)+C(n,2)+...=C(n,1)+C(n,3)+...=2ⁿ⁻¹；⑤最大系数：当n为偶数时，C(n,n/2)最大；当n为奇数时，C(n,(n-1)/2)=C(n,(n+1)/2)最大。

## 数学公式
- 对称性：C(n,k) = C(n,n-k)
- 递推：C(n,k) = C(n-1,k) + C(n-1,k-1)
- 系数和：ΣC(n,k) = 2ⁿ
- 奇项和 = 偶项和 = 2^(n-1)
- C(n,0)² + C(n,1)² + ... + C(n,n)² = C(2n,n)
