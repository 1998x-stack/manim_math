## Scene 2: 二项式定理主公式 (5-18s)
**目标**: 逐步呈现展开公式，对齐项结构

### 关键公式
```
(a+b)^n = C(n,0)a^n + C(n,1)a^(n-1)b + ... + C(n,n)b^n
         = ∑_{k=0}^{n} C(n,k) a^(n-k) b^k
```

## Scene 3: 通项公式 T_{k+1} (18-32s)
**目标**: 重点介绍通项，并举例 (a+b)^5 的第3项

### 关键公式
```
T_{k+1} = C(n,k) · a^(n-k) · b^k
```

### 示例: (a+b)^5, k=2 → T_3

## Scene 5: 重要推论 (46-57s)
**目标**: 展示 a=b=1 和 a=1,b=-1 两个代入结论

### 推论1: 所有系数和
```
令 a=b=1: (1+1)^n = ∑C(n,k) = 2^n
```

### 推论2: 奇偶系数和
```
令 a=1,b=-1: (1-1)^n = 0
→ C(n,0)-C(n,1)+C(n,2)-... = 0
→ 奇项和 = 偶项和 = 2^(n-1)
```

### 动画序列
