# 二项式定理

## 概述
二项式定理：(a+b)ⁿ=∑C(n,k)aⁿ⁻ᵏbᵏ（k从0到n）=C(n,0)aⁿ+C(n,1)aⁿ⁻¹b+...+C(n,n)bⁿ。通项公式：Tₖ₊₁=C(n,k)aⁿ⁻ᵏbᵏ是展开式的第k+1项。二项式系数：C(n,0)，C(n,1)，...，C(n,n)，具有对称性。帕斯卡三角形（杨辉三角）直观展示二项式系数。二项式定理可推广到多项式展开。

## 数学公式
- (a+b)ⁿ = ΣC(n,k)a^(n-k)b^k
- 通项：T_{k+1} = C(n,k)a^(n-k)b^k
- (1+x)ⁿ = ΣC(n,k)x^k
- (a+b)ⁿ展开有n+1项
- C(n,0) + C(n,1) + ... + C(n,n) = 2ⁿ
- C(n,0) - C(n,1) + C(n,2) - ... = 0
