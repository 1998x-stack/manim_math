## Scene 3: 组合数公式 (15-30s)

**目的**: 推导组合数公式，理解由来

### 视觉元素
1. 标题"组合数公式"
2. C(n,m)符号说明
3. 公式推导过程动画
4. 数值示例 C(5,3)

### 动画序列
| 时间 | 动作 |
|------|------|
| 15.0s | 显示"排列数 → 组合数"的逻辑 |
| 16.5s | A(n,m) = C(n,m) × m! 分析 |
| 18.5s | 变形推导 C(n,m) = A(n,m)/m! |
| 20.5s | 展开 = n!/[(n-m)!m!] |
| 22.0s | 代入例子 C(5,3) |
| 24.0s | 计算过程 = 5!/(3!×2!) = 10 |
| 27.0s | 强调结果，等待 |

### 关键公式（全部MathTex）
- f1: r"C(n,m) = \frac{A(n,m)}{m!}"
- f2: r"= \frac{n!}{(n-m)! \cdot m!}"
- f3: r"C(5,3) = \frac{5!}{3! \cdot 2!} = \frac{120}{6 \times 2} = 10"
