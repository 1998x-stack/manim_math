## 关键坐标计算

```python
# 斜二测变换公式
def oblique(x, y, scale=1.0):
    cos45 = np.sqrt(2) / 2  # ≈ 0.7071
    sin45 = np.sqrt(2) / 2
    draw_x = x * scale + (y / 2) * cos45 * scale
    draw_y = (y / 2) * sin45 * scale
    return np.array([draw_x, draw_y, 0])

# 矩形ABCD (W=3, H=2, UNIT=0.85)
# 原坐标（俯视）  →  斜二测坐标
# A(0,0)         →  A'(0,    0)
# B(3,0)         →  B'(2.55, 0)  [x不变]
# C(3,2)         →  C'(2.55+0.6, 0.6) = C'(3.15, 0.6)
# D(0,2)         →  D'(0+0.6, 0.6) = D'(0.6, 0.6)
# 屏幕偏移: 加上 DRAW_OFFSET = (-1.35, 1.2)
```
