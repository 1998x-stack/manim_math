## Scene 1: 开场 (5s)
1. 作者信息顶部固定帧
2. "棱台是什么？"钩子文字
3. 3D 正四棱台从无到有生长（下底→侧棱→上底→侧面）
4. 相机绕轴缓慢旋转一圈展示立体感

## Scene 2: 定义——棱台的由来 (10s)
1. "棱台 = 棱锥被截面切开后下面的部分"
2. 先显示完整棱锥（含phantom顶点Apex）
3. 截面（半透明黄色平面）从上方降下
4. 上方部分淡出，剩下棱台
5. 文字：两个平行底面，侧面是梯形

## Scene 3: 各部分标注 (12s)
1. 下底 ABCD（大）— 高亮
2. 上底 A'B'C'D'（小）— 高亮
3. 侧棱 AA'（斜线）
4. 高 h（竖直虚线 + 直角标记）
5. 斜高 l'（底边中点→上底边中点）

## Scene 4: 正棱台性质 (8s)
1. ①两底面相似的正多边形（上下同时高亮）
2. ②侧面全等等腰梯形（一面高亮）
3. ③侧棱相等（4条侧棱同时变黄）
4. 相机旋转展示对称性

## Scene 5: 体积公式推导 (15s)
1. 直观：棱台 = 大棱锥 - 小棱锥
2. 大棱锥体积 V大 = 1/3 S2 * h_pyr
3. 小棱锥体积 V小 = 1/3 S1 * (h_pyr - h)
4. V = V大 - V小 → 化简
5. 最终公式框：V = h/3·(S上 + S下 + √(S上·S下))
6. 代入数值计算

## Scene 6: 侧面积公式 (8s)
1. 展开一个侧面（等腰梯形高亮）
2. 斜高 l' 标注
3. S侧 = ½(C上 + C下)·l'
4. 代入数值

## Scene 7: 公式速记 + 片尾 (7s)
1. 公式速记卡（固定帧）
2. 环境旋转展示棱台美感
3. 作者信息 + 关注提示
