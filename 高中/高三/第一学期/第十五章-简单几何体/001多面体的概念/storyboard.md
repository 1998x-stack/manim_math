# 多面体概念教学动画 - 分镜脚本

## 元信息
- 目标时长: 75-90秒
- 场景数量: 8个场景
- 难度等级: 高三水平
- 格式: TikTok竖屏 (1080×1920)
- 主题: 多面体的定义、分类和欧拉公式

## 颜色配置
```python
COLOR_PRIMARY = "#3498db"        # 蓝色 - 主要多面体
COLOR_SECONDARY = "#e74c3c"      # 红色 - 强调元素（顶点）

COLOR_AUXILIARY = GRAY_B         # 灰色 - 辅助线

```

## 3D相机配置
```python
# 初始相机角度
phi = 70 * DEGREES      # 仰角
theta = -45 * DEGREES   # 方位角

# 相机位置
self.set_camera_orientation(phi=phi, theta=theta)
```

## 关键技术要点
1. **3D场景使用ThreeDScene**
2. **相机控制**：
   - `set_camera_orientation(phi, theta)`
   - `begin_ambient_camera_rotation(rate)`
   - `move_camera(phi, theta)`
3. **3D对象**：
   - `Tetrahedron()`, `Cube()`, `Octahedron()`
   - `Dodecahedron()`, `Icosahedron()`
4. **顶点/棱/面的访问**：
   - `.get_vertices()`返回顶点坐标数组
   - 需要手动标注棱和面
5. **标注用3D元素**：
   - `Dot3D()` - 3D点
   - `Line3D()` - 3D线
   - 文字用`Text()`放在固定2D层
