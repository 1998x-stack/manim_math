# 平面的基本性质

## 概述
平面是无限延展的平坦的面，通常用希腊字母α、β、γ等表示。平面的三个公理：①公理1：如果一条直线上的两点在一个平面内，那么这条直线上所有的点都在这个平面内；②公理2：过不在同一条直线上的三点有且只有一个平面；③公理3：如果两个不重合的平面有一个公共点，那么它们有且只有一条过该点的公共直线。确定平面的条件：不共线三点、一条直线和直线外一点、两条相交直线、两条平行直线。

## 数学公式
- 公理1：A ∈ l, B ∈ l, A ∈ α, B ∈ α ⇒ l ⊂ α
- 公理2：A, B, C不共线 ⇒ 存在唯一平面α过A, B, C
- 公理3：α ∩ β = {P} ⇒ α ∩ β = l (P ∈ l)
