# 平面的基本性质 - 动画分镜脚本

## 元信息
- 目标时长: ~60 秒
- 场景数量: 7 个
- 难度等级: 高三

## 颜色配置
```python
BG_COLOR = "#1a1a2e"
COLOR_PLANE_ALPHA = "#4FC3F7"   # 浅蓝色平面α
COLOR_PLANE_BETA  = "#A5D6A7"   # 浅绿色平面β
COLOR_LINE        = "#FFD54F"   # 黄色直线
COLOR_POINT       = "#FF8A65"   # 橙色点
COLOR_FORMULA     = WHITE
COLOR_HIGHLIGHT   = "#F06292"   # 粉红高亮
COLOR_AXIOM       = "#CE93D8"   # 紫色公理标题
```

## 平面视觉设计
平面用带透明填充的平行四边形表示（透视效果）

基础平面α坐标（在主内容区中心）:
- 左下: (-3.0, -0.5)
- 右下: ( 3.0, -0.5)
- 右上: ( 2.0,  1.5)
- 左上: (-2.0,  1.5)

平面β（稍微倾斜，用于公理3演示）

## Scene 1: 开场钩子 (0-4s)
**目的**: 引出主题，吸引学生注意

### 元素
1. 作者信息 (顶部, y=7)
2. 钩子问题 (大字)
3. 三角架图示

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 作者信息淡入 |
| 0.5s | 钩子文字 Write: "三脚架为什么稳？" |
| 1.5s | 显示三个点A,B,C |
| 2.5s | 显示平面穿过三点 |
| 3.5s | 等待 |

---

## Scene 2: 平面的概念 (4-10s)
**目的**: 介绍平面的定义和符号表示

### 元素
1. 标题 "平面"
2. 平行四边形（代表平面α）
3. α 标签
4. 说明文字

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 标题淡入 |
| 0.5s | 平面α创建 |
| 1.5s | α标签 |
| 2.5s | 说明文字："无限延展的平坦面" |
| 3.5s | 箭头指向各方向 |

---

## Scene 3: 公理1 (10-20s)
**目的**: 直线上两点在平面内 → 直线在平面内

### 元素
1. 公理1标题
2. 平面α
3. 直线l
4. 点A, B (在直线上，在平面内)
5. 所有点都在平面内的动画
6. 公式: A∈l, B∈l, A∈α, B∈α ⇒ l⊂α

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 公理1标题 |
| 1.0s | 平面α |
| 2.0s | 直线l (先画在平面外) |
| 3.0s | 标记A, B两点 |
| 4.0s | 条件"A,B在平面α上"高亮 |
| 5.0s | 直线整体移入平面 |
| 6.0s | 结论 l⊂α |
| 7.0s | 等待消化 |

---

## Scene 4: 公理2 (20-30s)
**目的**: 不共线三点确定唯一平面

### 元素
1. 公理2标题
2. 三点A, B, C (不共线)
3. 唯一平面α从三点展开
4. 对比：共线三点→不能确定唯一平面

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 公理2标题 |
| 1.0s | 显示三个不共线点 |
| 2.0s | 强调"不共线" |
| 3.0s | 平面从三点扩展展开 |
| 4.0s | 公式显示 |
| 5.0s | 等待 |

---

## Scene 5: 公理3 (30-42s)
**目的**: 两不重合平面有公共点 → 有且只有一条公共直线

### 元素
1. 公理3标题
2. 平面α (蓝色)
3. 平面β (绿色)
4. 公共点P (在两平面交线上)
5. 交线l 动画展现

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 公理3标题 |
| 1.0s | 两平面分别出现 |
| 3.0s | 两平面靠近，产生公共点P |
| 5.0s | 公共直线l 闪现 |
| 6.0s | 公式 α∩β = l |
| 7.0s | 等待 |

---

## Scene 6: 确定平面的4个条件 (42-54s)

### 元素

| 条件 | 描述 |

| ② | 一条直线和直线外一点 |
| ③ | 两条相交直线 |
| ④ | 两条平行直线 |
