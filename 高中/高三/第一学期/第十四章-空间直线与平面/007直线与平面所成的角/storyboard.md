# 直线与平面所成的角

## 概述
斜线：与平面相交但不垂直的直线。斜线与平面所成的角：斜线与它在平面上的射影所成的锐角，范围[0,π/2)。当直线与平面垂直时，规定所成角为90°；当直线与平面平行或在平面内时，规定所成角为0°。求线面角的方法：①找出斜线在平面上的射影；②计算斜线与射影的夹角。最小角定理：斜线与平面内所有直线所成角中，与射影所成的角最小。

## 数学公式
- 线面角 θ ∈ [0, π/2]
- l 与 α 所成角 = l 与射影的夹角
- sin θ = 斜线上一点到平面距离 / 该点到斜足距离
- cos θ = 射影长 / 斜线长
