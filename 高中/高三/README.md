# 高三课件：审查、修复与验收

范围：`高中/高三/第一学期`（第十四章空间直线与平面、第十五章简单几何体、第十六章排列组合与二项式定理）和 `高中/高三/第二学期`（第十七章概率论初步、第十八章基本统计方法）。现有课件脚本和视频保持原有路径，避免破坏目录引用。

## 已核实、可机械修复的缺陷

| 课件 | 缺陷 | 预期修复 |
| --- | --- | --- |
| `第二学期/第十七章-概率论初步/005条件概率与独立事件/cond_prob_animation.py` | 全概率示例 `0.3×0.8+0.4×0.5+0.3×0.3` 被显示为 `0.52` | 改为 `0.53`：`0.24+0.20+0.09=0.53`。 |
| `第二学期/第十七章-概率论初步/003频率与概率/freq_prob_animation.py` | `np.random.seed(42)` 修改全局随机状态；解释性文字暗示试验次数增加时误差逐次下降 | 使用场景自己的 `default_rng(42)`；说明长程趋势，不保证单次试验后更接近概率。 |
| `第一学期/第十五章-简单几何体/001多面体的概念/polyhedron_concepts.py` | 欧拉公式数据校验仅打印警告，错误数据仍可继续渲染 | 校验失败时抛出 `ValueError`。 |

由于涉及现有较长的 Manim 脚本，`tools/repair_known_issues.py` 使用精确锚点进行保守修复；只修改以上三个文件，先验证所有锚点及修复后的 Python 语法，再写入。若上游源码发生变化或锚点重复，则报错停止，**不要对未知版本进行模糊替换**。请先在独立工作分支运行，并审阅 `git diff`。

```bash
python 高中/高三/tools/repair_known_issues.py           # 只检查；有待修复项时退出码 1
python 高中/高三/tools/repair_known_issues.py --apply   # 实际修改原有课件源码
python 高中/高三/tools/repair_known_issues.py           # 修复后应显示 Pending: 0 edits
python 高中/高三/tools/audit_grade12.py                 # 全量离线审查 Python/JSON
python -m unittest discover -s 高中/高三/tests -v
```

`audit_grade12.py` 不导入 Manim 课件，避免触发课件导入时的全局 `config` 副作用。默认仅将明确的语法/JSON/静态算式或欧拉计数不变量失败作为错误；`GLOBAL_RNG`、`IMPORT_CONFIG`、`LLN_WORDING` 是人工复核警告。加 `--json` 可输出结构化结果；加 `--strict` 可将警告作为失败。静态审查**无法证明视频已能渲染，也无法自动证明每道数学题均正确**。

## 分章节人工审查矩阵（未审查项不可标记为已修复）

| 章节 | 数学核对 | 动画核对 |
| --- | --- | --- |
| 十四：空间直线与平面 | 位置关系、平行垂直的条件、投影与角度范围 | 相机深度、虚实线区分、遮挡及标注随相机移动的行为 |
| 十五：简单几何体 | 面/棱/顶点计数、欧拉公式适用前提、体积和表面积单位 | 形体尺寸、法向量、面透明度和三维视角 |
| 十六：排列组合与二项式定理 | 分类是否互斥、分步是否独立选择、顺序与重复限制、组合边界 `0≤k≤n` | 树图叶节点、重复方案计数、公式与枚举数量对应 |
| 十七：概率论初步 | 条件概率的 `P(B)>0` 前提、互斥与独立区分、全概率划分、随机模拟模型 | 样本频率与基准线是否对应、坐标变换后标签和曲线是否仍对应 |
| 十八：基本统计方法 | 样本/总体区分、分母 `n` 与 `n−1` 的选择、频率直方图面积、抽样偏差 | 直方图宽度/高度与频率密度关系、坐标刻度与实际数据一致 |

## 验收标准

1. `python -m unittest discover -s 高中/高三/tests -v` 通过；审计报告没有未解释的 `error`。
2. 检查每个课件的真实 Manim 场景入口，先渲染低清片段，再渲染完整视频；不得仅用 AST 检查代替 Manim 渲染。
3. 按每个 `prompt.md` / `storyboard.md` 核对文案及镜头；关键公式和示例使用独立数学计算复核。
4. 查看实际 9:16 画面，在标题/字幕/公式/坐标标注等最大尺寸时检查裁切、叠压、对比度和阅读时长。
5. 仅在原脚本已真实更新、测试通过、视频复核后，才能将该课件记为“完成修复”。已有 `_finish.mp4` 不能自动视为本次修改后的回归测试结果。

## 当前边界

本目录提供已核实问题的保守修复工具及静态审查框架；**工具文件本身不会自动改写原有课件**，只有显式运行 `--apply` 才会修改源文件。其余课件仍需要逐个进行数学复核和视频审阅；不要将本轮审查记录解读为高三所有动画已经修复或重新渲染。
