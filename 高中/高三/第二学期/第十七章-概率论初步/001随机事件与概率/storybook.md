# 随机事件与概率

## 概述
随机试验：在相同条件下可重复进行，所有可能结果已知但具体哪个结果出现事先不确定。随机事件：随机试验的结果，用A、B、C等表示。必然事件：每次试验一定发生的事件，概率为1。不可能事件：每次试验一定不发生的事件，概率为0。概率：事件发生的可能性大小的数值度量，0≤P(A)≤1。概率具有非负性、规范性、可加性。

## 数学公式
- 0 ≤ P(A) ≤ 1
- P(必然事件) = 1
- P(不可能事件) = 0
- P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
- P(A) + P(Ā) = 1
