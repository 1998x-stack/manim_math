# 线性回归

## 概述
当两个变量之间存在相关关系时，可用回归分析方法研究其关系。散点图可直观展示变量间的关系。线性回归：用直线ŷ=bx+a来拟合数据的方法。最小二乘法：使所有点到直线的距离平方和最小。回归系数：b=Σ(xᵢ-x̄)(yᵢ-ȳ)/Σ(xᵢ-x̄)²，a=ȳ-bx̄。回归直线必过点(x̄,ȳ)。相关系数r衡量线性相关程度，|r|越接近1，相关性越强。

## 数学公式
- 回归直线：ŷ = bx + a
- b = Σ(xᵢ-x̄)(yᵢ-ȳ)/Σ(xᵢ-x̄)²
- b = (Σxᵢyᵢ - nx̄ȳ)/(Σxᵢ² - nx̄²)
- a = ȳ - bx̄
- 相关系数：r = Σ(xᵢ-x̄)(yᵢ-ȳ)/√[Σ(xᵢ-x̄)²Σ(yᵢ-ȳ)²]
