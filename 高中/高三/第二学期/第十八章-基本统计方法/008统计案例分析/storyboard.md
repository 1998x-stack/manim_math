## 案例数据（吸烟与肺癌）
```
          患肺癌  未患肺癌  合计
吸烟       43      162      205
不吸烟      5      192      197
合计       48      354      402

a=43, b=162, c=5, d=192
n=402
χ² = 402×(43×192 - 162×5)² / (205×197×48×354)
   = 402×(8256-810)² / (205×197×48×354)
   = 402×7446² / 683,608,560
   ≈ 402×55,443,316 / 683,608,560
   ≈ 32.57
```

## 验证数据
- a+b = 205, c+d = 197, a+c = 48, b+d = 354
- n = 402
- ad - bc = 43×192 - 162×5 = 8256 - 810 = 7446
- χ² ≈ 32.57 >> 6.635
- 结论: 在0.01显著性水平下，吸烟与肺癌显著相关

## Scene 4: χ²公式 (8秒)
**目的**: 展示卡方公式和字母含义
