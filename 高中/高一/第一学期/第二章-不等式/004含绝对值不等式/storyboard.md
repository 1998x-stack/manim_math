## 元信息
- 目标时长: ~75 秒
- 场景数量: 6 个
- 难度等级: 高一第一学期

## Scene 1: 开场钩子 (4秒)
**目的**: 抛出问题，吸引学生注意

### 元素
- 作者信息 (顶部)
- 大问题文字: "你能解这道题吗？"
- 不等式: |x-2| < 3

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 作者信息 FadeIn |
| 0.5s | 问题文字 Write |
| 1.5s | 不等式 Write |
| 2.5s | 等待 1.5s |

---

## Scene 2: 绝对值几何意义 (12秒)
**目的**: 用数轴说明|x|是距离

### 元素
- NumberLine (x ∈ [-5, 5])
- 原点 O 标记
- 点 x 在数轴上移动
- 距离箭头 + 标注 |x|
- 文字说明

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 创建数轴 |
| 1.0s | 标记原点 O |
| 2.0s | 点 P(x=3) 出现 |
| 3.0s | 双向箭头显示距离=3 |
| 4.0s | |x| = 3 公式 |
| 5.5s | 点移到 x=-3, 距离仍为3 |
| 7.0s | 文字: "绝对值=到原点的距离" |

---

## Scene 3: |x|<a 型不等式 (15秒)
**目的**: 可视化解集

### 元素
- NumberLine
- a=3 标记
- 区间 (-3, 3) 高亮
- 公式 |x|<a ⟺ -a<x<a

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 数轴 + |x| < 3 公式 |
| 2.0s | "距离原点<3的x" |
| 3.5s | 区间 (-3,3) 高亮 |
| 5.5s | 转化公式: -3<x<3 |
| 7.0s | 通用公式 |x|<a ⟺ -a<x<a |

---

## Scene 4: |x|>a 型不等式 (12秒)
**目的**: 可视化两段解集

### 元素
- NumberLine
- 两段高亮 x<-3 和 x>3
- 公式 |x|>a ⟺ x<-a 或 x>a

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 数轴 + |x| > 3 公式 |
| 1.5s | "距离原点>3" |
| 3.0s | 左段 x<-3 高亮 |
| 4.5s | 右段 x>3 高亮 |
| 6.0s | 转化公式 |
| 8.0s | 通用公式 |

---

## Scene 5: 例题解析 |x-2|<3 (18秒)
**目的**: 解题步骤 + 几何意义

### 元素
- 问题: |x-2| < 3
- 方法1: 公式法
- 方法2: 数轴几何法 (x-2距离原点<3, 等价x到2的距离<3)
- 解集高亮

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 例题显示 |
| 2.0s | 利用公式 |
| 4.0s | -3<x-2<3 |
| 6.0s | 两边+2: -1<x<5 |
| 8.0s | 数轴展示 (-1, 5) 区间 |
| 12.0s | 几何意义: x到2距离<3 |

---
