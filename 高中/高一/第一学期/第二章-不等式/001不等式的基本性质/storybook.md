# 不等式的基本性质

## 概述
不等式的基本性质包括：对称性（a>b⟺b<a）、传递性（a>b,b>c⟹a>c）、加法法则（a>b⟹a+c>b+c）、乘法法则（a>b,c>0⟹ac>bc；a>b,c<0⟹ac<bc）。这些性质是解不等式和证明不等式的基础。乘以负数时不等号要变向是常见易错点。

## 数学公式
- a > b ⟺ b < a
- a > b, b > c ⇒ a > c
- a > b ⇒ a + c > b + c
- a > b, c > 0 ⇒ ac > bc
- a > b, c < 0 ⇒ ac < bc
- a > b > 0 ⇒ a² > b²
