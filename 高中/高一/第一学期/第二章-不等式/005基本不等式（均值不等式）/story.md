# 基本不等式（均值不等式）

## 概述
基本不等式：对于正实数a,b，有(a+b)/2≥√(ab)，即算术平均数≥几何平均数，当且仅当a=b时取等号。应用条件「一正二定三相等」：①各项为正；②和或积为定值；③能取到等号。常用变形：a+b≥2√(ab)，ab≤(a+b)²/4。可推广到调和平均数≤几何平均数≤算术平均数≤平方平均数。

## 数学公式
- (a + b)/2 ≥ √(ab) (a,b > 0)
- a + b ≥ 2√(ab)
- ab ≤ (a + b)²/4
- a²+ b² ≥ 2ab
- a/b + b/a ≥ 2 (a,b同号)
- √((a² + b²)/2) ≥ (a + b)/2 ≥ √(ab) ≥ 2/(1/a + 1/b)
