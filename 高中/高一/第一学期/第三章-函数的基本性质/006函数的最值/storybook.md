# 函数的最值

## 概述
设函数y=f(x)的定义域为D。若存在x₀∈D使得对所有x∈D都有f(x)≤f(x₀)，则f(x₀)为最大值；若f(x)≥f(x₀)，则f(x₀)为最小值。求最值方法：①利用单调性（单调函数在闭区间端点取最值）；②配方法（二次函数）；③基本不等式；④数形结合。注意最值与极值的区别，最值是整体概念，极值是局部概念。

## 数学公式
- 最大值：∀x ∈ D, f(x) ≤ f(x₀)
- 最小值：∀x ∈ D, f(x) ≥ f(x₀)
- 闭区间上连续函数必有最值
- 二次函数：y = a(x - h)² + k
