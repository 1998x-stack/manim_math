## Scene 2: 单调递增定义 (10秒)
**目的**: 可视化定义

### 元素
1. 坐标轴 + 递增函数图像（y = x³ 或 y = x 简单示意）
2. 在区间I上标注两个点 x₁ < x₂
3. 对应函数值 f(x₁) < f(x₂)
4. 竖直虚线辅助线
5. 定义公式
6. 文字说明

### 关键坐标预计算
- x1 = -1, x2 = 1（在坐标轴上的逻辑坐标）
- f(x) = x（为简单演示）
- f(x1) = -1, f(x2) = 1

### 动画序列

| 0.0s | Create(axes) + 标题"增函数" |
| 1.0s | Create(graph_increase) 绿色 |

| 9.5s | 清理 |

## Scene 5: 作差法（定义法）(12秒)
**目的**: 严格证明方法

### 元素
1. 以 f(x) = x² 为例
2. 分步骤展示作差
   - 令 x₁ < x₂ < 0
   - f(x₁) - f(x₂) = x₁² - x₂²
   - = (x₁+x₂)(x₁-x₂)
   - 分析正负号
3. 结论
