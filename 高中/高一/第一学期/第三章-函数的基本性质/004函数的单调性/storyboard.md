# 函数的单调性

## 概述
设函数y=f(x)的定义域为D，区间I⊆D。若对任意x₁,x₂∈I，当x₁<x₂时，有f(x₁)<f(x₂)，则f在I上单调递增；有f(x₁)>f(x₂)，则f在I上单调递减。单调性判断方法：①定义法（作差或作商）；②图像法（从左到右上升或下降）；③导数法（f'(x)>0递增，f'(x)<0递减）。单调性是函数最重要的性质之一。

## 数学公式
- 单调递增：x₁ < x₂ ⇒ f(x₁) < f(x₂)
- 单调递减：x₁ < x₂ ⇒ f(x₁) > f(x₂)
- 作差法：(f(x₁) - f(x₂))/(x₁ - x₂) > 0 递增
- f'(x) > 0 递增
- f'(x) < 0 递减
