# 集合的运算

## 概述
交集：由所有既属于A又属于B的元素组成的集合，记作A∩B。并集：由所有属于A或属于B的元素组成的集合，记作A∪B。补集：设全集为U，由U中所有不属于A的元素组成的集合称为A在U中的补集，记作∁ᵤA。交集、并集满足交换律和结合律。文氏图（韦恩图）是表示集合运算的直观工具。

## 数学公式
- A ∩ B = {x | x ∈ A 且 x ∈ B}
- A ∪ B = {x | x ∈ A 或 x ∈ B}
- ∁ᵤA = {x | x ∈ U 且 x ∉ A}
- A ∩ ∅ = ∅
- A ∪ ∅ = A
- (∁ᵤA) ∪ A = U
- (∁ᵤA) ∩ A = ∅
