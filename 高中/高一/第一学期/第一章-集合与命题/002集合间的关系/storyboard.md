# 002 集合间的关系｜可核验分镜

对应源码 `set_relations.py::SetRelationsAnimation`，分镜仅描述当前修改后的八镜教学内容，不代表旧 MP4 已同步生成。布局目标 9×16；实际字体、文字包围盒、转场须渲染复查。

## 数学规格与设计约束

- 第一至第三镜：`A={1,2,3}`，`B={1,2,3,4,5}`，因此 `A⊆B`、`A⊊B`、`A≠B`；圆 A 中心 `(-0.5,2)`，半径 `1.2`，圆 B 中心 `(0,2)`，半径 `2.0`。中心距离 `0.5`，`0.5+1.2<2.0` 保证真包含示意。
- 第四镜**另取** `C={1,2,3}`、`D={3,2,1}`，所以 `C⊆D` 且 `D⊆C`，集合相等；两个示意圆同中心同半径。不能把前面仍含 4、5 的集合 B 直接表述为与 A 相等。
- 第五镜集合 `A={1,2,3}` 非空：`∅⊆A`；`∅⊊A` 仅在 `A≠∅` 时成立。`∅⊊∅` 不成立。
- 第六、七镜使用 `A={1,2,3}`：共有 `2³=8` 个子集，包含空集与 A 本身；真子集数为 `2³−1=7`，一般式为 `2ⁿ` 与 `2ⁿ−1`，适用于有限、含 n 个元素的集合（包括 n=0）。

| 镜头 | learning_fact / 屏上可见状态 | 对象引用与清理 | check / 关键帧 |
|---|---|---|---|
| 1 开场 | 列举 A 与 B 的成员，引出包含问题 | 开场公式出现并清除 | 两集合的具体元素清楚可见 |
| 2 子集 | 内圆 A 的 1/2/3 都处于外圆 B 内，另有 4/5 在 B 中 | `self.diagram` 持有整个实际示意图 | 圆完整包含；B 额外的两点不能进入 A |
| 3 真子集 | 高亮真实 `self.extra_points`，公式 `A⊊B` 且 `A≠B` | 使用第二镜同一批点；结束移除 `self.diagram` | 文案与额外元素 4/5 一致，清场无残影 |
| 4 集合相等 | 切换到 C 与 D，两圆重合，3 个元素相同；双向包含得出 `C=D` | 新建独立 `diagram`，结束全部清理 | 不错误继承前镜 B 的 4/5；两圆中心与半径相同 |
| 5 空集 | `A={1,2,3}` 非空；分别显示 `∅⊆A` 与 `A≠∅⇒∅⊊A` | 临时创建新的 A 圆与元素并清理 | 不误写空集是真子集的无条件命题 |
| 6 子集计数 | 使用 `combinations` 从真实的 3 元素生成 8 个子集卡片 | `self.subset_cards` 一直持有在屏上的同一组对象 | 8 张卡片恰好各出现一次，含 `∅` 和 A 本身 |
| 7 真子集计数 | 最后一张卡片是 A 本身，移除该原始对象，仅剩 7 张 | 对 `self.subset_cards[-1]` 原对象淡出，再清除其余 7 张 | 计数 7 与实际剩余卡片一致；n=0 结果为 0 |
| 8 总结 | 子集、真子集、双向包含、空集与计数公式 | 总结退出后移除顶部作者信息 | 竖屏长公式不裁切，纯 LaTeX 公式不含中文 |
