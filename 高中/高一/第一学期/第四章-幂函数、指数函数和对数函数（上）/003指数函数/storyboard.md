# 指数函数

## 概述
指数函数是形如y=aˣ（a>0且a≠1）的函数。定义域为R，值域为(0,+∞)，恒过点(0,1)。当a>1时，函数单调递增，图像在y=1上方逐渐上升；当0<a<1时，函数单调递减，图像在y=1上方逐渐下降。y=0（x轴）是水平渐近线。指数函数的增长速度很快，是自然界和经济学中常见的增长模型。

## 数学公式
- y = aˣ (a > 0 且 a ≠ 1)
- 定义域：R
- 值域：(0, +∞)
- a > 1：单调递增
- 0 < a < 1：单调递减
- 过定点(0, 1)
- 渐近线：y = 0
