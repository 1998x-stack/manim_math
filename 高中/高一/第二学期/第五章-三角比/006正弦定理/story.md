# 正弦定理

## 概述
在任意三角形ABC中，a/sin A=b/sin B=c/sin C=2R，其中a、b、c分别是角A、B、C的对边，R是三角形外接圆半径。正弦定理揭示了三角形边角之间的关系，可用于：①已知两角及一边求其他边；②已知两边及其中一边的对角求其他角（可能有两解、一解或无解）。变形式：a=2R sin A，sin A/a=sin B/b=sin C/c=1/(2R)。

## 数学公式
- a/sin A = b/sin B = c/sin C = 2R
- a = 2R sin A
- b = 2R sin B
- c = 2R sin C
- sin A : sin B : sin C = a : b : c
