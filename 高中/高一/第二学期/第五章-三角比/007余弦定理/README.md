# 余弦定理教学动画

这个项目实现了余弦定理的Manim动画演示，适用于高一学生的三角比章节教学。

## 内容简介

在任意三角形ABC中：
- a² = b² + c² - 2bc cos A
- b² = a² + c² - 2ac cos B
- c² = a² + b² - 2ab cos C

余弦定理是勾股定理的推广（当A=90°时，cos A=0，得a²=b²+c²）。可用于：
- 已知三边求各角
- 已知两边及夹角求第三边

## 运行动画

```bash
# 快速预览（低质量）
manim -pql "007_余弦定理.py" CosineTheoremAnimation

# 高质量渲染
manim -qh "007_余弦定理.py" CosineTheoremAnimation

# 渲染为GIF
manim -qh --format=gif "007_余弦定理.py" CosineTheoremAnimation
```
