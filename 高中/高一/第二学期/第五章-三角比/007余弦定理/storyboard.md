# 余弦定理

## 概述
在任意三角形ABC中，a²=b²+c²-2bc cos A，b²=a²+c²-2ac cos B，c²=a²+b²-2ab cos C。余弦定理是勾股定理的推广（当A=90°时，cos A=0，得a²=b²+c²）。可用于：①已知三边求各角；②已知两边及夹角求第三边。推论：cos A=(b²+c²-a²)/(2bc)。余弦定理还可以用来判断三角形的形状（锐角、直角、钝角）。

## 数学公式
- a² = b² + c² - 2bc cos A
- b² = a² + c² - 2ac cos B
- c² = a² + b² - 2ab cos C
- cos A = (b² + c² - a²)/(2bc)
- cos B = (a² + c² - b²)/(2ac)
- cos C = (a² + b² - c²)/(2ab)
