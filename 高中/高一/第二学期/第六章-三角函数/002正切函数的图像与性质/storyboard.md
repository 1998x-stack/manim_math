# 正切函数的图像与性质

## 概述
正切函数y=tan x：定义域{x|x≠π/2+kπ, k∈Z}，值域R，最小正周期π，奇函数，在每个开区间(-π/2+kπ, π/2+kπ)上单调递增。图像有无穷多条垂直渐近线x=π/2+kπ。图像关于原点对称，过原点。与正弦、余弦函数相比，正切函数的值域是全体实数，没有最大值和最小值。正切函数在研究倾斜角、斜率等问题中有重要应用。

## 数学公式
- y = tan x = sin x / cos x
- 定义域：{x | x ≠ π/2 + kπ, k∈Z}
- 值域：R
- 周期：π
- tan(-x) = -tan x（奇函数）
- 渐近线：x = π/2 + kπ
