# 对数的概念与运算

## 概述
若aˣ=N（a>0,a≠1,N>0），则x称为以a为底N的对数，记作x=log_a N。a为底数，N为真数。常用对数：lg N=log₁₀ N；自然对数：ln N=log_e N（e≈2.718）。对数恒等式：a^(log_a N)=N。运算法则：log_a(MN)=log_a M+log_a N，log_a(M/N)=log_a M-log_a N，log_a Mⁿ=n log_a M。换底公式：log_a b=log_c b/log_c a。

## 数学公式
- aˣ = N ⟺ x = log_a N
- a^(log_a N) = N
- log_a aⁿ = n
- log_a 1 = 0
- log_a a = 1
- log_a(MN) = log_a M + log_a N
- log_a(M/N) = log_a M - log_a N
- log_a Mⁿ = n log_a M
- 换底公式：log_a b = (log_c b)/(log_c a)
