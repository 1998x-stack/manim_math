# 指数方程和对数方程

## 概述
指数方程是未知数在指数位置的方程，如aˣ=b。解法：①同底数法（化为同底比较指数）；②取对数法（两边取对数）；③换元法（令t=aˣ）。对数方程是未知数在真数或底数位置的方程，如log_a x=b。解法：①利用对数定义转化为指数形式；②利用对数运算性质；③换元法。解后必须验证真数>0、底数>0且≠1。

## 数学公式
- aˣ = b ⟺ x = log_a b
- log_a x = b ⟺ x = aᵇ
- aᶠ⁽ˣ⁾ = aᵍ⁽ˣ⁾ ⟺ f(x) = g(x)
- log_a f(x) = log_a g(x) ⟺ f(x) = g(x) > 0
