# 分学段教学设计与类型路由

## 小学

低年级使用逐个高亮计数、一一对应、数位分组、实际操作与短句；避免突然引入变量符号。中年级按场景选择竖式、数轴、单位换算、正方形/长方形面积模型。高年级在小数/分数/比例中强调单位、分母非零与等价变形。计数课核对显示对象数量、报数及总数是否完全相同；竖式核对进退位；分数模型核对等份；面积模型核对单位平方与公式数值。没有几何角度的课不要盲目跑三角形验证。

## 初中

代数式、同类项、乘法公式需要明确适用条件、变量域与简化步骤；纯符号命题可用 SymPy 或独立数学模型辅助核验，但抽样不替代证明。几何主题验证派生点、角与辅助线的实际构造及退化条件。函数检查定义域、截距、单调区间、奇点和端点开闭。概率题区分样本频率、理论概率和随机波动；不得演示每轮频率单调收敛。

## 高中

集合及命题明确元素、论域、条件与逆否；函数/三角/导数须保留定义域、参数限制和严格推导；解析几何展示参数退化分支；数列、统计、概率区分规律、计算、反例和推断。动画只作说明，不可替代数学证明。重点强调命题条件 → 结论 → 证明或反例的完整链条。

## 推荐的认知顺序

题目钩子 → 建立模型 → 操作演算 → 边界/反例 → 学生可复述的结论。每一镜只承载一个清晰学习事实，标定对象 create/update/remove、解说文字、目标停留时间与证据检查点。45–90 秒可作初始建议，但阅读时间优先。素材、品牌及音乐须另行核实授权。
