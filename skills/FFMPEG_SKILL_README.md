# FFmpeg Skill - 专业视频音频处理技能包

## 📋 概述

这是一个全面的 FFmpeg 技能包,基于 2025 年最新的 FFmpeg 版本(7.1.1/8.0.1)开发,为 Claude AI 提供专业级的多媒体文件处理能力。

## 🎯 技能特性

### 核心功能

1. **格式转换与转码**
   - 支持所有主流视频格式(MP4, AVI, MKV, MOV, WebM等)
   - 音频提取和转换
   - 智能编解码器选择

2. **视频操作**
   - 剪辑、合并、分割
   - 缩放和分辨率调整
   - 裁剪、旋转、翻转
   - 速度调整(加速/慢动作)

3. **高级过滤器**
   - 水印添加(文字/图像)
   - 视频稳定化
   - 降噪和锐化
   - 色彩校正和调整

4. **硬件加速**
   - NVIDIA GPU加速(NVENC/NVDEC)
   - CUDA过滤器支持
   - 多输出并行编码
   - 性能优化指南

5. **图像操作**
   - 帧提取
   - GIF创建
   - 图像序列转视频

6. **音频处理**
   - 音量调整和标准化
   - 音频混合
   - 速度调整
   - 降噪处理

7. **流媒体**
   - RTMP推流
   - HLS流媒体创建
   - 自适应码率编码

## 🚀 快速开始示例

### 基础格式转换
```bash
ffmpeg -i input.mov output.mp4
```

### 高质量H.264编码
```bash
ffmpeg -i input.mp4 -c:v libx264 -preset slow -crf 18 -c:a aac -b:a 192k output.mp4
```

### GPU加速编码
```bash
ffmpeg -hwaccel cuda -i input.mp4 -c:v h264_nvenc -preset p6 -rc vbr -cq 19 output.mp4
```

### 创建GIF
```bash
ffmpeg -i video.mp4 -vf "fps=15,scale=480:-1:flags=lanczos" output.gif
```

### 添加水印
```bash
ffmpeg -i video.mp4 -vf "drawtext=text='Copyright 2025':fontcolor=white:fontsize=24:x=10:y=10" output.mp4
```
