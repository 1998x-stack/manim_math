# Geometry precision / 几何精度

## 使用场景

涉及三角形中心、欧拉线、九点圆、相切、垂足、椭圆、运动点、交点、角度与连续构造的 Scene。结合 `docs/math/geometry/` 相关理论和 `docs/engineering/quality-gates.md`。

## 数学与工程边界

首先写定义域：三角形三点不能共线，直线方向向量不得为零；交点不存在、重合、数值病态需显式分类处理。以 `external/euler_line.py` 中 `circumcenter()` 在行列式近零时返回三点平均值为风险示例：重心一般不是退化三角形的外心，不能将占位值用于证明。应返回受检状态、抛出明确异常或在教学层跳过退化帧；修改原场景必须先提供回归测试。

## 分层流程

1. 从命题列出构造关系及不变量，如等距、垂直、共线、夹角、点在线上、圆半径相等等。所有点和向量使用一致坐标系与单位。
2. 将计算写成无 Manim 依赖的纯 Python 模块；二维叉积、点积、范数、行列式需区分符号和绝对值。数值比较采用按场景尺度设计的相对/绝对容差，而不是无解释地统一写死 `1e-10`。
3. 覆盖常规、平移、旋转、缩放、近退化、完全退化的测试样本；对小分母、几乎平行的线和近切线提供明确失败策略。
4. 对角度明确顶点、起始射线、方向和内角/优角语义；`Angle.from_three_points` 等方法必须核对 API 和顺逆时针约定，必要时计算有向角并测试示意图。
5. 将已验证坐标交给 Manim：点标、辅助线和弧不得修改计算结果；图形 `move_to`/`rotate` 后应验证实际呈现与数学模型的映射仍然一致。
6. 每个定理至少有独立的数学验证和关键帧视觉检查；数值抽样不能代替理论证明，缺失证据须标注为未验证。

## 可执行验收示例

欧拉线可用非退化三角形计算外心 O、重心 G、垂心 H、九点圆中心 N，检查 `||cross(G-O,H-O)||` 相对几何尺度足够小、`N≈(O+H)/2`、`G≈(2O+H)/3`（OG:GH=1:2，方向和位置需正确），并验证 O 对三顶点等距。对共线三点应明确拒绝外心计算而不是伪造成功。例子需在实际代码坐标定义下重新核对。
