# Chinese vertical layout / 中文竖屏版式

## 触发

字幕重叠、数学公式出框、中文字体缺失、文字缩放、竖屏排版或水印位置变化；动画创建阶段也应加载。现有项目常见目标为 1080×1920 和 Manim 画面 `frame_width=9` / `frame_height=16`；以目标平台规格和实际 Scene config 为准。

## 实施

1. 划分标题、水印、主要图形、推导/公式、结论/字幕和底部留白区域；以实际相机坐标而不是像素直接定位 Manim 对象。对界面裁切/平台覆盖区域保留弹性，不将固定 ±4、±7.5 当成所有场景恒定边界。
2. 中文说明用 `Text`，指定系统已有的中文字体并核对缺字回退；数学表达用 `MathTex`/`Tex` 和合法 LaTeX，避免未经环境配置就将汉字嵌入 `MathTex`。中英/数学混排可用 `VGroup(Text(...), MathTex(...)).arrange(...)`，分别控制基线、间距、缩放和包围盒。
3. 长公式分步呈现或换行并保留等号逻辑；不要通过无限缩小字体让画面“勉强塞下”。统一颜色语义，同一数学对象前后一致，高对比但不得仅靠颜色区分重要信息。
4. 对运动对象，在初始、中间、最大位移和终态计算 `get_left/right/top/bottom()` 或真实边界，检查字幕、水印、公式与主体碰撞；`add()`/`remove()`/`Transform` 后再验一次。
5. 低清渲染后查看关键帧的真实字形与安全区，检查中英文标点、负号/乘号、上下标、重叠、转场闪烁；最终高画质和平台预览需复核。

## 验收

观众在竖屏设备上能看清关键公式与中文；所有关键时间点图形完整、无遮挡、无缺字；只声明实际渲染和抽帧检查过的内容。无中文字体或 LaTeX 的运行环境下不能把语法检查当作排版检验通过。
