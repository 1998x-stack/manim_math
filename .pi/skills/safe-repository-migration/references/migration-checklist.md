# 可回退迁移：输入与验证清单

## 映射格式

```json
{"moves":[{"from":"docs/old.md","to":"docs/new.md","kind":"document","legacy_id":"unknown","public_url":"unknown"}]}
```

映射在审阅前只作为计划；`scripts/check_moves.py` 只读校验相对路径、不允许 `..`、重复起点/终点、无效自身移动和已有目标覆盖。即使校验成功，仍需人工核对软链接、导入路径、文件中引用的资源、线上 URL、画廊路径和许可。

## 最小回退纪律

- 保存原目录结构、已发布 URL 与原始媒体校验信息；识别可再生缓存和不可替代原件。
- 迁移文档时维护旧路径跳转；移动源码前先升级索引/部署监听及旧 ID 兼容。
- 不因名称相似合并知识点；多个知识点可以使用同一 Scene，但需明确注册。
- 分批提交；每批进行语法、适用的数学检查、低清渲染、画廊差异与链接验证；回退时还原与该批相关的索引和链接。

## 必须停止

计划中含未知版权的媒体批量重编码、目标已有文件但未准备保留方案、旧公开 URL 断裂、旧 ID 被自动重新计算、扫描器未识别新路径或无实际验证环境时，不进行不可逆迁移。
