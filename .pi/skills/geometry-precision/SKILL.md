# Geometry precision｜独立几何审查

本技能不需要外部 Skill；具体构造与失败案例见 `references/geometry-cases.md`。内置 `scripts/check_triangle.py` 使用 Python 标准库检测三角形退化并在有效时检查外心等距，仅用于数值回归，不构成一般证明。

## 执行流程

1. 为每个点、向量、角与圆声明坐标系、单位和定义域；区分有向角、内角与优角，不能根据角度超过 90° 就自动翻转方向。
2. 把几何关系转为独立不变量（点在线上、距离相等、垂直、共线、圆心与半径），先给出理论依据和存在条件，再设计数值断言。
3. 检查零向量、重合点、三点共线、近共线、平行直线、近切线；退化构造必须明确失败或跳过该帧，不得用重心等占位坐标冒充外心。
4. 回归样本至少包含普通、平移、旋转、缩放、近退化和完全退化。误差阈值依几何尺度确定；数值实验不等于定理证明。
5. 实现时让数学函数独立于 Manim，画面坐标和几何模型保持映射；低清预览确认角弧方向、点标和结论出现的时机。

## 交付

输出几何前提、构造公式、特殊情形策略、断言/样本、实际运行结果和剩余风险。可用 `python scripts/check_triangle.py --points '0,0;4,0;0,3'` 生成数值审计；不要求 NumPy/SymPy。更多样例和阈值说明按需加载 `references/geometry-cases.md`。
