# 课程索引、画廊兼容与安全迁移

## 兼容索引与分类

# 画廊数据契约与分类示例

当前兼容版 `assets/catalog.json` 的入口是 `levels[] → grades[] → semesters[] → chapters[] → topics[]`；旧 topic 常含 `id, number, name, docstring, pyFile, videoFile, hasVideo`。`videoFile=null` 时 `hasVideo=false`，旧路径与旧 ID 在兼容期原样保留。工具执行前保存基线，更新后按 ID 逐字段对比；已存在的视频不必然在稀疏检出中出现。

## 正交分类

课程位置（学段、年级、学期、教材、章节）与数学域（算术、几何、函数、统计等）分开管理；同一 Topic 可以属于多个课程定位与领域，未知信息留空。`external/` 不自动意味着高中内容。一个主题与 Scene/媒体不是一一对应；同目录多个 Python 文件、多个视频不能以第一个为权威。

## 静态失败样例

- 重复旧 `id`：报告冲突，不覆盖。
- `hasVideo=true` 且 `videoFile=null`：结构错误。
- 仅通过改名重新计算 ID：兼容性回归，应维护旧 ID 映射。
- 多个视频名都能模糊匹配：保留旧记录并标 `needs_review`，不根据第一个文件自动更新。

`check_catalog.py` 只读校验 JSON 结构；它不验证远程 URL/作品版权/数学真假，不能自行迁移 schema。

## 迁移映射与回退

# 可回退迁移：输入与验证清单

## 映射格式

```json
{"moves":[{"from":"docs/old.md","to":"docs/new.md","kind":"document","legacy_id":"unknown","public_url":"unknown"}]}
```

映射在审阅前只作为计划；`scripts/check_moves.py` 只读校验相对路径、不允许 `..`、重复起点/终点、无效自身移动和已有目标覆盖。即使校验成功，仍需人工核对软链接、导入路径、文件中引用的资源、线上 URL、画廊路径和许可。

## 最小回退纪律

- 保存原目录结构、已发布 URL 与原始媒体校验信息；识别可再生缓存和不可替代原件。
- 迁移文档时维护旧路径跳转；移动源码前先升级索引/部署监听及旧 ID 兼容。
- 不因名称相似合并知识点；多个知识点可以使用同一 Scene，但需明确注册。
- 分批提交；每批进行语法、适用的数学检查、低清渲染、画廊差异与链接验证；回退时还原与该批相关的索引和链接。

## 必须停止

计划中含未知版权的媒体批量重编码、目标已有文件但未准备保留方案、旧公开 URL 断裂、旧 ID 被自动重新计算、扫描器未识别新路径或无实际验证环境时，不进行不可逆迁移。
