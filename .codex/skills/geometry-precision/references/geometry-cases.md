# 动态几何核验案例

## 最小三角形检查

将 A=(0,0), B=(4,0), C=(0,3) 输入 `python scripts/check_triangle.py --points '0,0;4,0;0,3'`；预期非退化、外心 (2,1.5)、三顶点到外心距离相同。A=(0,0), B=(1,1), C=(2,2) 应拒绝求外心；不能用重心代替。平移、等比例缩放后，不变量应保持；过小三角形须依据模型尺度分析浮点条件数。

## 核心公式和边界

设二维向量 u、v，`cross(u,v)=u_x*v_y-u_y*v_x`；共线或平行需判断行列式接近零与尺度。数值容差同时考虑相对尺度和绝对下限，先写设计理由再确定具体阈值。法向量非零，直线参数化不能以零向量作为方向。

## 角度说明

计算 `atan2(cross(u,v), dot(u,v))` 得到有向主值角（范围约 -π 至 π）；`other_angle=True` 不能一概用于大于 90° 的角，必须确认所要标记的是内角、外角还是优角。视觉圆弧需要基于实际顶点、射线顺序与渲染结果审核。

## 交付清单

记录坐标及单位、理论结论、退化处理、数值断言、阈值理由、失败样例和帧审查。纯数学脚本只能对给定坐标执行数值回归，不证明一般几何命题。
