# 三角形中心术语表与坐标系统

## 三角形中心百科全书 (Encyclopedia of Triangle Centers) 参考资料

本文档详细介绍三角形几何中的关键术语、坐标系统和数学符号，基于 Clark Kimberling 的《三角形中心百科全书》(ETC)。

## 一、坐标系统

### 1.1 三线坐标 (Trilinear Coordinates)

**定义**：点 P 的三线坐标表示为 x : y : z（齐次坐标）

**含义**：
- 存在非零函数 h(a,b,c)，使得 x = hx', y = hy', z = hz'
- 其中 x', y', z' 是点 P 到三边 BC, CA, AB 的有向距离
- 也称为"三线坐标系"或"trilinears"

**特点**：
- 齐次坐标系统（比例不变性）
- 自然适用于基于角度的定义
- 经典三角形几何的主要坐标系

**示例**：
- 内心 X(1): 1 : 1 : 1
- 外心 X(3): cos A : cos B : cos C
- 重心 X(2): 1/a : 1/b : 1/c = bc : ca : ab

### 1.2 重心坐标 (Barycentric Coordinates)

**定义**：点 P 的重心坐标表示为 u : v : w（齐次坐标）

**含义**：
- 存在函数 k(a,b,c)，使得 u = ku', v = kv', w = kw'
- 其中 u', v', w' 是三角形 PBC, PCA, PAB 的有向面积
- 也称为"面积坐标"或"areal coordinates"

**坐标转换**：
- 如果三线坐标为 x : y : z
- 则重心坐标为 ax : by : cz

**物理意义**：
- 表示质量分布
- 点 P 处的质点可看作三个顶点处质量的平衡点

**示例**：
- 重心 X(2): 1 : 1 : 1
- 外心 X(3): sin 2A : sin 2B : sin 2C
- 垂心 X(4): tan A : tan B : tan C

### 1.3 实际坐标 (Actual Coordinates)

**实际三线坐标**：
- x', y', z' 表示点 P 到三边的实际距离
- 非齐次坐标

**实际重心坐标**：
- 三角形 PBC, PCA, PAB 的实际面积
- 归一化条件：x + y + z = 1

## 二、Conway 符号系统

### 2.1 基本 Conway 符号

**面积相关**：
- **S** = 2 × area(ABC) = 2 × 三角形面积
- **s** = (a + b + c)/2 = 半周长

**边长函数**：
- **SA** = (b² + c² - a²)/2 = bc cos A
- **SB** = (c² + a² - b²)/2 = ca cos B  
- **SC** = (a² + b² - c²)/2 = ab cos C

**半边长**：
- **sa** = (b + c - a)/2 = s - a
- **sb** = (c + a - b)/2 = s - b
- **sc** = (a + b - c)/2 = s - c

### 2.2 圆半径

**内切圆半径**：
- **r** = S/(a + b + c) = 2 × area(ABC)/(a + b + c)
- r = 面积/半周长

**外接圆半径**：
- **R** = abc/(2S) = abc/(4 × area(ABC))
- R = a/(2 sin A)

**旁切圆半径**：
- **ra** = 2 × area(ABC)/(-a + b + c)
- **rb** = 2 × area(ABC)/(a - b + c)
- **rc** = 2 × area(ABC)/(a + b - c)

**关系式**：
- 1/r = 1/ra + 1/rb + 1/rc
- area(ABC) = √(r × ra × rb × rc)
- ra + rb + rc = r + 4R

### 2.3 Brocard 角

**定义**：
- **ω** = Brocard 角
- **Sω** = S cot ω

**计算公式**：
- cot(ω) = (a² + b² + c²)/(2S)
- cot(ω) = (a² + b² + c²)/(4 × area(ABC))

## 三、核心术语定义

### 3.1 三角形中心 (Triangle Center)

**定义**：点 P = f(a,b,c) : f(b,c,a) : f(c,a,b) 是三角形中心，当且仅当满足：

**(1) 齐次性条件**：
- 存在整数 n，使得对所有正数 t，有：
- f(ta,tb,tc) = tⁿf(a,b,c)

**(2) 对称性条件**：
- |f(a,b,c)| = |f(a,c,b)|
- 即交换任意两个边长，函数绝对值不变

**重要性质**：
- 三角形中心在相似变换下保持不变
- 反射对称性：关于任意中线对称
- 无穷多个三角形中心存在

**非三角形中心的例子**：
- Brocard 点（不满足对称性条件）

### 3.2 双心点对 (Bicentric Pair)

**定义**：如果点 P = f(a,b,c) : f(b,c,a) : f(c,a,b) 满足：
- 齐次性条件 (1)
- 但 |f(a,b,c)| ≠ |f(a,c,b)|

则以下两点构成**双心点对**：
- P₁ = f(a,b,c) : f(b,c,a) : f(c,a,b)
- P₂ = f(a,c,b) : f(b,a,c) : f(c,b,a)

**经典例子**：
- **第一 Brocard 点**：c/b : a/c : b/a
- **第二 Brocard 点**：b/c : c/a : a/b

**几何意义**：
- 在构造步骤中交换 B 和 C 得到不同的点
- 不具有完全的对称性

### 3.3 等角共轭 (Isogonal Conjugate)

**定义**：点 P 的等角共轭点 P⁻¹

**构造方法**：
- 设 P = p : q : r（三线坐标）
- L(A) = 直线 AP 关于角 A 平分线的反射
- L(B) 和 L(C) 循环定义
- L(A), L(B), L(C) 交于点 P⁻¹

**坐标公式**：
- 若 P = p : q : r（三线坐标）
- 则 P⁻¹ = 1/p : 1/q : 1/r

**性质**：
- (P⁻¹)⁻¹ = P（对合变换）
- 等角共轭保持角平分线
- X(1) 是自身的等角共轭

**重要等角共轭对**：
- X(1) ↔ X(1)（内心自共轭）
- X(2) ↔ X(6)（重心 ↔ 类心）
- X(3) ↔ X(4)（外心 ↔ 垂心）
- X(13) ↔ X(15)（Fermat 点对）
- X(14) ↔ X(16)

### 3.4 等距共轭 (Isotomic Conjugate)

**定义**：点 P 的等距共轭点

**构造方法**：
- 基于中线的反射
- 涉及到边的中点

**坐标公式**：
- 若 P 的重心坐标为 x : y : z
- 则等距共轭的重心坐标为 1/x : 1/y : 1/z

**性质**：
- 对合变换
- 重心 X(2) 是自身的等距共轭

**重要等距共轭对**：
- X(2) ↔ X(2)（重心自共轭）
- X(1) ↔ X(75)
- X(6) ↔ X(76)

## 四、特殊三角形

### 4.1 中线三角形 (Medial Triangle)

**定义**：三边中点构成的三角形

**顶点**：
- A' = BC 的中点
- B' = CA 的中点  
- C' = AB 的中点

**性质**：
- 与原三角形 ABC 相似，相似比 1:2
- 周长是原三角形的一半
- 面积是原三角形的 1/4

**重要关系**：
- 中线三角形的外心是原三角形的九点圆心

### 4.2 垂足三角形 (Orthic Triangle / Pedal Triangle of Orthocenter)

**定义**：三条高的垂足构成的三角形

**顶点**：
- A' = 从 A 作的高与 BC 的交点
- B' = 从 B 作的高与 CA 的交点
- C' = 从 C 作的高与 AB 的交点

**特殊情况**：
- 锐角三角形：垂足三角形在内部
- 直角三角形：退化为一条线段
- 钝角三角形：部分顶点在外部

**性质**：
- 垂心是垂足三角形的内心

### 4.3 切线三角形 (Tangential Triangle)

**定义**：外接圆在三个顶点处切线构成的三角形

**性质**：
- 原三角形 ABC 是切线三角形的垂足三角形
- 外心 X(3) 是切线三角形的垂心

### 4.4 Cevian 三角形

**定义**：对于点 P，从三个顶点向 P 作直线与对边的交点构成的三角形

**构造**：
- A' = AP 与 BC 的交点
- B' = BP 与 CA 的交点
- C' = CP 与 AB 的交点

**特殊例子**：
- P = 重心时，Cevian 三角形 = 中线三角形
- P = 内心时，Cevian 三角形 = 接触三角形

### 4.5 Anticevian 三角形

**定义**：Cevian 三角形的"逆"

**构造**：
- 通过点 P 和边的延长线确定

**性质**：
- Anticevian 三角形的 Cevian 三角形是原三角形

### 4.6 外接三角形 (Excentral Triangle)

**定义**：三个旁心构成的三角形

**顶点**：
- 三个旁心 IA, IB, IC

**性质**：
- 内心 X(1) 是外接三角形的垂心
- 半径关系特殊

### 4.7 补三角形 (Anticomplementary Triangle)

**定义**：顶点是各边向外延长一倍处的三角形

**构造**：
- A' 使得 A 是 A'A 与中点的中点（反方向）
- 类似 B', C'

**性质**：
- 内心是 Nagel 点 X(8)
- 垂心是 de Longchamps 点 X(20)

## 五、共点与共线

### 5.1 Ceva 定理与 Ceva 点

**Ceva 定理**：
三条 Cevian 直线共点的充要条件

**Ceva 点**：
- 三条 Cevian 直线的交点

**X(I)-Ceva 共轭 of X(J)**：
- 表示特殊的共轭关系
- 在 ETC 中广泛使用

### 5.2 重合点 (Cevapoint)

**定义**：两点 P 和 U 的重合点

**性质**：
- 与 Ceva 三角形相关
- 透视关系

### 5.3 交叉共轭 (Cross Conjugate)

**记号**：X(I)-cross conjugate of X(J)

**含义**：
- X(I) 和 X(J) 之间的特殊关系
- 涉及透视和极线

### 5.4 共线关系 (Collinearity)

**表示方法**：
在 ETC 中，每个中心 X(n) 列出其所在的直线：
- 格式："X(1) lies on these lines: 2,8  3,35  4,33  5,11 ..."
- 含义：X(1) 在直线 X(2)X(8) 上，在直线 X(3)X(35) 上，等等

**重要共线**：
- Euler 线：X(2), X(3), X(4), X(5), X(20), X(21), ...
- X(1), X(2), X(8)：内心、重心、Nagel 点共线

## 六、代数运算

### 6.1 三线乘法 (Trilinear Multiplication)

**定义**：
- (x : y : z) * (u : v : w) = xu : yv : zw

**单位元**：
- 内心 X(1) = 1 : 1 : 1 是三线乘法的单位元

**性质**：
- 构成群结构
- 用于定义复杂的三角形中心

### 6.2 重心乘法 (Barycentric Multiplication)

**定义**：
- (x : y : z) * (u : v : w) = xu : yv : zw

**单位元**：
- 重心 X(2) = 1 : 1 : 1 是重心乘法的单位元

**构造方法**：
- Paul Yiu 给出了几何构造方法
- 可用于计算平方根

### 6.3 线性组合

**定理**：
- 如果 X, X', X'' 是三角形中心
- f, g, h 是同次齐次对称函数
- 则 f×X + g×X' + h×X'' 也是三角形中心

**推论**：
- 每个三角形中心可表示为其他三个非共线中心的线性组合
- 无穷多三角形中心的理论基础

## 七、特殊直线与圆

### 7.1 Euler 线

**定义**：包含重心、外心、垂心、九点圆心的直线

**包含的中心**：
- X(2) - 重心
- X(3) - 外心
- X(4) - 垂心
- X(5) - 九点圆心
- X(20) - de Longchamps 点
- 以及无穷多其他中心

**方向**：
- 在无穷远处与 X(30) - Euler 无穷点 相交

### 7.2 垂轴 (Orthic Axis)

**定义**：垂足三角形的外接圆（对于锐角三角形）

**三线方程**：cos A : cos B : cos C

**性质**：
- 垂直于 Euler 线
- 仅对锐角三角形存在

**极点**：
- X(25) 是垂轴关于外接圆的极点

### 7.3 三线极线 (Trilinear Polar)

**定义**：点 P = p : q : r 的三线极线

**方程**：px + qy + rz = 0

**性质**：
- P 的 Cevian 三角形与 ABC 透视的点的轨迹
- 对偶关系：点 ↔ 线

### 7.4 九点圆 (Nine-Point Circle)

**定义**：通过以下 9 个点的圆：
1. 三边中点（3 个）
2. 三条高的垂足（3 个）
3. 顶点到垂心的中点（3 个）

**圆心**：X(5) - 九点圆心

**半径**：R/2（外接圆半径的一半）

**Feuerbach 定理**：
- 九点圆与内切圆相切于 X(11) - Feuerbach 点
- 九点圆也与三个旁切圆相切

### 7.5 Brocard 圆

**定义**：通过两个 Brocard 点的圆

**圆心**：X(39) - Brocard 中点

**性质**：
- 与外接圆相关
- Brocard 角 ω 决定其大小

**第二 Brocard 圆**：
- 圆心在 X(3)（外心）
- 半径 = eR，其中 e = √(1 - 4sin²ω)
- 与第一 Brocard 圆交于两个 Brocard 点

## 八、命名约定

### 8.1 经典名称

**历史人物命名**：
- Euler（欧拉）：Euler 线、Euler 点
- Fermat（费马）：Fermat 点
- Napoleon（拿破仑）：Napoleon 点
- Brocard（布洛卡）：Brocard 点、Brocard 圆
- Feuerbach（费尔巴哈）：Feuerbach 点、Feuerbach 定理
- Gergonne（热尔岗）：Gergonne 点
- Nagel（纳格尔）：Nagel 点
- Lemoine（勒穆瓦纳）：Lemoine 点（即类心）

### 8.2 星名命名

**约定**：
- 当没有特定几何或历史名称时，使用恒星名称
- 确保每个中心都有唯一名称

**例子**：
- 某些高编号的三角形中心使用恒星名

### 8.3 编号系统

**X(n) 记号**：
- X(1), X(2), X(3), ... 表示 ETC 中的第 n 个三角形中心
- 截至 2025 年，已超过 70,000 个中心
- 原书《Triangle Centers and Central Triangles》列出了前 400 个

## 九、重要不等式与恒等式

### 9.1 三角形不等式

**边长条件**：
- a ≤ b + c
- b ≤ c + a
- c ≤ a + b

**等价条件**：
- 存在三边长为 a, b, c 的三角形

### 9.2 半径关系

**内切圆与旁切圆**：
- 1/r = 1/ra + 1/rb + 1/rc
- area(ABC) = √(r × ra × rb × rc)
- ra + rb + rc = r + 4R

**Euler 关系**：
- OI² = R² - 2Rr（外心到内心的距离）
- O = 外心，I = 内心

## 十一、高级概念

### 11.1 共轭类型

ETC 中定义了多种共轭：
- **Aleph 共轭**
- **Beth 共轭**
- **Gimel 共轭**
- **He 共轭**
- **Waw 共轭**
- **Zayin 共轭**
- **补共轭 (Complementary conjugate)**
- **反补共轭 (Anticomplementary conjugate)**

### 11.2 透视 (Perspectivity)

**定义**：
- 两个三角形从一点透视
- 对应顶点的连线共点

**透视中心 (Perspector)**：
- 透视点

**透视轴 (Perspectrix)**：
- 对应边的交点共线
- 这条直线称为透视轴

**Desargues 定理**：
- 两个三角形从点透视 ⟺ 从线透视

### 11.3 等距嵌套 (Cevian Nest)

**定义**：
- T₁, T₂, T₃ 三个三角形
- T₃ 内接于 T₂
- T₂ 内接于 T₁

**性质**：
- 如果其中一对透视，则每对都与第三个透视
