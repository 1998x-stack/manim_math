# Prompt 文档：历史资料与当前执行契约

## 两类 Prompt 不要混淆

| 来源 | 作用 | 使用方式 |
| --- | --- | --- |
| [小学课程提示词](xiaoxue.md)、[初中课程提示词](chuzhong.md)、[高中课程提示词](gaozhong.md) | 历史课程知识点提取要求与章节资料 | 核对年级范围、教材版本、术语、例题后再利用；不可直接视为最新课程事实 |
| `小学/`、`初中/`、`高中/` 下各知识点目录中的 `prompt.md` | 针对该作品的生成记录，通常包含通用长模板及 `<problem>` | 先读同目录 `description.json`、`storyboard.md` 和源码，提取具体需求，避免复制整份模板 |
| [当前 Prompt 编写规范](authoring.md) | 新建或更新作品时的可执行输入、输出和验收契约 | 与 [Skills 路由](../../skills/README.md) 结合使用 |

抽样示例：[一年级「数一数」的 Prompt](../../小学/一年级/上册/第一章-10以内数的认识/001数一数/prompt.md) 与[同目录元数据](../../小学/一年级/上册/第一章-10以内数的认识/001数一数/description.json)。这是**具体目录示例**，不代表所有课程目录的文件都齐全。

## 阅读旧 Prompt 时要特别核对

- 小学历史课程提示词请求范围与产物数量存在不一致描述，并使用八年级勾股定理作数据格式示例；高中提示词也使用八年级示例。不要把示例年级写成目标年级。
- 旧知识点 Prompt 中关于安装/解包 `.skill`、固定角度 API、字体、统一颜色和传播文案的要求，属于历史上下文；先与本仓库当前 Skills、场景源码、Manim CE 实际版本和数学规格核对。
- 旧 `prompt.md` 的 `<problem>` 是数据片段而非已验证事实：公式可能包含中文解释，组件名称可能是概念性候选，不能假定所有名字都是 Manim 可导入的类。
- 不将历史文本批量删除、统一覆盖或视为可在其他作品中直接执行的命令；更新模板时保留来源与旧版本映射。

按[编写规范](authoring.md)构建新 Prompt；最终发布之前按[质量门禁](../engineering/quality-gates.md)记录实际检查。
