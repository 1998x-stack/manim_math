## 概况

- `小学/` 下 **273 个 Python 文件**，分布在 **220 个含 Python 的目录**；其中 **211 个常规知识点目录**，其他目录属于奥数专题。
- 常规知识点目录中 **47 个**包含多个 Python 文件；其中可能同时存在主 Scene、旧入口、数学模型、验证器及测试，不可按文件名排序猜测首选渲染入口。
- **50 个** Python 文件小于 3 KB；体积只是复核线索，不代表一定是占位代码。
- **1 个**含 Python 的常规知识点目录缺少同目录 `storyboard.md`（以下列出）。
- 课程中的视频、图片与历史素材保持原路径，本批未移动或重编码。

## 风险与优化分批

| 顺序 | 工作 | 验收与边界 |
| --- | --- | --- |
| P0（本批） | 建立所有小学 `.py` 的确定性索引与 Scene 候选识别；补充轻量测试 | 所有课程脚本仅静态解析，不导入 Manim；不改变 Gallery、现有 Scene 类名或媒体 |
