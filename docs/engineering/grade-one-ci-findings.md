# 一年级全目录静态扫描的发现与处置

日期：2026-09-23。该文件补充 [已确认问题与分层验收](grade-one-quality-audit.md)，记录 CI 扫描产生的可复查证据。不能把静态源文件检查当成全部 38 个场景的数学、视觉验收。

## 审计覆盖（专项 CI）

- 递归发现 `.py` 文件 38 个：上册 21 个、下册 17 个；静态识别直接声明的 Scene 类 36 个。Scene 类数量并非已渲染视频数量。
- 初次开启强制语法门禁时，发现原仓库一处无法解析的 Python 文件和两处向 `MathTex` 传递中文的代码；相关源文件已在本 PR 单独修复。对复杂表达式、动态生成字符串与 Manim 实际渲染的识别能力有限。
- [出现原始错误的第二次专项 CI 日志](https://github.com/1998x-stack/manim_math/actions/runs/35818007745)：定位上述问题；其中最初的 8 项纯数学/扫描器单元测试均通过，但**整体门禁因原代码语法错误失败**。

## 另外三处代码修复

| 课目 | 已确认原始问题 | 本次修复及数学检查 |
| --- | --- | --- |
| 上册《连加、连减、加减混合》`005_连加、连减、加减混合.py` | 原类名 `连加、连减、加减混合Animation` 含顿号，不是合法 Python 标识符；源码第 3 行无法通过语法解析；内容只有圆形和一条连加式，不涵盖连减和加减混合。 | 改为可解析类名 `连加连减加减混合Animation`；展示 2+3+1=6、5−2−1=2、5+2−3=4 的**两步中间结果**和对应点数，纯函数 `calculate_steps()` 逐步验算；新增含 0、10 与非法输入的数学回归测试。原不合法 Scene 类名无法作为 Python API 别名继续保留。 |
| 上册《长方体》`001_长方体.py` | 原代码用圆形表示长方体，同时 `MathTex("6个面")` 混入未转义中文。 | 用三个可见面的长方体二维投影示意图替代圆形；独立 `Text` 明确“图中能看见3个面／长方体一共有6个面”，不把可见面数误认为总面数。 |
| 下册《认识平面图形》`001_认识平面图形.py` | 原代码仅展示圆形，使用 `MathTex("4种平面图形")` 混入中文，画面和字幕不匹配。 | 展示并分别标注圆形、三角形、正方形、长方形四个实例，中文用 `Text`；不声称四个例子构成互斥或穷尽分类。 |

## 分层验收口径

`tools/audit_grade_one.py` 的语法通过只说明全部 38 个 `.py` 源文件可被解析/编译；它不执行 Manim、无法保证数学语义、图片/字体/视频无误。专项 CI 的数学测试只覆盖数数、五角星、百数表与新增的两步加减计算；其它课程仍须逐课核对完整知识点和每一帧内容。原始 `.mp4`、`*_finish.mp4` 未修改，不能把旧成片称为这次修改后的渲染输出。

本次代码改动没有重命名任何已有 Python 文件或媒体文件；只有原先无法编译的混合运算 Scene 类名更正。新增 `.github/workflows/grade-one-quality.yml` 是纯源码/纯数学门禁；发布前仍需按 `docs/engineering/quality-gates.md` 低清渲染上述五个修改场景，人工核对标题、字体、画幅、转场及教学内容后再生产重渲染。
