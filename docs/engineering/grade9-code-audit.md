## 质量门禁及执行方式

1. `python tools/audit_grade9.py --json`：扫描五章的场景代码和课件元数据；静态问题中的警告必须由课程负责人复核，不能视为自动修复。
2. `python -m unittest discover -s tools/tests -p 'test_audit_grade9.py' -v`：验证审计器、三角比几何约定和基础数学恒等式。
3. `python -m compileall -q "初中/九年级"`：仅验证 Python 语法，不能证明导入、Manim API 或 LaTeX 在目标环境中可运行。
4. 逐个运行 `manim -ql <源码路径> <Scene类名>`，先审阅标题、公式、几何不变量、字幕重叠、离屏对象和过渡关键帧，再进行生产渲染。
5. 源码/故事板/成片存在差异时以数学内容审定为先；历史视频仅在重新渲染、审片和明确发布计划后替换，禁止把旧 MP4 当作新源码验收证据。

已提交的三角比场景改写保留原文件路径和类名，但缩减了原场景的动画实现；对比原 `storyboard.md` 的镜头节奏、颜色及画面布局是合并前的必要审核项。
