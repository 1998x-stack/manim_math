## 目录和本轮实做

GitHub 目录层级包含七个章节，当前可见知识点子目录分别为：第一学期第九章整式 12 个、第十章分式 7 个、第十一章图形的运动 4 个；第二学期第十二章实数 6 个、第十三章相交线和平行线 5 个、第十四章三角形 11 个、第十五章平面直角坐标系 4 个。合计 49 个知识点目录；**49 是目录数，不能据此推断 Python 文件或已完成视频数量**。

已确认且已修复：`第一学期/第九章-整式/003整式的加减法/003_整式的加减法.py` 原脚本只展示圆和 `+(a+b)=a+b`，与同目录描述中的去括号、变号、同类项以及整式减法不符。现已改为贯穿正/负号去括号、加法、减法、易错纠正、总结的教学动画，保留原有 Scene 名称。`tests/test_audit_grade7.py` 增加了公式步骤、Scene 类名和整数代入的独立回归检查；这些检查不替代低清渲染与关键帧审核。

结构兼容风险：第十四章同时有 `003三角形的内角和定理` 和 `003三角形的外角` 两个目录。以「章节+数字序号」作为唯一键的索引会冲突；现阶段不能为了消除编号冲突直接重命名历史路径，应先建立稳定 topic_id 并审核 gallery、已有 URL 和调用方。

## 每个章节的数学审查表

| 章节 | 核心不变量、边界和易错点 | 必须补充的专门验证 |
| --- | --- | --- |
| 九：整式 | 同类项字母与指数完全相同；去括号负号分配到每一项；乘法公式与因式分解互逆；幂法则的底数、指数和除法非零前提 | 为每个符号恒等式选正常值、零值、负值逐项代入；核对因式分解展开式，排查模板式演示 |
| 十：分式 | 所有原分母不得为零；约分前后定义域保持；分式方程去分母可能引入增根；除数分式自身不能为零 | 每道例题记录禁值和候选根，把候选根代回原方程；分式化简对禁值不声称等价 |
| 十一：图形的运动 | 平移向量一致、旋转保距保角、中心对称中点固定、轴对称等距；所有公式坐标须与画面一致 | 对一般/重合/轴上/中心点构型检查距离、中点、角度和退化元素；验证 `NumberPlane.c2p` 与 `p2c` 转换 |
| 十二：实数 | `\sqrt{x}` 在实数范围要求 x≥0，且表示非负算术平方根；方根、绝对值、分数指数幂要声明实数定义域 | 测试 0、正数、负数、完全平方数、近似值，核查 `\sqrt{x^2}=|x|` 而非普遍等于 x |
| 十三：相交线、平行线 | 对顶角/邻补角的类型不可混淆；同位角等关系需相应平行条件，判定与性质方向不同 | 测试平行、相交、重合和非平行反例，检查角度数字和绘制弧的方向及对应点标 |
| 十四：三角形 | 三边严格不等式、内角和、外角定理；SSS/SAS/ASA/AAS 的对应顺序及「SAS 夹角」要求；底边退化时高度计算 | 用独立坐标/长度断言校验，处理共线点、零长度边、等腰或等边特殊情况；检查图片不能暗示 SSA 足以判全等 |
| 十五：平面直角坐标系 | x/y 轴坐标顺序、四象限符号、轴上点归属、对称点符号、平移向量变化 | 检查 `(x,y)→(x,-y)`、`(-x,y)`、`(-x,-y)` 以及 `(x+a,y+b)`，覆盖原点与坐标轴上的点 |

## 验收次序与不通过条件

1. **结构层**：检查所有七年级 `.py` 和 `.json`，测试通过，逐项分流告警并记录例外理由；未执行时不得宣称所有源代码已通过。
2. **数学层**：逐知识点核对 `description.json`、`prompt.md` 的具体课题、分镜和 Scene 展示内容；对含除法、根式、退化几何和动态坐标的场景添加独立数学断言。只做若干数值抽查不能代替证明。
3. **运行层**：用代码内真实 Scene 名称执行 `manim -ql <path> <SceneClass>`；确认在明确的 Python/Manim/LaTeX/中文字体组合下不抛异常。命令示例不能算执行记录。
4. **视觉层**：检查竖屏安全区、标题/水印/字幕遮挡、色彩与符号一致、关键帧是否显示正确数学状态。最终用 `ffprobe` 校验视频帧尺寸和时长。
5. **兼容层**：不替换历史 MP4，不无意更改旧 scene/media 路径。需要改名时先建立稳定 topic_id 和旧到新路径映射，再同步索引和触发规则。
