## 自动化代码门禁

运行以下命令，无需安装 Manim：

```bash
python -m unittest discover -s tests -p 'test_audit_grade3.py' -v
python tools/audit_grade3.py --json
python tools/audit_grade3.py --strict
```

静态扫描覆盖三年级目录内的全部 Python 文件，报告语法错误、缺少直接 Scene 子类（信息项）和文字/Unicode 运算符误入 `MathTex`/`Tex` 的字面量（警告）。`--strict` 将错误和警告视为门禁失败，信息项不阻断；CI 对受影响的 PR 运行此命令。

**扫描器边界：** 不执行代码、不能发现动态拼接的 TeX 片段中的所有问题，也无法证明 Manim API、字体、LaTeX、画面位置、数学结果或视频正确。没有输出问题只表示这些静态规则没有触发。

## 数学正确性验收

对于每个完整课程，应记录至少一组正常例题、一组边界情形及与分镜逐帧对应的结论：

1. 乘法：计算与位值一致，例如 `23×14=23×4+23×10=322`，十位部分积不能漏乘 10。
2. 除法：检查 `被除数=除数×商+余数`，且整数有余数的情形满足 `0≤余数<除数`；不能只展示正确商而不验算。
3. 日期：明示是否计算起始日及终止日；例如 2023-07-15 到 2023-08-20 的日期差为 36 天（不计起始日，计终止日）；增加跨年和闰年用例。
4. 分数：比较前核对分数是否表示同一个整体、分母是否为正及所述规则的前提；加减法中单位分数含义与图形等分数量一致。
5. 周长/面积：周长对边界求长度，面积计数单位正方形；不能以线段长度替换面积，平方单位的换算系数应由边长换算平方推导。
6. 统计：每组柱形的高度与真实数据成比例，基线、刻度、组别与图例匹配，比较结论必须有图上证据。
