## 自动化代码门禁

以下命令无需安装 Manim：

```bash
python -m unittest discover -s tests -p 'test_audit_grade3.py' -v
python tools/audit_grade3.py --json
python tools/audit_grade3.py --strict
```

扫描覆盖三年级全部 Python 源码，报告语法错误、缺少直接 Scene 子类（信息项）、中文/Unicode 运算符误入 `MathTex`/`Tex` 字面量（警告）、历史通用占位教学句（警告）。`--strict` 将错误和警告视为门禁失败，信息项不阻断；GitHub Actions 使用稀疏检出，避免无意义地下载大量已跟踪视频。

**扫描器边界：** 不执行代码、不能发现全部动态拼接的 TeX 片段或没有固定占位句的空洞课程，也无法证明 Manim API、字体、LaTeX、画面位置、数学结果或视频正确。无警告仅表示这些静态规则没有触发。

## 数学正确性验收

对每个完整课程，应记录正常例题、边界情形、分镜与关键帧的一一对应：

1. 乘法：例如 `23×14=23×4+23×10=322`，十位部分积不能漏乘 10。
2. 除法：检查 `被除数=除数×商+余数`，且 `0≤余数<除数`（整数除法、除数为正）。
3. 日期：明确是否计算起始日和终止日；例如 2023-07-15 至 2023-08-20 的日期差是 36 天（不计起始日、计终止日）；增加跨年、闰年用例。
4. 分数：比较同一个整体下的分数，核对等分数量、分数单位与加减结果。
5. 周长/面积：周长计算边界长度，面积计数单位正方形；平方单位换算由边长换算平方推导。
6. 统计：每组柱形高度与示例数据成比例，基线、刻度、组别、图例匹配。
