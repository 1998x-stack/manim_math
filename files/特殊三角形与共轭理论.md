# 特殊三角形与共轭理论

## 三角形中心百科全书 (Encyclopedia of Triangle Centers) 高级专题

本文档深入探讨三角形几何中的特殊三角形、构造方法、共轭理论和高级概念，基于 Clark Kimberling 的《三角形中心百科全书》(ETC)。

## 一、特殊三角形大全

### 1.1 基于原三角形顶点的派生三角形

#### (1) 中线三角形 (Medial Triangle)
**顶点**：三边中点
- A' = BC 的中点  
- B' = CA 的中点
- C' = AB 的中点

**性质**：
- 边长是原三角形对应边的一半
- 与 ABC 相似，相似比 1:2
- 周长 = (a + b + c)/2
- 面积 = area(ABC)/4
- 九点圆是中线三角形的外接圆

**中心关系**：
- 中线三角形的重心 = ABC 的重心 X(2)
- 中线三角形的外心 = ABC 的九点圆心 X(5)

#### (2) 垂足三角形 / 垂三角形 (Orthic Triangle)
**顶点**：三条高的垂足
- HA = 从 A 的高与 BC 的交点
- HB = 从 B 的高与 CA 的交点  
- HC = 从 C 的高与 AB 的交点

**性质**：
- ABC 的垂心是垂足三角形的内心
- 垂足三角形的周长最小（锐角三角形中）
- 仅当 ABC 是锐角三角形时，垂足三角形在内部

**特殊情况**：
- 直角三角形：退化为从直角顶点到斜边的高
- 钝角三角形：部分垂足在三角形外部

**角度关系**：
- ∠BHAHC = π - 2A
- ∠CHAHB = π - 2B
- ∠AHBHC = π - 2C

#### (3) 接触三角形 (Contact Triangle / Intouch Triangle)
**顶点**：内切圆与三边的切点
- TA = 内切圆与 BC 的切点
- TB = 内切圆与 CA 的切点
- TC = 内切圆与 AB 的切点

**性质**：
- 内心 X(1) 是接触三角形的外心
- Gergonne 点 X(7) 与接触三角形相关

**边长**：
- TATB = s - c（s 是半周长）
- TBTC = s - a
- TCTA = s - b

#### (4) 外接三角形 (Excentral Triangle)
**顶点**：三个旁心
- IA = A-旁心
- IB = B-旁心
- IC = C-旁心

**性质**：
- 内心 X(1) 是外接三角形的垂心
- 九点圆与外接三角形的三个内切圆（旁切圆）相切
- Nagel 点 X(8) 是外接三角形的内心

**半径**：
- 旁心到对边的距离等于旁切圆半径

#### (5) 切线三角形 (Tangential Triangle)
**顶点**：外接圆在 A, B, C 处切线的交点
- AT = 在 A 处切线与在 B 处切线的交点（对应顶点 C）
- BT = 在 B 处切线与在 C 处切线的交点（对应顶点 A）
- CT = 在 C 处切线与在 A 处切线的交点（对应顶点 B）

**性质**：
- ABC 是切线三角形的垂足三角形
- 外心 X(3) 是切线三角形的垂心
- 切线三角形与 ABC 透视，透视中心是 X(25)

### 1.2 补三角形与反三角形

#### (6) 补三角形 (Complementary Triangle)
**顶点**：各边中点
- 实际上就是中线三角形

**补运算 (Complement)**：
- 如果 P 是 ABC 的一个中心
- 则 complement of P 是中线三角形的对应中心

**重要补点**：
- Complement of X(1) = X(10) (Spieker 中心)
- Complement of X(3) = X(5) (九点圆心)
- Complement of X(4) = X(3) (外心)

#### (7) 反补三角形 (Anticomplementary Triangle)
**定义**：顶点是各边向外延伸两倍形成的三角形

**构造**：
- A' 使得 A 是线段 A'M_A 的中点，其中 M_A 是 BC 中点
- 类似定义 B', C'

**性质**：
- 边长是原三角形的两倍
- 与 ABC 相似，相似比 2:1
- 面积 = 4 × area(ABC)

**反补运算 (Anticomplement)**：
- X(1) 的 anticomplement = X(8) (Nagel 点)
- X(3) 的 anticomplement = X(4) (垂心)
- X(4) 的 anticomplement = X(20) (de Longchamps 点)

**重要中心**：
- 反补三角形的内心 = Nagel 点 X(8)
- 反补三角形的垂心 = de Longchamps 点 X(20)

### 1.3 Cevian 族三角形

#### (8) Cevian 三角形
**定义**：对于点 P，从各顶点向 P 连线与对边交点构成的三角形

**构造**：
- A₁ = 直线 AP 与边 BC 的交点
- B₁ = 直线 BP 与边 CA 的交点
- C₁ = 直线 CP 与边 AB 的交点
- Cevian 三角形 = A₁B₁C₁

**特殊情况**：
- P = 重心 X(2) → Cevian 三角形 = 中线三角形
- P = 内心 X(1) → Cevian 三角形 = 接触三角形
- P = 类心 X(6) → Cevian 三角形 = 某特殊三角形

**性质**：
- 三角形 ABC 和 Cevian 三角形从点 P 透视
- Ceva 定理描述 Cevian 线共点条件

#### (9) Anticevian 三角形
**定义**：Cevian 运算的"逆"

**性质**：
- 如果 A'B'C' 是 P 的 anticevian 三角形
- 则 ABC 是 P 关于 A'B'C' 的 Cevian 三角形

**构造**：
- 通过延长和反向构造实现

#### (10) 垂足三角形 (Pedal Triangle)
**定义**：从点 P 向三边作垂线的垂足构成的三角形

**顶点**：
- PA = P 向 BC 的垂足
- PB = P 向 CA 的垂足
- PC = P 向 AB 的垂足

**特殊情况**：
- P = 垂心 → 垂足三角形 = 垂三角形
- P = 外心 → 垂足三角形 = 中线三角形
- P 在外接圆上 → 垂足三角形退化为直线（Simson 线）

**性质**：
- 类心 X(6) 是其垂足三角形的重心

#### (11) Antipedal 三角形
**定义**：垂足三角形的"逆"

**构造**：
- 过 P 作三边的垂线
- 这些垂线构成新三角形

---

### 1.4 同心圆族三角形

#### (12) 外切三角形 (Extangents Triangle)
**顶点**：外切圆（与三边延长线相切的圆）的切点

**性质**：
- 与内心构造相关
- Clawson 点 X(19) 相关

#### (13) 内切三角形 (Intangents Triangle)
**顶点**：内切圆相关构造

**性质**：
- 与外接三角形互补

### 1.5 特殊构造三角形

#### (14) Napoleon 三角形
**第一 Napoleon 三角形**：
- 在 BC 外侧作等边三角形，取其中心
- 类似地在 CA, AB 外侧作等边三角形
- 三个中心构成第一 Napoleon 三角形

**第二 Napoleon 三角形**：
- 在 BC 内侧作等边三角形
- 类似构造

**Napoleon 定理**：
- 两个 Napoleon 三角形都是等边三角形
- Napoleon 点 X(17) 和 X(18) 是其中心

#### (15) Fermat 三角形
**构造**：
- 基于 Fermat 点 X(13) 和 X(14)
- 涉及等边三角形的构造

**性质**：
- 最小化距离和

#### (16) Brocard 三角形
**定义**：与 Brocard 点和 Brocard 圆相关

**顶点**：
- 通过 Brocard 角 ω 构造

**性质**：
- 第一和第二 Brocard 三角形
- 与原三角形相似

## 二、共轭理论深入

### 2.1 等角共轭 (Isogonal Conjugate)

#### 定义与性质

**几何定义**：
点 P 的等角共轭 P⁻¹ 通过以下方式构造：
1. 作直线 AP
2. 将 AP 关于角 A 的平分线反射得到 L(A)
3. 类似得到 L(B) 和 L(C)
4. L(A), L(B), L(C) 交于 P⁻¹

**代数定义**：
- 三线坐标：P = p : q : r ⇒ P⁻¹ = 1/p : 1/q : 1/r
- 重心坐标：P = x : y : z ⇒ P⁻¹ = a²/x : b²/y : c²/z

**基本性质**：
1. (P⁻¹)⁻¹ = P（对合变换）
2. 保持角平分线
3. 如果 P 在边上，P⁻¹ 在无穷远
4. X(1) 是唯一的自等角共轭点

#### 重要等角共轭对

| P | P⁻¹ | 名称对 |
|---|-----|--------|
| X(1) | X(1) | 内心（自共轭） |
| X(2) | X(6) | 重心 ↔ 类心 |
| X(3) | X(4) | 外心 ↔ 垂心 |
| X(4) | X(3) | 垂心 ↔ 外心 |
| X(5) | X(54) | 九点圆心 ↔ Kosnita 点 |
| X(6) | X(2) | 类心 ↔ 重心 |
| X(7) | X(55) | Gergonne 点 ↔ ... |
| X(8) | X(56) | Nagel 点 ↔ ... |
| X(9) | X(57) | Mittenpunkt ↔ ... |
| X(10) | X(58) | Spieker 中心 ↔ ... |
| X(13) | X(15) | 第一等角中心 ↔ 第一等动力点 |
| X(14) | X(16) | 第二等角中心 ↔ 第二等动力点 |

#### 等角共轭的应用

**定理 1**：如果三条直线从点 P 共点，则它们的等角像从 P⁻¹ 共点

**定理 2**：直线的等角共轭是二次曲线（圆锥曲线）

**定理 3**：圆的等角共轭是圆锥曲线

### 2.2 等距共轭 (Isotomic Conjugate)

#### 定义与性质

**几何定义**：
基于中线的反射和边的等分点

**代数定义**：
- 重心坐标：P = x : y : z ⇒ P* = 1/x : 1/y : 1/z
- 三线坐标：P = p : q : r ⇒ P* = 1/(ap) : 1/(bq) : 1/(cr)

**基本性质**：
1. 对合变换
2. 保持中线
3. X(2) 是唯一的自等距共轭点

#### 重要等距共轭对

### 2.3 其他共轭类型

#### (1) 补共轭 (Complement)
**定义**：P 在 ABC 中的补点是 P 在中线三角形中的对应点

**公式**：
- 重心坐标：P = x : y : z ⇒ Complement = -x + y + z : x - y + z : x + y - z

**性质**：
- 两次补运算不是恒等变换
- Complement of complement ≠ P（一般情况）

**例子**：
- Complement of X(1) = X(10)
- Complement of X(4) = X(3)

#### (2) 反补共轭 (Anticomplement)
**定义**：P 在 ABC 中的反补点

**公式**：
- 重心坐标：P = x : y : z ⇒ Anticomplement = 3x - y - z : -x + 3y - z : -x - y + 3z

**例子**：
- Anticomplement of X(1) = X(8)
- Anticomplement of X(4) = X(20)

#### (3) Aleph 共轭
在 ETC 中定义的特殊共轭类型，用希伯来字母命名

#### (4) Beth 共轭
另一种特殊共轭类型

#### (5) Gimel, He, Waw, Zayin 共轭
更多在 ETC 中系统定义的共轭类型

## 三、透视理论

### 3.1 透视三角形

#### 定义
两个三角形 ABC 和 A'B'C' 从点 P **透视**，如果：
- 直线 AA', BB', CC' 共点于 P

点 P 称为**透视中心** (Perspector)

#### Desargues 定理
两个三角形从点透视 ⟺ 从线透视

**从线透视**：
- 对应边 BC 和 B'C' 的交点
- 对应边 CA 和 C'A' 的交点  
- 对应边 AB 和 A'B' 的交点
- 三点共线

这条直线称为**透视轴** (Perspectrix) 或 **Axis of Perspectivity**

### 3.2 透视中心的计算

**给定三角形 A'B'C'**：
如果知道顶点的坐标，可以计算透视中心

**重心坐标公式**：
涉及行列式计算

### 3.3 常见透视关系

**ABC 与中线三角形**：
- 透视中心：重心 X(2)

**ABC 与垂足三角形**：
- 透视中心：垂心 X(4)

**ABC 与接触三角形**：
- 透视中心：Gergonne 点 X(7)

## 四、Central Triangles（中心三角形）

### 4.1 定义

**中心三角形**：顶点由三角形中心的某种函数定义的三角形

**Type 1 Central Triangle**：
设 f(a,b,c) 和 g(a,b,c) 是中心函数，则 (f,g)-central triangle 的顶点为：
- A' = f(a,b,c) : g(b,c,a) : g(c,a,b)
- B' = g(a,b,c) : f(b,c,a) : g(c,a,b)
- C' = g(a,b,c) : g(b,c,a) : f(c,a,b)

### 4.2 例子

**中线三角形**：
- f(a,b,c) = 0, g(a,b,c) = 1

**垂足三角形**：
- 通过特定函数定义

## 八、对心点对的深入研究

### 8.1 Brocard 点详解

**第一 Brocard 点**：Ω
- 三线坐标：c/b : a/c : b/a
- 满足：∠ΩAB = ∠ΩBC = ∠ΩCA = ω（Brocard 角）

**第二 Brocard 点**：Ω'
- 三线坐标：b/c : c/a : a/b  
- 满足：∠Ω'BA = ∠Ω'CB = ∠Ω'AC = ω

**Brocard 角 ω**：
- tan ω = 4 × area(ABC) / (a² + b² + c²)
- cot ω = (a² + b² + c²) / (4 × area(ABC))

**性质**：
- 两点关于 Brocard 轴对称
- Brocard 轴 = 直线 X(3)X(6)
- Brocard 中点 = X(39)

### 8.2 其他双心点对

**一般理论**：
许多重要的双心点对在 ETC 中系统编目

**P(n) 和 U(n) 记号**：
- ETC 中双心点对按顺序编号
- P(n) 是第一个，U(n) 是对应的第二个

## 九、构造方法

### 9.1 经典尺规作图

**内心的作图**：
1. 作任意两个角的平分线
2. 交点即为内心

**外心的作图**：
1. 作任意两边的垂直平分线
2. 交点即为外心

**垂心的作图**：
1. 作任意两条高
2. 交点即为垂心

**重心的作图**：
1. 作任意两条中线
2. 交点即为重心

### 9.2 现代构造

**动态几何软件**：
- 可以精确构造数千个三角形中心
- 可视化复杂关系

**符号计算**：
- 精确计算坐标
- 验证共线、共点关系

## 十、应用与问题

### 10.1 最优化问题

**Fermat 点**：
- 最小化 |PA| + |PB| + |PC|
- 当所有角 < 120° 时为 X(13)

**重心**：
- 最小化 |PA|² + |PB|² + |PC|²

**类心**：
- 最小化到三边距离的平方和（三线坐标）

### 10.2 几何不等式

**Euler 不等式**：
- R ≥ 2r（外接圆半径 ≥ 2 倍内切圆半径）
- 等号成立当且仅当三角形是正三角形

**其他不等式**：
- 涉及各种三角形中心的距离关系
