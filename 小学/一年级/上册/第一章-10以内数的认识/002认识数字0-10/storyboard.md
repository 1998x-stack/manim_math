# 认识数字0-10 - 动画分镜脚本

## 元信息
- 目标时长: 50 秒
- 场景数量: 7 个
- 难度等级: 一年级上册

## 颜色配置
```python
BG_COLOR = "#1a1a2e"
COLOR_ZERO = "#e74c3c"      # 红色 - 0特殊
COLOR_1_5 = "#3498db"       # 蓝色 - 1-5
COLOR_6_10 = "#2ecc71"      # 绿色 - 6-10
COLOR_HIGHLIGHT = YELLOW
COLOR_GRID = "#4a4a6a"
COLOR_NUM = WHITE
```

## 元素生命周期追踪表
| 元素 | 创建场景 | 销毁场景 | 备注 |

## Scene 1: 开场钩子 (3秒)
**目的**: 引起注意，提出问题

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 作者信息淡入 |
| 0.3s | 标题"数字大冒险！" Write动画 |
| 1.0s | 副标题 "认识0到10" FadeIn |
| 1.5s | 数字雨效果（0-10随机位置飘落） |
| 2.5s | FadeOut清场 |

---

## Scene 2: 认识0 (8秒)
**目的**: 强调0的特殊含义

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 大数字"0"从中心长出 |
| 0.8s | 盘子图形出现，问"盘子里有几个苹果？" |
| 1.5s | 空盘子闪烁 → "0个！没有！" |
| 2.5s | 尺子图案出现，标注0刻度 |
| 3.5s | 箭头指向0，说明"计数起点" |
| 5.0s | 重点停留 |
| 6.5s | FadeOut清场 |

---

## Scene 3: 数字1-5 (10秒)
**目的**: 认识1到5，用点阵直观呈现

### 布局
- 上方：大数字
- 下方：对应数量的圆点阵列

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | "1" 出现 + 1个点 |
| 1.5s | Transform到"2" + 2个点 |
| 3.0s | Transform到"3" + 3个点 |
| 4.5s | Transform到"4" + 4个点 |
| 6.0s | Transform到"5" + 5个点(骰子布局) |
| 7.5s | 全部1-5排列显示 |
| 9.0s | FadeOut |

---

## Scene 4: 数字6-10 (10秒)

| 9.0s | FadeOut |
