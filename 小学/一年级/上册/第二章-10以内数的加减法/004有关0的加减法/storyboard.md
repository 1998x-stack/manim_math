# 有关0的加减法 - 动画分镜脚本

## 元信息
- 目标时长: 55 秒
- 场景数量: 6 个
- 难度等级: 一年级（简单）
- 目标受众: 6-7岁小学生

## 颜色配置
```python
COLOR_BG = "#1a1a2e"
COLOR_APPLE = "#e74c3c"       # 红色圆圈代表苹果
COLOR_ZERO = "#95a5a6"        # 灰色代表0（空）
COLOR_RESULT = "#2ecc71"      # 绿色结果
COLOR_FORMULA = "#f1c40f"     # 黄色公式
COLOR_HIGHLIGHT = "#e67e22"   # 橙色高亮
COLOR_RULE = "#3498db"        # 蓝色规律
```

## 几何预计算清单
| 元素 | 说明 | 备注 |
|------|------|------|
| 苹果圆圈 | radius=0.35, 横向排列, 间距0.9 | 5个一排，x从-2到2 |
| 空盘子 | 虚线圆形 DashedVMobject | 代表0 |
| 公式文本 | VGroup(Text+MathTex) | 中文+数学混排 |

## Scene 1: 开场钩子 (0-4秒)
**目的**: 抓住注意力，引出问题

### 元素
1. 作者信息 (顶部)
2. 大问号动画
3. 钩子问题: "5个苹果加0个苹果等于几？"

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 作者信息 FadeIn |
| 0.3s | 大数字"5+0=?" Write |
| 1.5s | 提示文字 FadeIn |
| 2.5s | Wait |
| 3.5s | FadeOut问题 |

---

## Scene 2: a+0=a 演示 (4-22秒)
**目的**: 用苹果直观展示加0不变

### 动画序列
1. 标题"加上0"淡入
2. 5个红苹果圆圈逐一出现
3. 加号出现
4. 空盘子（0个）出现，带虚线圆圈
5. 等号出现，右边5个苹果出现
6. 公式 5+0=5 写出
7. 规律文字"加上0，还是原来的数"

---

## Scene 3: a-0=a 演示 (22-35秒)
**目的**: 演示减去0不变

### 动画序列
1. 标题"减去0"淡入
2. 5个苹果出现
3. 减号 + 空盘子（0个）
4. 等号后5个苹果不变
5. 公式 5-0=5
6. 规律文字"减去0，还是原来的数"

---

## Scene 4: a-a=0 演示 (35-48秒)
**目的**: 演示相同数相减得0

### 动画序列
1. 标题"减去全部"淡入
2. 5个苹果出现
3. 减号 + 5个苹果（被减）
4. 等号后出现空盘子（0）
5. 公式 5-5=0
6. 规律文字"相同的数相减，等于0"

---

## Scene 5: 规律总结 (48-53秒)
**目的**: 三条规律汇总

三个公式卡片：
- a + 0 = a  （加0不变）
- a - 0 = a  （减0不变）
- a - a = 0  （自减得零）

---

## Scene 6: 片尾 (53-57秒)
**目的**: 作者信息 + 关注提示
