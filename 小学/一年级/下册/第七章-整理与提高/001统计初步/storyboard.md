# 一年级统计初步 - 动画分镜脚本

## 元信息
- 目标时长: 60-75 秒
- 场景数量: 6 个
- 难度等级: 入门（一年级）
- 主题颜色: 活泼、明亮

## 颜色配置
```python
BG_COLOR = "#1a1a2e"
COLOR_APPLE = "#e74c3c"      # 红色 - 苹果
COLOR_BANANA = "#f1c40f"     # 黄色 - 香蕉
COLOR_ORANGE = "#e67e22"     # 橙色 - 橙子
COLOR_GRAPE = "#9b59b6"      # 紫色 - 葡萄
COLOR_TABLE = "#2ecc71"      # 绿色 - 表格
COLOR_TITLE = GOLD
COLOR_HIGHLIGHT = YELLOW
```

## 数据设定
| 水果 | 人数 |
|------|------|
| 苹果 🍎 | 5   |
| 香蕉 🍌 | 3   |
| 橙子 🍊 | 4   |
| 葡萄 🍇 | 6   |
| 合计   | 18  |

---

## Scene 1: 开场钩子 (4-5秒)
**目的**: 抓住小朋友注意力，引出问题

### 元素
1. 作者标识（顶部小字）
2. 钩子问题大字
3. 四种水果图标（用彩色简洁图形代替）

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | 作者信息淡入 |
| 0.3s | 标题 "小朋友最爱哪种水果？" 写出 |
| 1.2s | 四种水果一个个弹入 |
| 2.5s | 等待 |
| 3.5s | 问句 "我们来统计一下！" 出现 |
| 4.5s | 清场 |

---

## Scene 2: 数据展示 (8-10秒)
**目的**: 展示班级调查结果，让学生理解原始数据

### 元素
1. "班级调查结果" 标题
2. 用小圆点代表每个学生的选择
3. 按水果分类展示

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | "班级调查结果" 写出 |
| 0.5s | 苹果行：5个圆点一个个弹出 |
| 1.5s | 香蕉行：3个圆点弹出 |
| 2.3s | 橙子行：4个圆点弹出 |
| 3.1s | 葡萄行：6个圆点弹出 |
| 4.0s | "好乱啊！怎么数清楚呢？" |
| 5.0s | 提示：用统计表！ |

---

## Scene 3: 建立统计表 (10-12秒)
**目的**: 展示如何用统计表整理数据

### 元素
1. 表格框架（含表头）
2. 数字逐个填入

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | "统计表" 标题出现 |
| 0.5s | 表格框出现（创建矩形格子）|
| 1.0s | 表头：水果名称填入 |
| 2.0s | 数字逐个填入（配合高亮） |
| 5.0s | 合计行填入 = 18 |
| 6.0s | 等待理解 |

---

## Scene 4: 象形统计图 (15-18秒)
**目的**: 核心！展示象形统计图，每格=1

### 元素
1. 坐标轴（横轴=水果，纵轴=个数）
2. 每格代表1人的说明
3. 用小星星/圆圈逐格填入（每格=1）

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | "象形统计图" 标题 |
| 0.5s | 创建网格坐标轴 |
| 1.5s | 说明："每个☆代表1人" |
| 2.5s | 苹果列：5个☆一个个从下到上出现 |
| 4.0s | 香蕉列：3个☆ |
| 5.0s | 橙子列：4个☆ |
| 6.0s | 葡萄列：6个☆ |
| 7.5s | 等待欣赏图表 |

---

## Scene 5: 提问与解答 (10-12秒)
**目的**: 引导学生从图表中读取信息

### 元素
1. 问题文字
2. 高亮对应列
3. 答案文字

### 动画序列
| 时间 | 动作 |
|------|------|
| 0.0s | ❓"谁最多？" 出现 |
| 1.0s | 葡萄列高亮闪烁 |
| 1.5s | "葡萄最多！有6人" |
| 3.0s | ❓"谁最少？" 出现 |
| 3.5s | 香蕉列高亮 |
| 4.0s | "香蕉最少！有3人" |
| 5.5s | ❓"一共有多少人？" 出现 |
| 6.0s | 所有列高亮 |
| 6.5s | "5+3+4+6=18人" |

---

## Scene 6: 总结与片尾 (5-6秒)
**目的**: 强化知识，鼓励关注

### 元素
1. 知识要点
2. 作者信息
