# 小学一年级数学动画｜课程入口与质量验收

> 课程包含上册和下册，使用 Manim Community Edition 制作中文数学竖屏动画。历史 MP4 与 `*_finish.mp4` 是既有成片：修改 `.py` 不会自动重新制作或替换成片。

## 按学期导航

- [上册](上册/)：10 以内数的认识、10 以内数的加减法、认识图形（一）、20 以内数的认识、20 以内的进位加法。
- [下册](下册/)：100 以内数的认识、时间的初步认识（一）、人民币的认识、100 以内数的加减法、几何小实践、整理与提高。

章节编号遵循仓库当前目录。此处不根据缺失的“第一章”目录推断教材或动画文件缺失，教材版本需以具体知识点的课程说明核对。

## 当前优先修复的两个知识点

| 知识点 | 源文件 / 真实 Scene 类名 | 必须验证的数学事实 |
| --- | --- | --- |
| [上册：数一数](上册/第一章-10以内数的认识/001数一数/) | `counting_animation.py` / `CountingAnimation` | 5 个苹果依次对应 1～5；6 颗星星依次对应 1～6；只显示一个计数标签；星形顶点按圆周顺序排列。 |
| [下册：百数表](下册/第二章-100以内数的认识/003百数表/) | `003_百数表.py` / `HundredChartLesson` | 表格按 1～10、11～20……91～100 排列，横向 +1、纵向 +10、右下斜向 +11；末列为整十数，不能教“同一行十位相同”。 |

百数表的历史 `prompt.md` 属于原始任务资料；出现与数学规格冲突的描述时，以当前 `description.json`、`storyboard.md` 中核验后的数学定义为准。不要直接复用旧视频作为新代码的验证证据。

## 分层验收

以下命令在仓库根目录执行：

```bash
# 1. 全面列出一年级的 Python 源码、Scene 类和静态诊断；不依赖 Manim
python tools/audit_grade_one.py
python tools/audit_grade_one.py --json > grade_one_audit.json

# 2. 针对数数、星形顶点和百数表数值的纯数学回归测试
python -m unittest discover -s tests -p 'test_grade_one_*.py' -v

# 3. 两个优先修复场景的语法检查
python -m py_compile '小学/一年级/上册/第一章-10以内数的认识/001数一数/counting_animation.py'
python -m py_compile '小学/一年级/下册/第二章-100以内数的认识/003百数表/003_百数表.py'

# 4. 具备 Manim CE 与 PingFang SC（或复核后的替代中文字体）时分别低清渲染
manim -pql '小学/一年级/上册/第一章-10以内数的认识/001数一数/counting_animation.py' CountingAnimation
manim -pql '小学/一年级/下册/第二章-100以内数的认识/003百数表/003_百数表.py' HundredChartLesson
```

第 1 步的“全部源码”指按目录遍历的静态 AST/语法检查，**不是全部课程数学正确性检查**。第 2 步只覆盖两个知识点的纯数学辅助函数，无法检测 Manim 动画是否重叠或缺字。第 4 步必须逐帧核查数物对应、百数表行末颜色、中文字体、字幕安全边距、结束画面对象清理；通过后再讨论生产渲染和成片更新。

## 其他章节的数学验收重点

| 知识领域 | 需要覆盖的边界情况 |
| --- | --- |
| 数的组成与加减法 | 0、10、20；凑十与退位过程每一步的数量守恒，结果与展示物体一致。 |
| 百以内数的认识与计算 | 数位、跨整十（例如 19→20）、整十加减、借位时十位与个位的变化。 |
| 整时与半时 | 12:00、8:00、8:30、12:30；半时时针位于两小时数字之间，分针指向 6。 |
| 人民币 | 1 元＝10 角，1 角＝10 分；优先用整数分进行计算，不用浮点数累计金额。 |
| 几何与整理 | 图形经过平移和旋转后种类不变；区分立体和平面、数量和位置，复习题结论与画面一致。 |

详细问题、已修复范围与未完成项参见 [一年级代码审查与后续验收](../../docs/engineering/grade-one-quality-audit.md)。
