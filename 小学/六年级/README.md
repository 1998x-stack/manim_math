## 数学规格和边界

- 整除：整数 `a,b,c`，`b ≠ 0`，存在整数 `c` 使 `a=b×c`，等价于 `a` 除以 `b` 的余数为零。`12=3×4`，但 `13=3×4+1`；“12 能被 3 整除”和“3 能整除 12”方向不能颠倒。
- 最大公因数：`12=2²×3`、`18=2×3²`，所以 `gcd(12,18)=2×3=6`。
- 最小公倍数：对于正整数 12、18，各质因数选最高次数，`lcm(12,18)=2²×3²=36`。校验 `6×36=12×18`。零、负数输入的推广不在这段示范的教学范围内。
