# 认识千克 - 动画分镜脚本

## 元信息
- 目标时长: 60-75 秒
- 场景数量: 7 个
- 难度等级: 低（二年级）
- 格式: TikTok竖屏 1080×1920

## 颜色配置
```python
COLOR_TITLE = GOLD
COLOR_WATER = "#4FC3F7"
COLOR_APPLE = "#E53935"
COLOR_KG = "#A5D6A7"
COLOR_SCALE = "#78909C"
BG = "#1a1a2e"
```

## 元素说明
- 水瓶：用 RoundedRectangle + Rectangle 拼合
- 苹果：用 Circle + Line(茎) + Ellipse(叶) 拼合
- 电子秤：RoundedRectangle + 绿色屏幕 + 数字显示
- 无 ImageMobject，全部用基础图形绘制
