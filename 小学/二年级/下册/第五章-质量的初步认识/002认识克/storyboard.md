## 场景清单

### Scene 1: 开场钩子 (5s)
- 大字"1克"金色弹入
- "有多轻？" 淡入
- 左边：硬币图形 / 右边：花生米图形（问号遮盖）
- 两物品同时 GrowFromCenter

### Scene 2: 认识克单位 (8s)
- 标题"认识克"
- 绿色大圆圈 + "g"（字母符号）
- 等号行：克 = g
- 信息框："克是计量较轻物品的单位"
- 副说："比千克小得多！"

### Scene 3: 一枚硬币 ≈ 1g (10s)
- 标题"生活中的1克"，副标"一枚2分硬币"
- 硬币从空中落下（正面有"2分"字样）
- 下方弹簧秤（用Line+Circle组成）显示"1g"
- 指示箭头 + "读数：1g"
- 信息框："硬币很轻，只有1克哦！"

### Scene 4: 一粒花生米 ≈ 1g (10s)
- 副标"一粒花生米"
- 花生米图形（椭圆+纹理线）从中心生长
- 与硬币并排对比
- "它们都约 1克" 结果框
- 小说明："用手指捏一捏，感受1克！"

### Scene 5: 用弹簧秤称量 (10s)
- 标题"用弹簧秤称量"
- 弹簧秤：竖向刻度尺 + 指针 + 钩子
- 硬币挂上钩子，指针偏转到"1g"
- 黄色箭头指向刻度
- 三行说明框

### Scene 6: 克 vs 千克对比 (8s)
- 天平形状（两边）
- 左边：1枚硬币（1克）
- 右边：两瓶水（1千克）
- "1千克 = 1000克" 大字
- "1000枚硬币 = 1千克"说明

### Scene 7: 知识总结 + 片尾 (9s)
- 3张卡片飞入
  - "1克 = 1g"（蓝色）
  - "硬币/花生米 ≈ 1g"（棕色）
  - "克 < 千克"（紫色）
- 星星 + 作者信息
