## 执行检查

在仓库根目录：

```bash
python tools/audit_grade2.py
python tools/audit_grade2.py --json > grade2-audit.json
python tests/test_audit_grade2.py
python "小学/二年级/上册/第三章-乘法、除法（二）/002有余数的除法/verify_geometry.py"
```

`--strict` 将全部静态发现视为失败；默认仅语法错误导致非零退出码，便于在尚未清理全部历史占位脚本之前逐步修复。静态扫描或离线数学检查不能证明实际 Manim 画面通过。

运行渲染烟测须另行配置 Manim Community、LaTeX、FFmpeg 和可显示中文的字体：

```bash
manim -ql "小学/二年级/上册/第三章-乘法、除法（二）/002有余数的除法/you_shu_shu_de_chu_fa.py" YouShuShuDeChuFa
manim -ql "小学/二年级/上册/第三章-乘法、除法（二）/0017、8、9的乘法口诀/001_7、8、9的乘法口诀.py" MultiplyTableAnimation
```

## 逐课验收标准

| 数学领域 | 必须验证的要点 |
| --- | --- |
| 乘法与口诀 | 每行点数、行数、总数与算式、口诀一致；退出当前口诀时点阵不会遗留。 |
| 除法与余数 | 物体不增不减，`a=bq+r` 且 `b>0`、`0<=r<b`；“分给几人”和“每组几个”语义一致。 |
| 角与几何 | 角的两条射线共顶点，角弧是 intended interior；锐角小于 90 度、直角等于 90 度、钝角介于 90 和 180 度之间。 |
| 方位 | 地图旋转后方向文字与箭头同转；根据指北针判定北方，不将屏幕朝上误当恒定北方。 |
| 运算顺序 | 每步等式值不变；同级从左到右、乘除优先、先算括号。 |
| 位值、时间、计量 | 文字、单位、时钟指针、数量图像一一对应；进退位与时刻变化可追踪。 |
| 画面与工程 | 全部 Scene 成功渲染；文本不缺字、不溢出；对象不过度遮挡；脚本、故事板、描述和最终视频一致。 |
