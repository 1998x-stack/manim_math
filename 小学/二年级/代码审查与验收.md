## 2. 已在原始代码中定位、但尚待处理的问题

1. 上册《有余数的除法》原 `verify_geometry.py` 只有固定的“验证完成”打印，没有对场景对象边界、相交或公式语法进行实际断言；不能作为渲染或视觉质量通过的证据。
2. 原二年级部分短脚本以圆形充当通用占位图，并将中文、Unicode 符号直接交给 `MathTex`。这类问题需要在全目录逐个扫描后更换为语义对应的模型。
3. 部分课件在模块顶层修改 `manim.config`（如帧尺寸、分辨率），单独运行时可作为视频规格配置，但多个模块在同一 Python 进程中批量导入时可能相互覆盖；批量渲染建议使用独立子进程与显式配置。
4. 部分脚本硬编码 `PingFang SC` / `Heiti SC`。跨平台运行前需确认字体存在，并检查中文实际渲染与文本宽度；不应单靠 Python 成功导入判定字体可用。
5. 教学 `prompt.md` / `storyboard.md`、脚本、描述 JSON 和已生成视频需要逐课对齐；代码修复不代表仓库中历史 MP4 自动更新。

## 3. 可重复的基础检查

在仓库根目录运行：

```bash
python tools/audit_grade2.py
python tools/audit_grade2.py --json > grade2-audit.json
python tests/test_audit_grade2.py
```

`--strict` 将所有静态发现视为失败；默认仅语法错误导致非零退出码，避免当前历史占位课件阻断所有后续修复。静态扫描仅能标记高风险片段，无法证明复杂几何、数学对应关系与实际画面正确。

单课渲染示例（在具备 Manim Community、LaTeX、中文字体及 FFmpeg 的环境中执行）：

```bash
manim -ql "小学/二年级/上册/第三章-乘法、除法（二）/002有余数的除法/you_shu_shu_de_chu_fa.py" YouShuShuDeChuFa
manim -ql "小学/二年级/上册/第三章-乘法、除法（二）/0017、8、9的乘法口诀/001_7、8、9的乘法口诀.py" MultiplyTableAnimation
manim -ql "小学/二年级/下册/第一章-复习与提高/001运算顺序/001运算顺序_animation.py" Topic001运算顺序Animation
```

## 4. 后续逐课验收标准

| 内容 | 必须验证的教学与动画性质 |
| --- | --- |
| 乘法与口诀 | 每行物体数量、行数、乘积和口诀数字一致；动画退出后无遗留对象；交换因数时解释符合实际分组模型。 |
| 有余数的除法 | 原始对象守恒；`a = bq + r`；`b > 0`、`0 <= r < b`；平均分给几人和每组几个的语义不能混淆。 |
| 认识角、直角、锐角、钝角 | 两条射线共顶点；角弧指向预期内角；区分 0～90、90、90～180 度（不把平角当钝角）。 |
| 方向与位置 | 北箭头与文字始终一致；旋转地图后不再把屏幕上方直接称作北；观察方向应写明观察者视角。 |
| 运算顺序 | 每步等式值相同；有括号先算括号，同级运算从左到右，乘除优先于加减。 |
| 数的认识、计量与时间 | 数字、数量、单位和图示一一对应；进位/退位与位值变化可追踪；时钟指针角度和所写时刻一致。 |
| 所有场景 | Python 语法通过；Manim 低质量完整渲染成功；中文字体不缺字；内容在画幅安全区；对象没有不合理遮挡；标题/公式/语音/视频与题目一致。 |
