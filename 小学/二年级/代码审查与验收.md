## 三、复现命令

在仓库根目录执行：

```bash
python tests/test_audit_grade2.py
python tools/audit_grade2.py --json > grade2-audit.json
python '小学/二年级/上册/第三章-乘法、除法（二）/0017、8、9的乘法口诀/verify_geometry.py'
python '小学/二年级/上册/第三章-乘法、除法（二）/002有余数的除法/verify_geometry.py'
```

`python tools/audit_grade2.py --strict` 要求当前所有静态发现都清零；默认退出码只会在发现 Python 语法错误时变为非零。数学/静态坐标检查不运行 Manim，也不能确认中文字体、渲染边界或图像遮挡。

需要 Manim Community、LaTeX、FFmpeg 和中文字体的真实渲染验收示例：

```bash
manim -ql '小学/二年级/上册/第三章-乘法、除法（二）/002有余数的除法/you_shu_shu_de_chu_fa.py' YouShuShuDeChuFa
manim -ql '小学/二年级/上册/第三章-乘法、除法（二）/0017、8、9的乘法口诀/001_7、8、9的乘法口诀.py' MultiplyTableAnimation
manim -ql '小学/二年级/下册/第一章-复习与提高/001运算顺序/001运算顺序_animation.py' Topic001运算顺序Animation
```

## 四、合并前的分项验收

| 领域 | 验收标准 |
| --- | --- |
| 除法 | 原始物体数量守恒，每人实际获得 3 个、余 1 个；`a=bq+r` 且 `b>0, 0<=r<b`；对象移动不重叠、不增加。 |
