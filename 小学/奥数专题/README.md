# 小学奥数专题｜知识地图与第一批 8 集

面向小学三至六年级的拓展学习。按**数学主题**归档，与已有按教材/年级/学期组织的课程并行，不覆盖旧 Prompt、Scene、媒体或画廊索引。本目录的知识点清单是课程规划，不表示已完成对应视频。依据 `.claude/skills/manim-video-production/SKILL.md` 设计数学、分镜、源码、验收的分层产物。

## 核心知识地图（16 模块、112 项）

| 模块 | 知识点（逐项） |
|---|---|
| 01 计算与巧算（8） | 加减乘除巧算；凑整与拆分；乘法分配律；等差数列求和；分组求和；裂项相消；定义新运算；复杂分数计算 |
| 02 数论与整数性质（9） | 奇偶性；整除特征；质数与合数；质因数分解；约数与倍数；最大公因数；最小公倍数；余数与同余；完全平方数 |
| 03 数字谜与数字规律（7） | 数位与位值；数字排列；填数谜；算式谜；竖式谜；周期数列；数表与数阵规律 |
| 04 分数、比例与百分数（7） | 分数的意义与性质；单位“1”；分数大小比较；比与比例；比例分配；百分数应用；浓度与配比问题 |
| 05 典型应用题（9） | 和差问题；和倍问题；差倍问题；年龄问题；盈亏问题；鸡兔同笼；平均数问题；归一与归总问题；还原问题 |
| 06 行程问题（8） | 路程速度时间；相遇问题；追及问题；流水行船；火车过桥与错车；环形跑道；多次相遇；变速与分段行程 |
| 07 工程与效率问题（6） | 工作总量与效率；合作工程；交替工作；休息与停工；水池注水与排水；周期性工程 |
| 08 平面几何（10） | 角度计算与角度追踪；三角形与四边形性质；周长与面积；等底等高与等面积法；割补法；平移与旋转；蝴蝶模型；燕尾模型；鸟头模型；圆与扇形 |
| 09 立体几何（6） | 正方体与长方体；表面积与体积；立体图形展开图；三视图与堆积木；切割与拼接；染色方块与空间计数 |
| 10 排列组合与计数（8） | 分类计数原理；分步计数原理；排列与组合；树状图与列表法；加法原理与乘法原理；容斥原理；路径计数；抽屉原理 |
| 11 逻辑推理与策略（7） | 真假话推理；条件分析与排除；列表推理；最优策略；博弈与必胜策略；操作与变换问题；不变量与奇偶分析 |
| 12 集合与容斥（5） | 集合与韦恩图；两个集合的容斥；三个集合的容斥；至少与至多问题；集合分类计数 |
| 13 数学模型与数形结合（6） | 线段图模型；面积模型；方格模型；天平与等量代换；倒推模型；方程思想与消元 |
| 14 周期、规律与递推（6） | 周期循环；图形变化规律；递推数列；斐波那契数列；找规律填数；数阵与幻方 |
| 15 组合几何与图论启蒙（5） | 图形计数；握手问题；点线面计数；一笔画问题；最短路径与网络连通 |
| 16 趣味数学与综合专题（5） | 最值问题；称重与找假币；钟表问题；日历与星期；综合数学建模 |

这些模块可能交叉：分数乘法的面积模型也属于数形结合；容斥既可放在集合模块也可放在计数模块。本清单的“112 项”指上表计数，不保证所有教材都使用相同分类。
