# 006 相遇问题｜真实比例的双向线段图

- 数学规格：初距 200 千米，甲乙相向匀速 60、40 千米/时，同时出发且不停走；道路 x∈[-3,3] 表示 200 千米，scale=6/200 单位/千米。t=2 小时相遇于 x=.6，甲走 120 千米、乙走 80 千米。

## 分镜与核验
1. `road/ticks`：从 0 到 200 每隔 40 千米等比例刻度，甲乙点分别在 −3 与 3；速度标签分别贴近对应起点。
2. `t/x_a/x_b/traveled_a/traveled_b/gap`：同一时间跟踪器驱动甲、乙坐标及蓝色、黄色已走线段和绿色剩余路段。任意 0≤t≤2 时路程总和 60t+40t+(200−100t)=200。
3. `time_value/gap_value` 实时更新小时数与剩余千米；t=1 时可见剩余 100 千米，t=2 时显示 0，两个点必须在 x=.6 重合。
4. `mark/proof/answer/principle`：突出交点，显示 120+80=200、t=200/(60+40)=2；颜色、数字与两条已走线段一一对应。

## 验收
检查三个时间关键帧 t=0,1,2 的位置与数字，防止动态零长度线段造成首帧运行故障；文字基线、运算公式和音轨需真实渲染及媒体检查后才算通过。
