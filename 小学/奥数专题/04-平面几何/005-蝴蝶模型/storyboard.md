# 005 梯形蝴蝶模型｜四块真实面积

- 数学规格：A=(-1.5,2),B=(1.5,2),C=(3,-2),D=(-3,-2)；AB∥CD，长度分别 3 与 6，高 4。由相似关系 O=A+AB/(AB+CD)×(C−A)=(0,2/3)，且 O 也须落在 BD。四区面积为 2、4、4、8，合计 18。退化底长或高拒绝。

## 分镜及核验
1. `title/premise/outline/diagonals/names`：按真实 A,B,C,D 连两条对角线，标签对应实际点；不能手画一个不在两条线上的交点。
2. `regions/area_labels`：顶蓝、左绿、右绿、底黄，四块恰好铺满梯形，不覆盖或遗漏；数字必须置于对应三角形的重心附近。
3. `horizontal/similar/heights`：过 O 画平行辅助线，显示 AO:OC=1:2、上下高分别 4/3 与 8/3；确保高与顶底位置相容。
4. `wings/ratio`：逐一高亮左右两翼且面积同为 4；上下两区 2:8=1:4。数学检测 butterfly_areas(3,6,4)==(2,4,8) 和四区之和为梯形面积 18。

## 验收
实际预览核查每块面积数字不被对角线、点标 O 或辅助线遮挡；AST 与数学检查不能代替渲染审阅。
