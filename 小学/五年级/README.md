## 数学规格与验收

加权平均数的独立校验：`(90×10 + 85×15 + 80×5) ÷ (10+15+5) = 515/6 = 85又5/6 ≈ 85.83`；保留一位小数为 `85.8`。确认每个数值的精度标注，尤其不要把近似号写成等号。

分数的意义：单位“1”必须先明确指定；平均分成四份后每份为 `1/4`，取三份为 `3/4`。检查每一份面积相等、颜色覆盖和分数标注与分镜一致。

等式的性质：两边同乘一个数或同除一个数时，除法的除数**不能为零**；天平演示必须在两侧实施等价操作。

体积的意义：`4×3×2=24` 个单位立方体，但仅展示平面 `Square` 网格不足以单独证明三维填满；对 `第五章-几何小实践/004长方体和正方体的体积` 的网格、层数和等轴测表示继续进行关键帧检查。

## 不依赖 Manim 的快速审计

在仓库根目录执行：

```bash
python tools/check_grade5.py
python tools/check_grade5.py --json > grade5-audit.json
python -m unittest discover -s tests -p 'test_grade5_*.py'
```

`--strict` 会将历史遗留警告也视为失败，适合完成清理后作为更严格的质量门禁。扫描只能定位 Python 语法、疑似占位内容、错误说明、可疑文本和全局配置等模式；**它不能证明数学逻辑、场景时序、画面和已有 MP4 正确**。在具备 Manim CE、中文字体、LaTeX、FFmpeg 的环境中，应继续分别运行主场景与兼容入口的 `manim -ql` 渲染，再人工检查代表帧。此次修改未对 MP4 重新渲染，也未将历史媒体标记为验证通过。
