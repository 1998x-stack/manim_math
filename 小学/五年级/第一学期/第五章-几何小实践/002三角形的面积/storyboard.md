## 几何预计算

```
A  = (-2.0,  0.0)   底边左端点
B  = ( 1.0,  0.0)   底边右端点
C  = (-1.0,  2.5)   顶点 (底边内侧垂足)
M_BC = (0.0, 1.25)  BC中点 —— T2旋转轴
A' = ( 2.0,  2.5)   T2翻转后的第四顶点

底 a = |AB| = 3.0
高 h = C.y - A.y = 2.5
H_foot = (-1.0, 0.0)  C在底边上的垂足 (在AB内部: -2 ≤ -1 ≤ 1 ✓)

平行四边形顶点顺序: A(-2,0) → B(1,0) → A'(2,2.5) → C(-1,2.5)
旋转验证:
  A(-2,0)  → 2*(0,1.25) - (-2,0) = (2, 2.5) = A' ✓
  B(1,0)   → 2*(0,1.25) - (1,0)  = (-1,2.5) = C  ✓
  C(-1,2.5)→ 2*(0,1.25) - (-1,2.5)= (1,0) = B   ✓
```
