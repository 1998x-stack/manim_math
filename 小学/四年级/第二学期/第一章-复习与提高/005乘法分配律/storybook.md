# 乘法分配律

## 概述
两个数的和与一个数相乘,可以先把它们分别与这个数相乘,再相加。用字母表示:(a + b) × c = a × c + b × c。这是最重要的运算定律,也可以逆用:a × c + b × c = (a + b) × c。如102×15=(100+2)×15=100×15+2×15=1530。

## 数学公式
- (a + b) × c = a × c + b × c
- 示例:102 × 15 = (100+2) × 15 = 1530
- 逆用:35×7 + 65×7 = (35+65) × 7 = 700
