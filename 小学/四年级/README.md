## 全年级源码巡检

从仓库根目录运行：

```bash
python tools/audit_grade4.py
python tools/audit_grade4.py --json > grade4_audit.json
python -m unittest discover -s tests -p 'test_grade4_*.py' -v
```

`audit_grade4.py` 使用标准库检查四年级目录下每一个 `.py` 文件，不依赖 Manim。它将语法/读取错误归为 `errors`，将疑似模板、MathTex 中的中文或 Unicode 数学符号、在 `construct` 内设置画幅等归为 `warnings`。警告需要人工复核，不能当作已证实的渲染故障。`--strict` 仅在存在源码错误时返回退出码 1；建议在修完全部旧代码语法问题后将其作为 CI 阻断条件。

已添加纯数学测试：`123×45=5535`、`105×40=4200`、`204×30=6120`、`999×99=98901`，并覆盖全部 900×90 种合法输入组合以及边界/错误输入。测试通过并不证明 Manim 画面、中文字体或 LaTeX 渲染成功。显示形式为把十位部分积 `4920` 的个位 0 对齐到个位列，突出十位乘法带来的数位移动。

## 每一课的验收要求

1. **源码**：`ast.parse` 成功；Manim 能发现且执行预期场景，且无导入副作用导致的画幅冲突。
2. **数学**：答案、每步计算、单位和图中标记一致。小数使用整数比例或 `Decimal` 验证；角度区分约数和精确等式；统计图刻度与真实数据相符。
3. **画面**：使用目标 9:16 画幅，检查首帧、每次转场、主要计算步骤和尾帧；所有公式与字幕在安全区域内，文字不覆盖或越界。
4. **工程**：两份入口共用实现；不要将 Python 源码、渲染结果和旧版占位动画视作同一状态。若修改数学或画面，重新生成并核对视频后再更新其发布状态。

由于本次代码连接不具备可运行的 Manim、LaTeX 与完整本地仓库环境，上述视觉与整课运行验收仍需要在已安装依赖的工作环境执行，不应将静态检查通过表述为所有课程已经完成修复。
